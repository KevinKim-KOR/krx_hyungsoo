## 5. 설계자 판단이 필요한 질문

1. **D-1 을 어떻게 처리할지.** ML 을 돌려 값을 채울 것인가, 아니면 참고점수처럼
   **`고점 대비` 열·정렬도 화면에서 뺄 것인가.** 지금은 "열은 있는데 값이 없는" 상태다.
2. **N-3 (ML job `failed` 잔존)** — 화면이 실패를 계속 보여주는 게 맞는가, 아니면
   실패 상태를 지울 수단이 필요한가.
3. **`EXCLUDED` 6건이 정말 제외인가.** 원장 본문에 제외 근거가 없어 개발자 추정이 섞였다.
4. **`COMPLETED` 3건을 제거할지 범위 축소할지.**
5. **U-3 — `Layer B/C` 의 연계 대상.** 원장은 "ASSUMPTIONS 연계" 라는데 그 문서에
   해당 문자열이 없다. 다른 문서로 옮겨졌는가, 아니면 정의된 적이 없는가.
6. **원장 건수 정합.** 105 → 65 로 줄인 기록은 있으나 현재 67건이다. **차이 2건의
   출처와, `B-001~B-105` ↔ 현재 67건 대응표를 만들지** 판단이 필요하다.
7. **D-3 (PC package 경로)** — PC 에서 실측이 필요하다. 개발자는 PC 접근이 없다.
