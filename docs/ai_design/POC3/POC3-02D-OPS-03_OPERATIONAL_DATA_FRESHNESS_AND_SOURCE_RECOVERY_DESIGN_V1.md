## 확정된 설계 계약

### 1. 국내 데이터 정상 기준

08:00 시장 브리핑과 장중 신규 진입 판단의 정상 기준일은 **직전 완료 거래일 T-1**입니다.

매일 반복되는 T-2를 정상으로 수용하지 않습니다.

### 2. 08:00 시장 브리핑

T-1 국내 데이터가 없으면:

* 미국 시장 전망은 정상 조건을 충족할 때 발송
* 국내 「오늘 볼 기초지수」 구역은 생략
* T-2 값을 오늘의 정보처럼 표시하지 않음
* 생략 사유를 한 줄로 명시

예시:

```text
국내 기초지수는 직전 거래일 자료를 확인하지 못해 제외했습니다.
```

### 3. 장중 신규 진입 검토·회피

5일·20일 추세 기준일이 T-1이 아니면 해당 신규 진입 구역은 fail-closed로 생략합니다.

보유 종목의 실시간 급등락 판정은 정상 동작하므로 계속 운영합니다.

신규 진입 구역을 표시할 때는 반드시 다음 줄을 넣습니다.

```text
추세 기준 YYYY-MM-DD 종가
```

본문의 실시간 현재가·전일 대비 기준과 5일·20일 추세 기준을 혼동하지 않게 분리하십시오.

### 4. 국내 T-1 확보 방법

다음 후보를 실제 가용 시각·가격 기준·호출량으로 비교하십시오.

1. KRX 기존 API를 장 마감 뒤 재조회
2. 다음 날 08:00 직전 재조회
3. 현재 API 키로 사용할 수 있는 다른 KRX 공식 데이터
4. 기존 FDR 경로
5. 기존 Naver 경로
6. 승인된 사업군 대표 ETF 27개만 선택 조회

특히 `16:30 · 18:00 · 20:00 · 다음 날 07:20`의 T-1 가용성을 확인하십시오. 전일 장 마감 뒤 미리 받아 두는 방법을 우선 검토합니다.

수동 KRX CSV는 메타데이터이지 매일의 가격 갱신 수단이 아닙니다. 일별 가격 때문에 사용자에게 CSV를 반복 요청하는 설계는 허용하지 않습니다.

ETF 기본정보도 기존 API 키로 자동 갱신 가능한지 조사하고, 불가능하다면 정확한 API 제약을 PLAN에 적으십시오.

### 5. KOSPI 자료원

기존 `SOURCE_SWITCH=PROHIBITED` 계약은 OPS-03 범위에서 해제합니다. 현재 자료원이 2026-09-17 이후 멈췄기 때문입니다.

우선순위:

1. 현재 보유한 KRX API 키로 공식 KOSPI 일별 지수 조회
2. 저장소가 이미 사용하는 다른 자료원
3. 신규 외부 자료원

자료원을 비교할 때 같은 날짜 값, 종가 기준, 수정 가능성, 공표 시각을 함께 대조하십시오.

KOSPI를 표시하는 모든 PC 화면에는 동일한 최신성 판정을 적용합니다. 일부 카드에만 경고하고 차트에는 낡은 값을 정상처럼 보이는 상태를 남기지 마십시오.

### 6. S&P500 최신성

정상 기준은 **가장 최근에 완료된 미국 거래 세션**입니다. 주말·미국 휴장일을 반영하여 기대 기준일을 계산하십시오.

### 7. 실패·지연 고지

* 08:00 국내 데이터 지연: 같은 브리핑 안에서 고지
* 장중 신규 진입 추세 지연: 해당 구역 생략 및 집계 기록

## STEP 1. 시간 계약 변경

이는 기존 08:00 계약을 단순히 다르게 해석하는 것이 아니라 **명시적으로 변경하는 것**입니다.

```text
KRX 수집 시작       08:10
KRX 재시도          08:15 · 08:20 · 08:24
수집 마감           08:27
시장 브리핑         08:30
장중 첫 알림         09:30
```

08:00 시장 브리핑 계약은 08:30으로 개정하고 관련 설계서·목업·운영 문서를 모두 동기화하십시오.

고정 PUSH 수는 그대로입니다. 시장 브리핑 시각만 08:00에서 08:30으로 이동합니다.

## STEP 2. 배치 구조 — 전체 배치를 08:10으로 이동

07:20 전체 배치는 폐지하고 **전체 배치를 08:10으로 이동**합니다.

단, 전체 단계는 실패를 격리해야 합니다.

* FDR 한 종목 실패가 KRX·KOSPI·미국 데이터 수집을 막지 않음
* FDR timeout 명시
* 미국·FDR은 회차당 한 번만 수집
* KRX 재시도 때문에 FDR·Naver 호출을 반복하지 않음
* KRX 재시도는 동일 실행 안에서 또는 KRX 전용 idempotent 경로로 수행
* 08:27 이후에는 더 기다리지 않고 fail-closed

재시도 과정에서 성공한 T-1 결과를 이후 실패 응답이나 T-2 결과가 덮어쓰면 안 됩니다.

## STEP 3. KRX 성공 판정

행 수 1,175 같은 고정값 일치를 성공 조건으로 두지 마십시오. 신규 상장·상장폐지 때문에 바뀔 수 있습니다.

성공 조건은 다음과 같습니다.

1. 반환 기준일이 기대 기준일 T-1과 정확히 일치
2. 필수 대표 ETF 27종 커버리지 100%
3. 전체 행 수가 직전 정상 적재 대비 급감하지 않음
4. 관계식·중복·0행 검증 통과
5. 저장 후 read-back 기준일과 건수 일치

전체 행 수 급감 기준은 직전 정상 적재의 95% 미만을 기본안으로 두되, 실제 분포를 확인해 PLAN에 근거를 기록하십시오.

5일·20일 계산은 단순 행 위치가 아니라 **거래일 날짜 기준**으로 계산하십시오. 하루가 빠졌다고 6일·21일 전 값으로 밀리면 안 됩니다.

## STEP 4. 국내 데이터 최신성

08:30과 09:30 이후 정상 기준은 모두 **직전 완료 거래일 T-1**입니다.

`lag ≤ 1`만으로 정상 처리하면 T-2가 다시 정상으로 들어올 수 있으므로, 정상 판정은 lag 숫자가 아니라 다음 조건으로 합니다.

```text
actual_basis_date == expected_previous_trading_day
```

08:27까지 T-1이 공개되지 않으면:

* 08:30 미국 전망은 정상 조건 충족 시 발송
* 「오늘 볼 기초지수」 구역은 생략
* T-2 자료를 대신 표시하지 않음
* 기존 확정 안내 문구를 한 줄 표시
* 08:30 브리핑을 나중에 재발송하지 않음

## STEP 5. 09:20 보강 수집

08:27까지 T-1을 확보하지 못한 날에는 **09:20 KRX 전용 재조회 1회**를 허용합니다.

목적은 09:30 이후 장중 판단 복구입니다.

* 08:30 시장 브리핑 재발송 금지
* 성공하면 09:30부터 장중 신규 진입 구역 정상 사용
* 실패하면 신규 진입 검토 구역만 계속 생략
* 하루 한 번만 실행
* FDR·미국·Naver 전체 재수집 금지

## STEP 6. 장중 알림

T-1 가격 이력에 의존하는 것은 「신규 진입 검토」 구역입니다. 이 구역은 T-1 미확보 시 생략합니다.

다음은 사용하는 입력이 정상이라면 계속 운영합니다.

* 보유 종목 실시간 급등락
* 전일 대비 실시간 급락 회피
* 전일 대비 실시간 추격 주의

단, 이 구역들에 5일·20일 수치를 표시한다면 그 수치도 반드시 T-1 기준이어야 합니다. 최신성이 확인되지 않은 5일·20일 수치는 문구에서 빼십시오.

추세 수치를 표시할 때는 다음을 명시합니다.

```text
추세 기준 YYYY-MM-DD 종가
```

## STEP 7. KOSPI 공식 자료원

KOSPI는 `idx/kospi_dd_trd` 공식 종가로 전환합니다.

정상 조건:

```text
kospi_as_of == expected_previous_trading_day
```

기존 `lag ≤ 1` 계약은 폐기합니다. T-2는 정상으로 보지 않습니다.

현재 저장된 2026-09-17 값이 공식 종가와 다르므로 다음 절차를 지키십시오.

1. 기존 값·source·hash 보존
2. 영향 날짜 전체 대조
3. 공식 종가로 정정
4. 변경 전후 건수와 값 기록
5. 화면·API·배치가 같은 최신성 함수를 사용
6. 일부 카드뿐 아니라 KOSPI 차트에도 기준일 지연 표시

기존 값을 증거 없이 조용히 덮어쓰지 마십시오.
