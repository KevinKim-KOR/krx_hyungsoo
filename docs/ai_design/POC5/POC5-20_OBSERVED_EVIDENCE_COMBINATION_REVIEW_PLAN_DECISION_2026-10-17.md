# POC5-20 근거 조합의 과거 사례 대조 — PLAN 판정

작성일: 2026-10-17 · 작성자: 설계자 · 수신: 개발자

**판정: PASS. 아래 확정을 PLAN에 반영하고 재제출 없이 구현한다.**

첨부 PLAN V1과 설계서 V1을 대조했다. 첨부 설계서는 설계자 원문과 같다. 실측 수치는 개발자의 읽기 전용 조사 근거로 수용하며, 설계자가 PC DB를 직접 조회한 것은 아니다.

## 1. Q1 확정 — (b) 반올림 전 거래량 배수

- 유효한 원래 계산 배수가 **1보다 크면 평균 초과, 1 이하면 평균 이하**다. 표시용 소수 둘째 자리로 반올림한 뒤 분류하지 않는다. 임의 오차 허용 구간도 추가하지 않는다.
- 이번 질문은 거래량이 실제 직전 평균을 넘었는지다. 1.004배는 평균 초과이고 1.000배는 평균 이하다. 화면에서 둘 다 1.00배로 보일 수 있다는 이유로 실제 관측 경계를 옮기지 않는다.
- 리포트의 비교 정의에 '거래량은 표시 반올림 전 배수 기준'을 한 번 적는다. 기존 화면의 배수 표시나 계산 함수를 변경할 필요는 없다.
- 흔들림은 기존 POC5-16 비교 라벨을 재사용하도록 명시했으므로 **소수 둘째 자리 기준의 higher / lower / same**을 유지한다. 거래량과 흔들림 각각의 기준을 구분해 기록한다.
- 경계 시험은 최소한 원래 배수 0.996·1.000·1.004를 포함한다. 각각 평균 이하·평균 이하·평균 초과여야 한다. 평균 0·결측 등 기존 계산 불가 사유는 분류 대상이 아니다.

## 2. PLAN 수용과 실행 확정

- ETF 26종목·기준일 159일·전체 4,134건의 조사 범위, 계좌 중복 제거, 개별주 3종목의 대상 밖 처리, 세 계산 함수 재사용과 역사적 기준일 적용을 수용한다.
- **1,754건은 결과 완결·연결 확인 전의 공통 표본 후보 수**다. 이를 최종 분석 건수로 고정하거나, 최종 건수를 맞추기 위해 제외 규칙을 바꾸지 않는다.
- 공식 대조는 **`--end 2026-10-14`로 고정**한다. PLAN §3의 '실행 당시 시장 DB 최신 저장일' 문장은 이 날짜로 바꾼다. 이후 갱신으로 더 최신 자료가 생겨도 이번 대조의 종료일은 유지한다.
- 시장 DB의 필요한 가격 행을 하나의 읽기 트랜잭션에서 읽고, 읽은 보유 종목 목록과 함께 입력 사본으로 확정한다. 계산·입력 식별·산출물은 같은 입력 사본을 사용한다. 기준일 t의 관측은 t 이하, 이후 결과도 10-14 이하 자료만 사용한다. 기존 자료가 갱신돼 PLAN의 조사 건수와 달라지면 실제 건수와 이유를 적는다.
- 사유를 순서대로 하나씩 세는 제외표, 같은 공통 표본의 가격 구간 표·네 조합 표, 실제 건수·분위수·날짜별 중앙값의 중앙값, 입력 거래일 앞 80일·뒤 79일 부록을 수용한다. 읽기·계산·표·출력의 제안 모듈 분리와 시험 범위도 수용한다.

## 3. 진행과 종료

- PLAN 반영 → 구현·시험 → 실제 자료 공식 1회와 같은 입력 결정성 확인 → 결과서·리포트의 검증자 확인 → 설계자 RESULT 판정 순서로 진행한다. 별도 조사 단계·목업·추가 PLAN 판정은 필요 없다.
- 결과가 약하거나 일부 조합의 표본이 부족해도 정상 산출물이다. 결과에 맞춰 기준·종목·기간을 바꿔 반복하지 않는다. 결함 정정에 따른 재실행은 사유를 기록한다.
- 이번 산출은 현재 보유 ETF의 관측 대조다. 운영 위험 등급·새 모델·PUSH 채택 판정이 아니며, Q6 운영 계약 OPEN과 기존 연구의 종료·REJECT 기록을 유지한다. OCI 반영이나 거래일 대기는 필요 없다.
- 커밋·push는 이번 단계의 사용자 승인 범위에서 처리한다. 본 PLAN 판정 자체를 새로운 사용자 push 승인으로 해석하지 않는다.
