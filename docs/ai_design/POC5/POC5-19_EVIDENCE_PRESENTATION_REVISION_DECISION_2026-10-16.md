# POC5-19 사용자 목업 의견 반영 — 근거 배치 개정 판정

작성일: 2026-10-16 · 작성자: 설계자 · 독자: 개발자

**판정: 기존 독립 거래량 접힘 구역의 화면 구현은 수정 목업 확인 뒤 진행한다. 같은 POC5-19 안에서 근거 배치를 개정하며 새 단계를 만들지 않는다.**

## 1. 변경 이유와 우선순위

- 사용자 의견은 '기능이 있다는 것을 확인했다'는 데 그치지 않는다. 가격·거래량·변동성 등 쓸 만한 정보를 함께 보고 판단할 수 있어야 한다는 요구다.
- 긴 설명을 ? 안으로 옮기는 원칙을 개별 기능의 핵심 수치까지 따로 숨기는 방식으로 적용한 설계는 수정한다. 개발자의 구현 편의를 위한 결정이 아니라 설계자의 기본 접힘 지시가 만든 배치다.
- 우선순위는 **종목 선택 → 중요한 근거 함께 보기 → 필요할 때 세부 흐름 확인**이다. 각 기능을 별도로 펼쳐 수치를 모아야 하는 구조를 반복하지 않는다.

## 2. 수정 목업 지시

- 「확인 근거」에서 종목을 고르면 기존 상세의 핵심 근거를 한 묶음으로 보여 준다. 새 메뉴·새 대시보드 카드를 만들지 않는다.
- 기본 표시: **가격 흐름 / 거래량 / 가격 흔들림** 세 묶음. 기존 5일·20일 변화와 하락 구간, 거래량 평균 대비 배수, 최근 변동성과 직전 대비 문구를 짧게 나란히 읽을 수 있게 배치한다. 같은 값을 기존 위치와 새 위치에 중복 나열하지 않는다.
- 기존 평가손익·계좌 정보·자료 확인 사유·가격 기준일은 유지한다. 숫자와 날짜가 빠지는 이동은 하지 않는다. 해당 항목을 계산할 수 없으면 그 항목의 기존 사유를 기본 화면에 남긴다.
- 거래량 차트와 세부 수치·기간 정보는 **공통 [세부 흐름 보기] 하나** 아래로 모은다. 가격 흔들림·거래량마다 독립적인 펼침 버튼을 늘리지 않는다. 기존 가격 차트가 있으면 그 배치와 함께 전체 상세를 그려 보고 중복을 피한다.
- 설명은 묶음의 클릭형 ?로 제공한다. 뜻·계산 기준·해당하는 한계를 문단으로 나누며 기본 화면에는 긴 해설을 쓰지 않는다.
- 1440px·1000px 전체 화면에서 현재와 수정안을 비교한다. 정상과 일부 근거 미확인 사례를 포함한다. 개발자가 목업을 만들고 사용자 확인을 받는다.

## 3. 판단의 의미

- 세 관측을 같은 곳에서 읽게 하는 것은 승인한다. 요약 문장을 붙인다면 표시된 값·기존 라벨의 사실 관계만 조합한다. 새 LLM 호출이나 새 해석 API는 필요 없다.
- 이를 검증된 종합 위험 등급·미래 하락 확률·매매 의견으로 표시하지 않는다. P-06의 종합 위험 분류가 완료된 것으로 기록하지 않는다.
- 함께 보이는 값의 실제 기준일을 확인할 수 있어야 한다. 기준일이 다른 자료는 기존 경고를 보존하고 한 시점의 동시 관측처럼 묶어 설명하지 않는다.

## 4. PLAN 질문의 기술 방향

- **Q1 (a) 수용, 읽기 정의 개정:** 기존에 읽은 '종가가 유효한 저장 행'의 최근 최대 20개를 거래량 차트에도 쓴다. 가격 흐름·기존 거래량 네 칸과 같은 날짜 집합을 사용하는 범위다. 모든 원본 저장 행을 빠짐없이 보여 준다고 설명하지 않는다. 도움말의 기간 기준에 이 뜻을 포함한다. 거래량 결측은 제거하지 않고 날짜 자리를 유지하며 0과 구분한다. 별도 DB 읽기는 요구하지 않는다.
- **Q2 (a) 수용:** 막대 선택 → 날짜·거래량 한 줄, 키보드 좌우 이동 방식으로 진행한다. 20줄 표를 추가할 필요는 없다.
- **Q3 (a) 수용:** 기존 거래량 근거와 동일하게 실제 기준일·기존 안내를 붙여 과거 자료도 볼 수 있다. 현재 기준일 자료라는 인상을 주거나 다른 날짜의 근거와 동시점 결론으로 합치지 않는다.
- 위 세 가지는 기존 설계의 '원본 행' 표현 및 차트 세부 표시를 이번 판정으로 보충한 것이다. 기존 평균·배수 계산, 가격 흐름·변동성 산식은 바꾸지 않는다.

## 5. 진행

- PLAN의 화면 배치와 수용 기준을 이 판정에 맞추고 수정 목업을 보여 준다. 기술 방향은 위와 같이 확정했으므로 **수정 목업을 사용자가 확인하면 PLAN 재제출 없이 구현**한다. 실제 코드 충돌이 새로 확인된 경우에만 그 사실을 보고한다.
- 기존 근거 GET의 volume_trend 추가, 조회 재사용, 자료 보존·기존 값 불변과 필요한 표시 시험은 기존 PLAN을 따른다. 기본 표시·공통 펼침 관련 화면 시험만 새 배치에 맞춘다.
- 새 수집·판정 산식·DB 쓰기·의존성·OCI·PUSH 변경은 없다. 이 개정의 목적은 기존 근거와 새 차트를 사용자의 판단 흐름에 통합하는 것이다.
