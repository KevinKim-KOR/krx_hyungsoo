# POC5-25 PLAN 판정 — 현재 저장 종가의 고점 대비 근거 정정

작성: 2026-10-19 · 설계자 → 개발자 / 사용자

**판정: PASS. Q1 (a) · Q2 (a)를 수용한다. PLAN 재제출은 필요 없다.**

## 1. 범위 판단

폐기된 참고점수 스냅샷을 현재 수치처럼 보여 주던 문제와 같은 값을 쓰는 정렬을 한 범위에서 정정한다. 현재 판단 근거의 신뢰성을 바로잡는 작업이며, ML 학습·고도화나 ML 착수의 선행 관문은 아니다. 두 화면의 직접 소비처를 이번에 함께 정리하고 별도 문구 정정 단계로 나누지 않는다.

## 2. 질문 판정

- **Q1 (a)**: 종목 자신의 실제 기준일 D로 계산한다. 시장 저장 최신일과 다르면 기존 '수익률 끝일' 안내와 실제 계산 기간을 보인다. 현재 시장 최신값으로 오인시키지 않으며, 시장 최신일·다른 종목 날짜로 채우지 않는다. 이 판정으로 보유 근거의 날짜 가드나 동일 기간 KODEX200 비교 규칙을 완화하지 않는다.
- **Q2 (a)**: 「요즘 잘 오르는 ETF」 기존 기간 상자에 셋째 줄과 ?를 둔다. 공통 기간은 한 번만 보이고 다른 종목에만 기간을 덧붙인다. 「ETF 비교하기」는 기존 상세 칸에 기간·고점 날짜·종가를 둔다. 새 카드·별도 펼치기 버튼은 없다.

## 3. 구현안 수용과 경계

- D는 PLAN의 실제 가격 끝일 정의를 따른다. D를 포함한 최근 원본 20행을 별도로 읽는 안을 수용한다. 기존 읽기는 비정상 종가를 거르므로 이번 계약의 원본 창을 대신할 수 없다. 종목별 LIMIT 20 · 읽기 전용 연결 하나의 제한된 추가 조회를 허용한다.
- 20행 안의 비정상 종가를 빼고 과거 행으로 채우지 않는다. 기존 유효 가격·허용 자료원·가격 기준 연결 검사를 재사용한다. 원본 창, 최근 고점 중 가장 늦은 날짜, 계산값·단위·사유가 같은 객체에서 나온다.
- 새 stored_drawdown_20 선택 객체와 두 화면의 공통 helper를 수용한다. 옛 drawdown_20d의 의미와 연구 자료는 바꾸지 않으며, 새 객체가 없으면 옛 값으로 대체하지 않는다. 새 값의 단위는 %이므로 기존 비율 필드처럼 다시 100배 하지 않는다.
- 「ETF 비교하기」의 값 없음은 양방향 모두 맨 뒤, 동률은 기존 순서다. 현재 오름차순에서 값 없음이 앞서는 문제는 이번에 함께 고친다. 기본 후보 선정·수익률 정렬은 유지한다.
- 조사상 복사문·AI 전달에 고점 대비 소비처가 없으므로 해당 경로 변경은 0이다. POC5-23~24에 항목을 새로 넣거나 과거 기록을 다시 쓰지 않는다.
- 정렬 helper 분리와 글자 단위 줄바꿈 방지 CSS를 수용한다. 화면 전체 리팩터·새 숫자 표시 체계·다른 고점 지표 변경으로 넓히지 않는다.

## 4. 진행과 종료

- 제출 PLAN에는 사용자 목업 확인이 아직 '대기'다. 설계자는 맥북의 로컬 목업을 직접 보지 않았다. **사용자 전체 화면 목업 확인을 기록한 뒤 바로 구현한다. 이미 확인받았다면 그 기록만 반영하고 다시 묻지 않는다.** Q1·Q2가 목업의 권장안과 같으므로 이 판정 때문에 목업을 다시 만들 필요는 없다.
- PLAN의 핵심 계산·결측·정렬·기존 호출 보존 시험과 기존 검증 절차를 수행한다. 사용자 실화면·검증자 확인 뒤 RESULT를 제출한다.
- 별첨 백로그 정리는 문서 반영 지시다. POC5-25 구현의 새 선행 감사·별도 PLAN·추가 검증 라운드로 만들지 않는다. 다음 자연스러운 문서 변경에 함께 반영할 수 있다.
- 이번 판정은 새 커밋·push·파일 삭제 승인을 부여하지 않는다. 사용자께서 이미 승인한 동일 범위가 있다면 그 승인은 존중한다. OCI pull·거래일 대기·별도 인계 문서는 없다.
- ML 고도화의 목표·검증·종료 기준 설계는 이 정정 및 기존 운영 점검과 병행할 수 있다. 운영 ML 승인과 Q6 계약은 별도 판단이며 현재 상태를 바꾸지 않는다.
