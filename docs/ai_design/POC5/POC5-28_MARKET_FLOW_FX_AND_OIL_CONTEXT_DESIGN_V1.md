## 1. 사용자 요구와 판단 범위

사용자는 코스피 상승기부터 외국인의 순매도가 이어지고 개인이 순매수하는 흐름, 이후 지수 하락에도 매도가 지속되는 상황을 보고 '누적 수급이 시장을 압박하는지'를 확인하고 싶다고 설명했다. 환율·유가도 개별 최신값이 아니라 같은 시기의 흐름과 연결해 읽기를 원한다.

따라서 원안의 '원/달러·WTI 두 값 추가'로 끝내지 않는다. 이번 범위는 **코스피 현물 투자자 수급 + 기존 코스피 + 원/달러 + WTI의 기간 관측과 조건부 해석**이다. 유가를 제외하거나 원인 판정을 자동 확정하지 않는다.

- 외국인 순매도액은 주식 매매 통계다. 같은 금액이 환전·해외 송금됐다고 계산하지 않는다. 채권·예금 등 국내 잔류 가능성과 실제 대외 자금 이동은 별도다.
- 외국인 순매도에서 개인 순매수를 뺀 값을 '수급 부족액'으로 만들지 않는다. 기관·기타법인 등 다른 거래 주체가 있다. '현재 가격에서 매도 압력을 받아내는 매수세가 약하다'는 설명은 검토할 가설이다.
- 실적 호조·리밸런싱·자사주 매입 종료·해외 송금 등은 수급 숫자만으로 확정하지 않는다. 실제 기업 실적·공시·펀드 구성·대외 통계가 필요한 설명은 '추가 확인'으로 둔다.
- Q6 운영 계약 OPEN, ML 운영 미승인, 기존 선정·경보·PUSH 기준은 유지한다. 새로운 종합 점수·위험 등급·매매 신호를 만들지 않는다.

## 2. 자료와 수집 범위

| 자료 | 우선 경로와 의미 | 이번 처리 |
|---|---|---|
| 코스피 | 기존 저장 지수·날짜 | 재사용. 새 지수 대체 없음 |
| 투자자 수급 | KRX 코스피 현물 투자자별 매수·매도·순매수 | 외국인·기관·개인·기타법인 등 원천 분류를 보존. 기관 합계와 기관 세부를 중복 합산하지 않음 |
| 시장 거래대금 | 위 수급과 같은 시장·범위의 거래대금 | 수급 규모의 분모. 매수·매도 양쪽 합을 거래대금으로 쓰지 않음 |
| 원/달러 | 기존 설치 FDR의 지원 경로 우선 | 1달러당 원화. 실제 공급자·기준 시각·일별 행의 완료 여부를 PLAN에 고정 |
| WTI | 기존 설치 FDR의 CL=F 지원 경로 우선 | USD/배럴 선물 계열. 현물·공식 정산가로 표기하지 않음 |
| 미국 시장·VIX | 기존 확보한 자료가 해당 기간을 지원할 때만 | 조건부 해석의 보조 근거. 이번에 새 세계시장 수집망을 만들지 않음 |

KRX 웹 통계 제공과 프로젝트에서의 자동 조회 가능성은 구분한다. 현재 KRX 승인 API가 투자자별 통계를 제공한다고 가정하지 않는다. 개발자는 **정확한 제공 경로·이용 조건·인증 필요·일별 확정 시점**을 짧은 PLAN에서 확인한다. 외국인에 기타외국인을 포함하는지 등 분류도 원천 정의대로 고정한다. 코스닥·ETF·선물 수급을 코스피 현물 합계에 섞지 않는다.

신규 조회 대상은 위 시장 총괄 통계와 원/달러·WTI다. 전 종목 투자자별 자료·실시간 호가·선물 포지션·뉴스 자동 수집은 이번 범위에 넣지 않는다. CNN·뉴스는 조건부 그대로이며 보유 평가는 기존 PC 기능을 유지한다. 개인 보유 값은 외부 조회 인자·공통 시장 자료·OCI·원장·ML 입력으로 보내지 않는다.

과거 자료는 **연초부터 현재까지 + 연초 이전 60 한국 거래일의 계산 준비 구간**을 우선 확보한다. 원안의 최근 90일 제한은 적용하지 않는다. 올해 흐름을 보기에 부족하기 때문이다. 그 이전 수년 자료를 모두 받거나 원천별 자동 대체 체계를 만들지는 않는다. 제공이 제한되면 실제 지원 시작일을 보이고 부분 기간으로 연초 누적을 위장하지 않는다.

## 3. 기간·날짜·계산

- 기간 선택은 전체 묶음에 하나다. 기본 6개월, 1개월·3개월·6개월·연초 이후를 제공한다. 끝일 D는 코스피 지수와 코스피 일별 수급이 함께 확인된 가장 최근 완료 거래일이다. 일부가 늦으면 D와 각 자료의 최신일을 구분한다.
- 투자자별 누적 순매수는 선택 기간의 실제 순매수 합이다. 시작일에 모든 선을 0으로 두고 이후 누적한다. 순매도는 음수다. 누락일은 0으로 채우지 않는다. 결측이 있으면 완전한 기간 합계 대신 '부분 집계'와 확보 일수를 보인다.
- 장기 누적과 별개로 **최근 20거래일·직전 20거래일**, 최근 60거래일의 순매수 합을 계산한다. 필요한 구간이 온전할 때만 표시한다. 20일·60일은 관찰 창이며 투자 예측에 최적화된 값이라고 주장하지 않는다.
- 매도 강도는 두 20일 구간의 순매수 합·일평균을 나란히 보여 준다. 둘 다 순매도일 때 감소/증가를 비교하고, 부호가 바뀌면 순매수/순매도 전환으로 적는다. 아직 큰 누적 순매도라도 최근 매도 강도가 줄어드는 상황을 구분한다.
- 규모 보조값은 같은 구간의 외국인 순매수 합 / 시장 거래대금 합 × 100이다. 음수는 순매도다. 거래대금이 없거나 범위가 다르거나 분모가 0이면 계산하지 않는다. 임의 임계치로 강매도 등급을 붙이지 않는다.
- 코스피·환율·유가 차트는 같은 표시 기간과 가로축을 사용한다. 세로축 단위는 각각 지수·원/달러·USD/배럴이며, 수급은 조원 또는 억원으로 명시한다. 모두 한 이중축 차트에 억지로 겹치지 않는다.
- **같은 날짜 라벨이 같은 관측 시각을 뜻하지 않는다.** 환율·WTI의 실제 관측 날짜/시간대·완료 여부를 보존하고 한국 15:30 값으로 둔갑시키지 않는다. 진행 중 행은 제외한다. 완료 여부 확인 수단이 없을 때 원안의 보수적인 UTC 날짜 제외 방식은 가능하나 실제 지연을 설명한다.
- 기간 변화율은 실제 사용한 시작·끝 날짜를 함께 적는다. 요청한 기간 경계에 가격이 없으면 실제 계산 구간을 밝히고, 같은 시각의 비교라고 쓰지 않는다. 날짜를 바꿔 채우거나 없는 날을 보간하지 않는다. 공급자의 날짜 의미를 확인할 수 없다면 그 자료원 확정을 멈춘다.
- 최초 수집분·정정된 과거 수치를 당시 이미 알았던 정보로 ML에 넣지 않는다. 수집 시각·출처를 남기되 이번에 별도의 과거 버전 원장이나 ML 파이프라인을 만들지 않는다.

### 3-1. 단기 큰 변화 관측 — 장기 추세와 독립적으로 계산

코스피·원/달러·WTI는 **직전 대비 변화와 5개 관측 간격의 변화**를 기본 요약에 함께 제공한다. 5개 간격은 최신 값과 그 5개 관측 전 값의 차이로, 완료된 값 6개가 필요하다. 여기서 관측은 완료된 일별 자료이며 실제 사용한 양 끝 날짜를 보인다. 장기 약세 속 단기 급반등·장기 안정 속 단기 급락도 같은 방식으로 계산한다.

| 관측 | 고정 계산·표시 기준 |
|---|---|
| 단기 변화 확대 | 최신 값과 직전 값의 차이를 Δ라 한다. 그 이전 20개 변화량의 절댓값 평균을 M이라 한다. M>0이고 절댓값(Δ)/M≥3이면 '최근 변화 확대'와 실제 변화량·비율을 표시한다. 기준 20개에는 현재 변화를 넣지 않는다. 두 계산에 원본 일별 값 22개가 필요하다. 3배는 이번 화면의 관측 표시 기준이며 검증된 위험·수익 임계치가 아니다. |
| 최근 범위 이탈 | 최신 값이 그 이전 20개 일별 값의 최댓값보다 높거나 최솟값보다 낮으면 '직전 20개 관측 범위 위/아래'를 표시한다. 같은 값은 이탈이 아니다. 이전 범위의 실제 상·하한과 날짜도 전달한다. 이를 검증된 기술적 박스권·추세 전환으로 명명하지 않는다. |
| 수급의 단기 확대 | 외국인·기관의 당일 순매수 금액 절댓값을 이전 20거래일 순매수 금액 절댓값 평균과 비교한다. 3배 이상이면 방향에 따라 '순매수/순매도 규모 확대'와 금액·비율을 표시한다. 순매수의 전일 대비 차이로 바꾸지 않는다. 누적 수급·거래대금 대비 값과 함께 읽는다. |

- 위 조건이 없어도 직전 대비·최근 5개 관측 변화는 보인다. 조건 미해당을 '안정·안전'으로 표시하지 않는다. 최신 관측만 보지 않고 **최근 5개 관측에서 발생한 확대·범위 이탈**을 날짜별로 전달한다. 오래된 확대가 누적액에 묻히거나 다음 관측에서 사라지지 않게 하며, 별도 사건 DB는 만들지 않는다.
- 평균 M이 0이면 배수를 계산하지 않는다. 현재 변화가 0이 아니면 '직전 20회 변화 0, 이번 관측에서 변화 발생'과 실제 차이를 표시한다. 수급 평균이 0일 때는 '직전 20거래일 순매수 0'으로 구분한다. 각 판정에 필요한 기준 자료가 모자라면 직전 변화는 보여도 비교 판정은 '비교 자료 부족'이다. 결측·비정상 원본·확인된 가격 기준 변경을 건너뛰어 정상 창을 만들지 않는다.
- 가격 차이는 각 자료의 본래 단위로 계산한다. 변화율도 함께 제공할 수 있으나 직전 값이 0 이하이면 변화율은 비운다. 가격 차이 기반 비교는 가능한 경우 유지한다. WTI의 음수·0 가격을 일괄 손상으로 처리하지 않는다. 선물 계열의 만기 교체도 변화에 영향을 줄 수 있음을 기존 도움말에 적는다.
- **단기 요약은 자료원마다 확보한 최신 완료 관측 E를 사용한다.** 장기 묶음의 공통 끝일 D나 화면의 6개월 선택 때문에 더 최신인 환율·유가의 큰 변화가 잘리면 안 된다. 각 결과에 E·자료 수집 시각·실제 계산 기간을 표시하고 장기 요약의 D와 구분한다. 오래된 값에 '오늘 급변'이라고 쓰지 않는다.
- 이 단계는 PC 시장 갱신 뒤 저장된 일별 자료로 관측한다. **장중 실시간 급변이나 하루 중 튀었다가 되돌아온 움직임까지 감지하는 기능은 아니다.** 이를 보장하려면 장중 자료 수집 계약이 추가로 필요하다. 기존 보유·대표 종목의 장중 급등락 알림 경로는 유지하며, 이번에 전 종목·환율·원유의 실시간 감시로 확장하지 않는다.

## 4. 화면과 읽는 순서

기존 시장 정보 영역에 **기간 요약·현재 단기 변화 → 함께 보는 흐름 → 짧은 해석 근거** 순서로 통합한다. 새 메뉴를 만들거나 지표마다 별도 펼치기를 추가하지 않는다. 「오늘의 투자 점검」에는 장기 요약과 해당하는 단기 변화의 짧은 줄, 「요즘 잘 오르는 ETF」의 기존 시장 정보 영역에는 전체 흐름을 둔다. 기존 시장 상세의 배치 조정은 가능하다.

1. **기간 요약**: 선택 기간, 코스피 변화, 외국인·개인 등의 누적 순매수, 최근 20일 수급을 함께 읽는다. 각 수치는 실제 데이터에서 계산한다. '올해 150조' 같은 기사 숫자를 상수로 넣지 않는다.
2. **기간을 공유하는 차트**: 위에 코스피, 아래에 투자자별 누적 수급과 환율·WTI 흐름을 정렬한다. 작은 화면에서도 날짜 눈금·단위·기준선·범례가 보여야 한다. 과거의 축 없는 흐름 그림을 반복하지 않는다. 세부 일자 값은 선택 시 읽는다.
3. **요약 문장**: '기간 누적 순매도 / 최근 20일도 순매도 / 직전 20일보다 일평균 매도 감소'처럼 계산으로 확인한 사실을 먼저 쓴다. 한 줄에 과밀하게 몰지 않고 의미 단위로 줄을 나눈다.
4. **해석과 반대 근거**: 현재 조합에 해당하는 짧은 설명만 보인다. 긴 계산 정의는 클릭 ?에 둔다. 현재 자료 누락·부분 집계·지연은 기본 화면에 남긴다.

단기 확대·범위 이탈이 해당하면 같은 요약 영역에서 확인되게 한다. 예: 'WTI 최근 변화 확대 · 직전 대비 +○달러 · 이전 20회 평균 변화의 ○배 · 기준일 ○일'. 이는 형식 예시이며 실제 수치를 계산해 채운다. 장기 방향과 단기 방향이 다르면 둘 다 적는다. 차트에는 해당 관측 위치와 실제 값을 확인할 수 있게 하고, 장기 기간을 바꾸더라도 현재 단기 요약의 의미를 유지한다.

해석은 다음처럼 **가능성과 추가 확인 사항**으로 작성한다. 아래는 규칙을 설명하는 예시이며 현재 시장 판정이나 검증된 예측 규칙이 아니다.

| 관측 조합 | 제시할 수 있는 해석 | 함께 남길 다른 설명 / 한계 |
|---|---|---|
| 코스피 하락·외국인 순매도·원/달러 상승 | 주식 매도와 원화 약세가 동반 | 환율 때문에 매도했는지, 매도가 환율에 영향을 줬는지는 이 자료만으로 구분 불가 |
| 코스피 하락·외국인 순매도·원/달러 하락 | 주식 수급 압박과 원화 강세가 동시에 관측 | 원화 강세가 외국인 주식자금 유입을 뜻하지 않음. 달러 공급·다른 자금 이동 가능 |
| 유가 하락·기존 글로벌 시장 근거도 약세 | 수요 둔화 가능성 검토 | 공급 확대·공급 차질 완화도 유가를 낮출 수 있음. 원인 확정 불가 |
| 유가 하락·글로벌 시장은 견조 | 비용 부담 완화 가능성 검토 | 업종별 영향이 다르고 공급 원인은 별도 확인 필요 |

반도체 업황·실적을 자동으로 평가하는 기능은 추가하지 않는다. '실적이 좋은데도 하락'이라는 사용자의 질문은 AI 검토문에 별도 질문으로 넘길 수 있다. 확인하지 않은 실적 호조를 시스템의 사실 문장에 넣지 않는다.

기존 AI 복사문과 POC5-23 시장 근거 묶음에 **동일한 기간·수치·관찰·현재 단기 변화·최근 5개 관측 발생 내역·조건부 설명·자료 한계**를 담는다. POC5-24 세션 전달을 그대로 사용한다. 새 LLM 자동 호출은 없다. 숫자만 나열한 뒤 사용자가 다시 조합해야 하는 상태로 끝내지 않는다.

## 5. 수집·실패·변경 경계

- PC의 기존 시장 갱신 작업에 연결한다. GET·차트 기간 변경·복사·미리보기 생성 때 외부 조회하지 않는다. 기간 변경은 확보된 자료를 재사용한다.
- 기존 시장 DB와 저장·실패 기록·timeout을 우선 재사용한다. ETF 가격 표에 가짜 ETF를 넣지 않는다. 적절한 저장 자리가 없으면 같은 DB의 최소 표 구조를 PLAN에 적는다. 새 DB·수집 플랫폼·큐·cron은 만들지 않는다.
- 자료원별 성공분과 이전 값은 보존한다. 실패·결측을 0으로 바꾸지 않는다. 반복 실패의 우회용 비공개 API·자동 다중 원천·자동 로그인은 넣지 않는다. 기존 요청 제한의 한계를 전체 종료 보장으로 과장하지 않는다.
- 원래 #48에 적힌 OCI runtime 빌더가 현행 운영에서 쓰이는지는 한 번 조사해 기록한다. 이 단계는 PC 시장 판단 근거를 위한 것이며 OCI 알림 본문·러너·선정 기준·원장·PARAM은 바꾸지 않는다. OCI pull·새 발송은 없다.
- 한국은행의 외국인 증권자금 유출입 등 월별 자료는 실제 대외 이동을 확인할 별도 근거로 안내할 수 있다. 이번에 의무 수집원을 추가하거나 KRX 매매 통계와 같은 단위·범위인 양 합산하지 않는다.

## 6. 개발자 짧은 PLAN·목업·검증

PLAN은 다음 다섯 사실만 확인한다. 저장소 전체 재감사 단계는 만들지 않는다.

1. KRX 투자자별 통계의 실제 접근 가능 경로·권한·시장/분류 정의·확정 시각·올해 자료 확보 범위. 자동 연결 불가라면 그 사실과 최소 대안을 먼저 질문한다. 빈 수급 칸을 만든 뒤 완료 처리하지 않는다.
2. 설치된 FDR의 환율·WTI 실제 공급자·심볼·단위·날짜/시간대·완료된 행을 고르는 방법. 새 설치나 유료 계약을 조용히 추가하지 않는다.
3. 기존 DB·수집 작업·응답·AI 전달의 재사용 경계, 필요한 최소 저장 구조와 파일. 필요한 책임 분리는 이번 변경 안에서 한다.
4. 실제 자료로 구할 수 있는 연초 누적·6개월·20/60일 창과 결측 사례. 원안의 90일 자료를 억지로 연초 누적으로 계산하지 않는다.
5. 관련 검증 계획. 합계/중복 집계·누적 시작점·결측일·20일 창·기준일 차이·진행 중 값·값/단위/기간 전달 일치·개인값 경계를 확인한다. 단기 관측은 현재 값의 기준 창 혼입 방지·3배 경계·범위 상/하향 이탈·동률·평균 0·자료 부족·최근 발생 내역·D보다 최신인 E 보존·장기와 단기 방향 반대를 추가 확인한다.

개발자가 전체 화면 1440/1000px 목업을 만든다. 기본 화면에서 장기 누적과 단기 변화가 함께 읽혀야 한다. 잔잔한 흐름 뒤 큰 상승/하락·장기 약세 속 단기 반등·수급의 하루 확대·자료가 오래된 사례를 격리 fixture로 포함한다. 사용자 목업 확인·PLAN 판정 뒤 구현한다. 이번 사용자 설명은 이 통합 범위 설계의 근거이며, 구현 방식·실제 외부 조회 경로는 PLAN에서 구체화한다.

과거 확보 자료와 격리 사례로 계산·문구를 검증하고 실제 PC 화면과 AI 전달문을 확인한다. 검증자·RESULT 판정 뒤 기존 승인 범위에서 커밋·push한다. 다음 거래일·미래 하락 적중·새 PUSH·공식 R0를 종료 조건으로 삼지 않는다. 인과관계 규명이나 매매 수익 개선을 이 기능의 완료 조건으로 만들지 않는다.

#48 기록은 '시장 수급·환율·WTI의 PC 기간 근거 연결 범위'로 정확히 구분한다. CNN·뉴스·OCI 알림 확대까지 완료로 기록하지 않는다. 후속 ML 설계에서는 이 흐름을 후보 근거로 검토할 수 있지만, 이번 구현이 ML 설계 착수의 선행 게이트는 아니다.
