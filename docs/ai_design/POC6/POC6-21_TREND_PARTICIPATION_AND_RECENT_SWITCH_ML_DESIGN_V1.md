## 1. 출발 상태·이번 단일 목표

최신 사용자·개발자 보고에 따라 POC6-20은 `83e5c8fb` push 완료·`IMPLEMENTED_VERIFIED_CLOSED`로 인수한다. 시장 정보 추가 효용은 관측됐으나 NOT_CANDIDATE·UNCERTAIN·운영 미채택이다. 고정 연구를 다시 열지 않는다. 설계자가 현재 저장소·원격·연구 사본을 직접 검사한 보고는 아니다.

사용자가 원하는 것은 **상승 일부를 확인하고 진입해 추세에 참여하며, 고점 수익 일부를 반납하더라도 보유 근거가 약해지면 이탈하는 것**이다. 짧은 기간 안의 재진입·재이탈은 이전 행동을 뒤집는 만큼 더 강한 근거를 요구하고, 직전 거래의 수익·손실과 반복 매매 전체의 결과를 평가한다.

**이번 단일 목표: 절대 가격변화 추정 ML과 최근 거래 후 강화 기준을 결합했을 때, 동일한 단순 추세 점수 운용보다 비용 후 성과를 개선하면서 반복 매매 부담을 줄이는지 검증한다.**

POC6-20의 ETF 간 상대순위 목표에서, 이번에는 **보유와 현금 사이의 전환을 돕는 과제**로 바꾼다. 새 과제의 근거는 최신 사용자 결정이다. 입력·모델 이름·시험기간만 바꾸는 반복이나 D20 오차 연구의 재개가 아니다. 무릎·어깨를 사후 최저점·최고점의 일정 비율로 정의하지 않는다.

## 2. 비교 구조 — 같은 과제에서 두 효과를 분리

| 곡선 | 판단 점수 | 최근 거래 후 강화 |
|---|---|---|
| R0 | 단순 추세 점수 | 없음 |
| R1 | 같은 단순 추세 점수 | 적용 |
| M0 | 절대 가격변화 추정 ML | 없음 |
| M1 · 주 평가 대상 | 같은 ML의 동일 예측 | 적용 |
| K | KODEX200(069500) 보유 | 해당 없음 |

주 비교는 M1−R1로 ML의 추가 효용을 본다. M1−M0와 R1−R0로 최근 거래 후 강화의 효과를 별도로 본다. 같은 ML을 정책별로 다시 학습하지 않는다. 강화 기준만으로 개선된 것을 ML 효과라고 쓰지 않는다.

H1의 **상위 10위 이탈·SMA60 신규 필터·검토 4회 재진입 대기는 이번 연구에 적용하지 않는다.** 이번에는 단일 점수의 진입·유지·이탈 경계를 검증하기 때문이다. 이를 기존 연구 결함 정정이나 운영 규칙 변경으로 기록하지 않는다. 다른 이름의 보조 필터로 되살리지 않는다.

통상 이탈 대상이 여러 개면 점수가 가장 낮은 종목을 우선하고 동점은 종목코드 순이다. 최초 다종 편입 예외는 전량 청산 뒤 되살리지 않는다. 같은 종목의 중복 보유·동일 실행일 매수와 매도·진행 중 계획의 중복을 만들지 않는다. 보호청산과 통상 이탈이 겹치면 한 건이며 보호 사유를 남기고 중복 계획을 취소한다. 미체결·취소된 의도를 거래 이력으로 세지 않는다. 매매 불가·보유 평가 불확정은 기존 CHECK_REQUIRED 계약을 적용하며, 빈 가격으로 체결·가상 정산하지 않는다.

## 4. 점수와 학습 — 확률·바닥·천장 추정이 아님

- **R 점수:** `log(C(D) / C(D−60))`. D−60은 한국 시장의 60거래일 전이다. 과거 60거래일 추세를 나타내는 단순 기준이며 미래 수익 예측으로 검증됐다는 뜻은 아니다.
- **M 학습 목표:** `log(C(E의 60번째 거래일) / O(E))`. E는 D 뒤 두 번째 한국 거래일이고 E를 첫 번째로 센다. 해당 종목의 절대 가격변화이며, K 상대성과·ETF별 순위·확률로 변환하지 않는다. 미래 값은 학습 정답과 사후평가에만 쓴다.
- **M 입력:** POC6-20의 가격·거래량 30열과 시장 4열을 정의·순서·이용 시각까지 그대로 재사용한다. 개인 평단·실거래 손익은 넣지 않는다. 새 열·자료원·기간 조합 탐색은 없다.
- **M 모델:** 기존 CPU LightGBM ML_B의 고정 회귀 설정·학습 가중치·seed·분기 재학습을 재사용한다. 이번 정답을 단면 순위로 중심화하지 않는다. 새 모델 경쟁·하이퍼파라미터 탐색 없음. 필수 예측이 비유한 값이거나 생성에 실패하면 CHECK_REQUIRED이며, 이를 정상 유지 판단이나 0점으로 대체하지 않는다.
- **학습 시점:** 기존 5년 창·정답 종료 5거래일 여유·최소 104주/5,000행을 이번 비교의 고정 계약으로 재사용한다. 모든 학습 정답은 해당 분기 마감 전에 성숙해야 한다. 필수 분기 요건 미충족은 DATA_SHORT이며 기준을 줄여 진행하지 않는다. 이 요건을 ML 일반 최소 길이라고 설명하지 않는다.

60거래일은 수주~수개월 목적에 맞춘 **이번 연구의 평가 길이**다. 의무 보유기간·사용자 확정 숫자·최적 기간이 아니다. 단순 점수와 ML 모두 동일한 행동 계약으로 평가하며, ML 오차 개선만으로 투자 효용을 판정하지 않는다.

## 5. 최근 재진입·재이탈은 기준을 강화

일반 전환 기준 `h = log((1+0.002)/(1−0.002))`로 둔다. 편도 20bp의 왕복 비용에 해당하는 로그 변화폭이며 약 0.40%다. 강화 기준은 `2h`다. 두 비용 장부 모두 이 기준을 고정하고, 40bp에서 유리하도록 다시 조정하지 않는다.

| 판단 | R0·M0 / R1·M1의 일반 상황 | R1·M1의 최근 거래 상황 |
|---|---|---|
| 진입·재진입 | 점수 ≥ +h | 같은 종목의 직전 전량 매도 체결 뒤 0~10거래일이면 점수 ≥ +2h |
| 통상 이탈·재이탈 | 점수 ≤ −h | 현재 보유의 진입 체결 뒤 0~10거래일이면 점수 ≤ −2h |
| 경계 사이 | 현재 보유/현금 상태 유지 | 넓어진 경계 사이에서도 상태 유지 |
| 보호청산 | 기존 보호 기준 적용 | 강화 기준·기간에 관계없이 동일 적용 |

10거래일은 두 차례 정도의 주간 검토가 걸리는 최근 구간으로 설계자가 정한 이번 가설이다. 2배 역시 비교할 단일 강화안이며 최적값 주장이 아니다. 기간·배수를 그리드로 돌리지 않는다. 거래일 수는 **판단일 D까지 실제로 완료된 체결**에서 한국 시장 달력으로 센다. 보호청산 뒤 재진입도 같은 강화 대상이다. 거래가 없거나 최근 구간을 벗어나면 일반 기준이다.

이 방식은 막 샀다는 이유만으로 작은 반대 신호에 다시 팔거나, 막 팔았다는 이유만으로 작은 회복에 다시 사는 것을 줄이려는 가설이다. 반대로 손실을 오래 보유하거나 급반등 복귀를 늦출 위험도 있다. 보호청산 예외와 아래 성과 비교로 그 대가를 함께 평가한다.

### 직전 수익·손실과 반복 거래 평가

이번 손익은 **각 모의 장부의 비용 차감 손익**이다. 시스템 전에 산 사용자 보유나 개인 거래 손익을 모델 성과에 섞지 않는다.

1. 재진입은 직전 완료 거래의 순손익을 이익/손실/0/이력 없음으로 구분한다. 재이탈은 판단 당시 평가손익과 실제 청산 후 순손익을 나란히 남긴다. 당시 미확정 손익을 실현손익으로 부르지 않는다.
2. 직전 매도가→재진입가 변화, 보유 중 최고 평가이익과 청산까지의 반납, 체결 간 거래일 수·비용·보호/통상 사유를 기록한다. 이전 매도가보다 비싸게 샀다는 사실만으로 실패라고 판정하지 않는다.
3. 같은 종목의 완료 거래들을 **직전 이탈→다음 진입 간격이 10거래일 이내일 때 연결한 묶음**으로도 집계한다. 묶음 순손익은 같은 연구 장부의 현금흐름으로 계산하고 모든 비용을 포함한다. 개별 거래 수익률을 단순 합산하지 않는다. 열려 있는 마지막 거래는 별도 표시한다.
4. 직전 손익별 거래 수·서로 다른 발생 날짜 수·순손익·반복 전환 비용을 공개한다. 미완료·말단 평가기간 부족을 임의 제외해 성공률을 만들지 않는다. 개별 거래 승률과 포트폴리오 성과를 구분한다.

손익별 분석은 사전 고정된 평가 축이다. **이익을 냈으니 재진입에 관대하거나, 손실을 봤으니 본전 회복을 목표로 하는 규칙은 만들지 않는다.** 이익/손실에 따라 배수를 달리하는 효과는 아직 근거가 없으므로 이번에는 공통 강화 기준을 검증한다. 그룹별 결과를 본 뒤 차등 임계를 추가하지 않는다.

## 6. 자료·기간·실행 경계

봉인 가격·시점별 집합, POC6-19 수급 성공 사본 `20261103T171931Z_b0ea4fcf`, 낮 Yahoo 근거 `20261103T044323Z_92947186`를 그대로 사용한다. 수급 PARTIAL 4일, 기관계 중복 해석, WTI 제외·음수·공백, 실제 과거 공개시각 미확인 한계를 유지한다. 시장 정보 이용 시각과 4열 완전성·공통 주간 신호일은 POC6-20 계약 그대로다.

추가 정보 미정의 주에는 R/M 네 곡선 모두 새 통상 진입·이탈을 만들지 않는다. 기존 보유 평가·일별 보호 처리는 계속한다. 판단 시점 자격을 미래 정답의 존재로 줄이지 않는다. 현재 ML 학습에 못 쓰는 미래 미성숙 행과, 당시 판단 가능한 종목을 구분한다.

- 2018~2020은 고정 계약의 유효성 재생이며 성과로 설정을 고르지 않는다. 필수 장부가 불확정이면 주 평가를 시작하지 않는다.
- 주 평가는 2021-01-04~2026-09-21, 보조는 2021~2022/2023~2024/2025~종료다. 공통 첫 실행일은 PLAN에서 확정하며 K를 M의 실제 첫 매수에 맞추지 않는다.
- 이미 본 가격 기간의 **새 과제에 대한 탐색적 회고 연구**다. 처음 보는 독립 시험이나 이번 10~11월 급락 검증으로 부르지 않는다. 종료일 연장·유리한 최근 장세 삽입은 없다.
- 공식 실행 1회, 분기별 M 1개·예상 최대 35 fit, CPU 4스레드·90분·RSS 8GiB 상한. R은 학습하지 않으며 정책·비용별 재학습 없음. 분모와 실제 최대 fit은 성과 없이 PLAN에서 대조한다.
- 보고 생성·후처리까지 계산을 마친 뒤 최종 예산을 한 곳에서 판정한다. 초과·자료 부족·실행 실패를 낮은 성과와 구분하고 원본을 보존한다. 코드 결함 정정 외 성과를 이유로 재실행하지 않는다.

|---|---|
| ML 추가 효용 관측 | 20bp CAGR(M1)−CAGR(R1) ≥ 연 1.0%p, 보조 3구간 중 2개 이상에서 M1 > R1 |
| 최근 강화 효용 관측 | 20bp에서 M1의 연환산 회전율 < M0이고 CAGR(M1) ≥ CAGR(M0), 40bp에서도 CAGR(M1) ≥ CAGR(M0). R1−R0도 모두 공개 |
| 목적·위험·부담 | 20bp M1 > K, M1 MDD가 R1·K보다 각각 5%p 넘게 나쁘지 않음, 연환산 회전율 M1 ≤ 6 |
| 높은 비용 확인 | 40bp M1 > R1·K. 비용별 순위·장부·강화 효과를 생략하지 않음 |
| 불확실성 | 평가 완전 주 전체의 M1−R1 주간 수익률 차이, 기존 13주 원형 블록·2,000회·seed 20261026로 평균 차이 95% 구간. 0 포함이면 UNCERTAIN |

위 숫자는 이번 설계의 고정 비교 기준이다. 결과를 보고 변경하지 않는다. 경제적 네 축을 모두 충족해야 제한된 후속 검토 후보로 남긴다. 신뢰구간·이미 본 기간·그룹별 표본 한계는 후보 여부와 함께 표시하고, 후보라도 운영 채택·총수익 검증은 NO다. 최근 사건이 없어 강화 효과를 비교할 수 없으면 해당 축은 판단 불가로 남긴다. 작은 손익 하위그룹으로 일반적인 효과를 단정하지 않는다.

**AC:**

1. 성과 전에 입력 판·코드·환경·점수/목표·기준·시각·모집단·학습/평가·예산을 고정한다. 정보 시점 이후 자료를 바꿔도 과거 판단 입력과 그때의 학습이 바뀌지 않는다.
2. 네 곡선은 동일한 후보 순서·가용일·체결·비용·보호 조건을 쓰고, 점수 종류/최근 강화만 정한 대로 다르다. 강화 판단은 완료 체결·당시 정보만 사용한다.
3. 진입·일반 이탈·단기 재진입·단기 재이탈·보호청산이 분리되며, 직전 손익별·반복 묶음별 결과와 적용/제외/미확정 분모를 재계산할 수 있다.
4. 모든 곡선의 기간별 성과·낙폭·회복·연환산 회전율·보유기간·현금·거래/비용·말단 미완료를 공개한다. 회복은 직전 최고 평가자산을 밑도는 연속 한국 거래일 수의 최장값으로 보고 말단 미회복을 별도 표시한다. 회전율과 거래 횟수를 혼동하지 않는다. 개별 체결 사례를 전체 성과의 인과 설명으로 단정하지 않는다.
5. 저장 예측에서 정책·장부·비교·판정을 다시 계산하고, 검증자 확인 뒤 설계자 RESULT를 판정한다. 구현 완료·ML 효용·강화 효용·후속 후보·운영 채택을 분리한다.

## 8. 변경 범위·보류 위험·다음 게이트

기존 H1·POC6-19·20 코드/잠금/모델/장부는 수정하지 않고, reader·가격 30열·시장 4열·학습/보호/체결/검산의 직접 계약을 재사용하는 별도 연구 범위로 둔다. 출력은 `state/ml/research/poc6_21/`의 PC 연구 산출물이다. 새 플랫폼·거래 엔진·설치·DB·외부 조회·OCI·PUSH·06 전향 모델·UI·자동 주문은 없다.

**단계 한정 예외:** POC6-21에서만 위 입력으로 절대 가격변화 학습과 독립 모의 운용 비교를 허용한다. 이 문장은 기술 설계 범위이며 실행 승인이 아니다. 기존 기반 문서의 ML 연구 제한은 해당 단계 예외 기록에만 추가하고, Q6 OPEN·운영 ML 미승격·#3/#55/#57/#62 미완료는 유지한다.

부분축소·비중 조절, 개인 실거래 손익을 쓰는 맞춤 학습, PC 권고·화면/운영 연결은 **BACKLOG 후보**로 분리한다. 보류 사유는 이번 단일 효용 검증을 넘어서는 기능 확장이다. 보류 위험은 실제 계좌·부분매매·실사용에 대한 효용 미확인이다. 재검토 트리거는 이번 결과로 제한된 후속 후보가 생기고 별도 적용 범위가 정해지는 경우다. 이번에 정식 등록·구현까지 묶지 않는다.

설계 검토 통과 후 PLAN은 지정된 reader·학습·정책의 직접 접점, 새로운 목표의 학습/평가 분모, 최소 변경·환경·자원, 기존 승인에서 부족한 범위만 확인한다. 전 저장소 재조사·기존 완료 연구 재실행·성과 사전 열람은 필요 없다. 실제 자료 의미·시점·단일 가설과 충돌할 때만 그 지점을 올린다. 미달이면 이 고정 가설을 종료하며 기간·배수·목표·모델을 돌려 합격을 찾지 않는다. 다음다음 연구는 여기서 설계하지 않는다.
