STEP_ID는 **POC6-32**, STEP_NAME은 **ETF 주간 검토 한 장**이다. POC6-31의 구성종목 수집·보유 비교를 사용한다. POC6-31 AC4는 PARTIAL이며, 한 장에서 판단 부담이 줄어드는지는 이번 실제 화면 확인에서 별도로 판단한다.

## 1. Q0~Q9 판정

| 질문 | 판정과 적용 기준 |
|---|---|
| **Q0 · 단계 번호** | **POC6-32 확정.** 설계서·PLAN·목업·STATE와 이번 결과서는 POC6-32를 쓴다. |
| **Q1 · 위치** | **(a) 수용.** 「오늘의 투자 점검」의 「잘 오르는 ETF」 카드 위치에 주간 요약 한 장을 둔다. 이 카드의 조건은 1개월 상위 30 및 인버스·레버리지·합성·선물 제외다. 실제 비교 기간과 조건을 머리에 쓰고 다른 화면 설정과 별개로 적용한다. |
| **Q2 · 묶음과 이름** | **(c) 채택.** 확인된 동일 공식 기초지수로 묶는다. 묶음 이름은 공식 지수명, 단독 행은 ETF명이다. 지수명이 확인되지 않으면 해당 ETF를 단독으로 표시한다. 지수가 다른 상품의 관측된 겹침은 기존 「ETF 구성종목」에서 본다. |
| **Q3 · 보일 개수** | **(a) 수용.** 대표 ETF의 기존 선정 순서로 최대 3개 묶음이나 단독 후보를 보여 주고, 그 다음을 펼친다. 같은 지수 묶음의 대표는 원래 후보 순위가 가장 높은 ETF다. |
| **Q4 · 겹침 문구** | **수용.** 구성 일부만 확인됐다면 범위를 먼저 보여 준다. 예시는 ‘보유 평가액의 44.71%에 해당하는 ETF는 상위 30행 밖 구성이 미확인’이다. 다음 줄의 0.00~0.16%는 확보된 행으로 계산한 **후보 주요 주식별 보유 노출 범위**다. 분모는 현금 제외 보유 평가액이다. 55.29%는 원천 전체 구성 응답이 확인된 ETF와 직접 보유의 평가 비중으로 표시한다. ‘대조 전’, ‘자료 없음’, ‘저장 범위에서 미확인’은 각 상태에 맞게 보인다. |
| **Q5 · 보유 전체 상위 노출** | **(c) 채택.** 이번 보유 항목은 선택 후보와 전체 보유의 겹침·확인 범위다. ⓪과 W0의 상위 노출 계산·조회는 이번 범위에서 제외한다. 업종 집중도는 주식별 업종 근거와 확인 범위가 갖춰지면 검토한다. |
| **Q6 · AI 답 대조** | **(a) 보완 수용.** 아래 §2의 상태·근거 번호 계약을 적용한다. 한 장에서 어느 후보에 추가 확인이 필요한지와 그 짧은 이유를 읽을 수 있어야 한다. |
| **Q7 · 목록 저장** | **기존 저장 항목 사용으로 확정.** D5 실측을 수용한다. 기준일·제외 조건·후보 목록·실제 기간은 기존 정형 항목에 저장하고, 정렬 기준·상하위·개수는 당시 질문 원문에 보존한다. 이 한 장의 출처는 기존 출처 항목에 기록한다. 다시 열기에서 빠진 항목이 발견되면 그 항목과 저장 경로를 보고한다. |
| **Q8 · 마지막 기록** | **(a) 채택.** 이 한 장에서 넘겨 저장한 기록 중 저장 시각이 가장 최근인 건이다. 조회할 때 저장 시각과 원자료 기준일을 따로 표시한다. 첫 사용은 ‘이 한 장에서 저장한 기록 없음’이다. 11/16 22:57의 종목 검토와 11/17 00:14의 목록 기록은 각자의 기존 기록에서 열 수 있다. 명시적으로 고른 보류는 이유·다음 확인을 비운 상태로도 유효하다. |
| **Q9 · VIX와 날짜** | **(a) 보완 수용.** 해석에 사용한 **기간의 시작·끝 VIX 값과 미국 기준일**을 보여 준다. 자료 기준일·복사문·미리보기도 같은 근거를 사용한다. 한쪽 값이나 날짜가 확인되지 않으면 해당 VIX 해석 자리에 ‘미확인’을 표시한다. |

## 2. 목업과 표시 정정

- **② 후보 흐름.** 11/16 예시의 처음 세 행은 1위 KODEX 미국ETF산업Top10 Indxx, 2위 KODEX 글로벌비만치료제TOP2 Plus, 3·4위 Nifty 50 Index 묶음이다. 비만치료제 5·6위는 펼친 목록에서 원래 순위대로 읽는다. 쌍별 50% 기준은 11/16의 구성 겹침을 확인한 참고 실측으로 남긴다.
- **③ 보유 겹침.** 44.71%는 상위 30행 밖을 알 수 없는 ETF들의 평가 비중이다. 해당 ETF의 확보된 행에서 발견한 편입은 노출 계산에 들어간다. 구성일이 다르거나 자료가 부족하면 기존 비교 결과의 상태와 기준일을 표시하고, 실제 데이터에 맞춰 범위를 계산한다.
- **④ AI 의견.** 같은 복사본에서 후보별 근거 항목 번호를 붙인다. 답변은 후보 코드, 상태 하나(근거 확인·추가 확인·자료 부족), 인용 근거 번호, 관측·보유 겹침·확인할 점의 짧은 글로 받는다. PC는 **같은 후보의 상태와 유효한 근거 번호 집합을 각각 대조**한다. 번호가 같으면 ‘인용 근거 번호 일치’, 다르면 각각 표시한다. 앞서 쓴 ‘이유가 다르면’은 이 의미로 정정한다. 일치 표시는 상태와 인용 근거 번호에만 붙인다. 한 장에는 필요한 짧은 문장도 보여 주고 원문은 기존 세션 상세에서 연다. 형식이나 번호를 확인할 수 없는 답은 ‘요약 확인 필요’로 보여 준다.
- **⑤ 마지막 기록.** 첫 상태는 ‘이 한 장에서 저장한 기록 없음’이다. 저장한 뒤에는 그 기록의 근거 검토값과 작성된 이유·다음 확인을 표시한다. 빈 칸은 ‘미기록’이다.
- **VIX 근거.** 6개월 해석 예시는 미국 날짜 5/13의 17.87 → 11/13의 19.30이다. 시작값 대비 변화율을 재계산하면 약 +8.0%다. 일간·5일 변화와 기간 변화는 각각 표기한다. 시세 11/16과 수급 11/13은 해당 자료 옆에 따로 붙인다. 같은 기간을 비교하는 계산에서는 실제 시작·끝 날짜를 확인하고, 최근 저장 기록의 순서는 저장 시각을 기준으로 한다.

## 3. 반영과 사용 확인

1. PLAN V1의 W2·W4~W8과 목업의 ⓪·②~⑤·VIX 표기를 위 판정에 맞춘다. W0는 제외한다. 갱신 전후에 보이는 후보·기간·근거가 섞이지 않도록 화면·복사·저장에 같은 검토 건을 사용한다.
2. 11/16의 고정 자료로 1·2위와 3·4위 지수 묶음, 실제 비교 기간, 시세·수급 기준일을 확인한다. 보유 자료 확인은 합성 사례로 전체 구성·상위 행만 확보·누락을 구별한다.
3. AI 대조는 같은 상태와 같은 근거, 같은 상태와 다른 근거, 형식 미확인을 한 화면에서 구별하는지 확인한다. VIX는 기간 근거가 있는 해석과 미확인 표시를 확인한다. 저장·다시 열기에서 목록과 당시 근거가 복원되고, 한 장의 최근 기록이 다른 화면 기록과 섞이지 않는지 확인한다.
4. 격리 구현 뒤 형수님이 한 장에서 먼저 볼 후보·보유 겹침·불확실한 근거를 읽을 수 있는지 확인한다. POC6-32 결과서에는 기존 POC6-31 검증과 이번 실제 사용 결과를 구분해 기록한다. 운영 반영과 커밋은 PLAN에 적힌 형수님 화면 확인 뒤에 진행한다.
