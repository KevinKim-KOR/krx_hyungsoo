# POC6-30 섹터요약 보강 설계 V1

2026-11-14 KST · 설계자 · 형수님과 개발자

## 1. 목표

**1개월 수익률 상위 30개 ETF의 구성종목을 확인하면, 지금 「섹터요약」에서 읽기 어려운 업종을 근거와 함께 찾을 수 있는지 판단한다.** 같은 ETF 목록의 기존 요약과 구성종목을 더한 요약을 나란히 본다.

11/14 운영 PC 실측에서 11/13 기준 1개월 순위의 비교 대상은 963개였다. 상위 30개 중 기존 사업군 사전으로 분류된 ETF는 1개였다. 구성종목 자료가 저장된 ETF는 3개였고, 모두 7/3 기준 상위 10종목이었다. 현재 섹터요약은 KRX 기준정보의 기초시장·기초자산과 기초지수명에 일치한 사업군을 주로 보여 준다. 공통 구성종목도 이미 만들어진 묶음 안에서 확인한다. 지수명이 다른 ETF들이 실제로 어떤 주식을 함께 담는지 확인할 여지가 있다.

## 2. 같은 목록으로 대조할 것

1. **대상 고정.** 「섹터요약」의 1개월 공통 기간과 기존 기본 제외 조건을 쓴다. 수집 전 요약 응답에서 실제 시작일·끝일, 장중·마감 확인 상태, 선정 순서와 ETF 코드를 기록한다. 이 목록을 세 대조에 공통으로 쓴다. 11/13 목록을 계속 쓸 수 있으면 10/14→11/13 목록을 사용한다.
2. **기존 수집 경로 사용.** 「후보리스트」에서 같은 조건으로 맞춘 목록을 고정 목록과 대조한 뒤 「ETF 구성종목」으로 넘긴다. 기존 네이버 수동 수집은 한 실행에 최대 10개다. 현재 화면에서 나머지 묶음도 지정할 수 있는지 확인하고, 가능한 범위를 수집한다. 각 ETF의 신규 수집·캐시 재사용·미확보 상태, 원천 기준일, 가져온 시각과 실패 사유를 남긴다.
3. **기존 요약과 비교.** 같은 ETF와 수익률을 놓고 아래 세 결과를 본다. 세 번째 결과에서 얻은 새 정보가 표시 보강의 근거다.

| 대조 | 확인할 내용 |
|---|---|
| 현재 저장 자료 + 기존 요약 | 현재 화면에서 읽을 수 있는 기초시장·자산·업종 묶음과 공통 구성종목 |
| 새로 확인한 자료 + 기존 요약 방식 | 기존 묶음에서 자료만 보충해 더 읽을 수 있게 된 내용 |
| 같은 새 자료 + 지수 간 공통 구성종목 확인 | 이름이 다른 지수에 반복 편입된 주식과 실제 편입 비중, 그 자료로 설명할 수 있는 업종 |

우선 확인할 곳은 기존 상·하위 요약 응답(`GET /market/etf-compare/summary`), 「후보리스트」의 목록 전달, 「ETF 구성종목」의 수동 수집, 저장 `etf_constituents`다. POC6-28 분류·겹침 규칙과 11/14 실측을 기준으로 사용한다.

## 3. 근거를 읽는 기준

- **반복이 확인된 주식.** 현행 공통 종목 비교와 같이 ETF별 비중 상위 10종목을 비교한다. 저장된 종목 식별자를 사용하고, 동일 종목 여부가 불명확하면 미확인으로 적는다. 같은 기초지수를 추종하는 여러 상품은 지수 한 종으로 센다. 기초지수 미확인은 따로 표시한다. 서로 다른 지수에서 반복 확인된 주식은 ETF명·기초지수·편입 비중·구성 기준일을 보여 준다.
- **업종 해석.** 기존 자료에서 구성 주식의 업종을 확인할 수 있으면 그 근거를 붙인다. 근거가 모자라면 공통 종목과 편입 비중까지 보여 주고 업종은 가설로 적는다. 넓은 시장을 추종하는 ETF끼리 일부 주식이 겹친 사례는 공통 편입 근거로 읽는다. 채권 등은 공식 자산 분류로 읽고, 현금·선물·옵션은 주식 업종 집계에서 제외한다. 필요하면 기존 AI 복사문으로 업종 가설을 검토한다. 시스템의 자동 섹터 판별 관련 ASSUMPTIONS Q4는 기존 OPEN 계약을 적용한다.
- **자료 범위.** 상위 목록 전체 대비 구성종목 확인 ETF 수, 그중 주식으로 확인한 범위, 구성 기준일, 각 ETF에서 읽은 건수와 원본 비중을 함께 본다. 자료가 채우지 못하는 범위는 확인 불가로 표시한다. 순위 끝일보다 뒤의 구성 자료에는 원천 날짜를 붙여 현재 편입 참고로 표시한다. 순위는 ETF의 기간 수익률을, 구성종목은 그 목록의 업종 노출을 설명한다.

## 4. 완료 기준

| 기준 | 확인할 내용 |
|---|---|
| AC1 · 같은 순위 | 대조표에서 실제 기간·제외 조건·가격 상태·사용한 상위 ETF 목록을 확인할 수 있다. 각 대조에서 ETF 선정과 수익률이 동일하다. |
| AC2 · 읽을 수 있는 자료 | 전체 대비 확보 수와 기준일이 있고, 오래된 자료·미확보·수집 실패·업종 미확인을 구분할 수 있다. 같은 기초지수의 여러 상품과 주식 외 자산으로 업종 근거가 부풀지 않는다. |
| AC3 · 사용자 판단 | 실제 목록의 기존 요약과 보강안을 한 장에서 본다. 첫 줄에서 새로 확인된 업종이나 공통 종목을 읽고, 근거에서 종목·대표 ETF·비중·확인 범위를 대조할 수 있다. 업종을 확인하기 어렵거나 새 정보가 없으면 이유를 한 줄로 읽을 수 있다. |
| AC4 · 표시 채택 판단 | 업종이 확인되고 여러 지수에 걸친 편입 근거가 있어 기존 요약보다 읽을 내용이 늘어난 경우, 기존 「섹터요약」의 상위권 영역에 넣는 안을 채택한다. 자료 보충만으로 개선됐다면 기존 요약으로 사용한다. 근거가 부족하면 필요한 자료를 결과에 적고 표시 결정을 보류한다. |

최초 산출물은 **실제 목록의 대조표 한 장**이다. 화면 보강이 채택되면 기존 상위권 카드에 한 줄과 펼친 근거로 반영하고, 바뀐 화면과 수치를 맞춰 확인한다.

## 5. 적용 경계와 다음 검토

이번 설계는 **PC 「섹터요약」의 1개월 상위권 근거**에 한정한다. 순위·조회 조건·가격 기준은 POC6-28·29 계약을 사용한다. 「ETF 구성종목」은 수동 수집과 원본 확인 경로로 사용한다. OCI·PUSH·Telegram은 현재 운영 계약을 적용한다.

- **보유 업종 집중도**는 별도 후보로 둔다. 보유 ETF의 최신 구성 확보 범위와 분류 가능한 보유 금액 비중을 확인할 때 재검토한다. 현재 보유 ETF 26개 중 6개만 구성 자료가 있고 모두 6월 기준이다.
- **새 자료원·상시 갱신·하위권 또는 다른 기간 확대**는 이번 대조에서 실제 부족분과 반복 사용 필요가 확인될 때 검토한다. 이 단계의 결과를 보고 형수님이 다음에 다시 볼 메뉴나 작업을 정한다.
