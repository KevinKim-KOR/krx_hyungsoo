## 1. 기존 합의와 선택 이유

- POC6-07은 선택 근거의 MA20·MA60과 AI 검토 연결로 종료됐다. 이번에는 화면을 더 정리하거나 이동평균 배지를 늘리지 않는다.
- 기존 02/04의 HGB·MLP 결과는 보존한다. 과거 4종/12종 점수와 이번 24종 점수를 빼서 성능 개선율로 쓰지 않는다. **이번 같은 입력 판·같은 행에서 다시 학습한 기준선과 비교한다.**
- HGB는 기존 고정 설정을 쓰면서 추가 열의 결측을 직접 처리할 수 있다. 입력 결측 때문에 가격 기준선까지 다른 표본으로 줄이는 것을 피한다. 이번 결과는 이 HGB 설정에서의 효과이며 모든 알고리즘에서의 효과로 일반화하지 않는다.
- MEDIAN과 종목별 RIDGE는 실제 비교 기준으로 유지한다. MLP는 06에서 계속 비교되며, 이번에는 GPU·신경망 구조·학습률 실험을 추가하지 않는다.
- 수급·환율·유가·VIX는 계속 보관한다. 이번 입력에는 넣지 않는다. 충분한 겹치는 이력과 실제 가용 시각의 처리 규칙을 확인하지 않고 소급 연결하지 않기 위해서다. 별도 수집·자료원 탐색을 이번 선행 작업으로 만들지 않는다.
- 먼저 가격·거래량이 함께 있는 장기 사본과 이미 보관된 벤치마크로 좁힌 가설을 검증한다. 현재 보관량이나 화면의 지표 개수를 모델 개선 근거로 대신하지 않는다.

연구 한정 예외: 기반 문서의 미래 하락 추정·ML 연구 제한에 대해, 본 POC6-08의 고정 표본·고정 입력 조합·PC 회고 D20 비교만 허용한다. PLAN PASS 뒤 관련 현행 기반 문서에 이 범위를 기록한다. 운영 경보·매매·새 모델 탐색 허용으로 확대하지 않는다.

## 2. 자료·표본 — 기존 사본을 먼저 쓴다

### 2-1. 고정 입력

1. 06의 cohort_v1과 선정 근거를 그대로 읽는다. 명단·해시를 결과에 남기고 보유 파일·계좌·평가·seed를 읽지 않는다. 분모 24종은 실패해도 남긴다.
2. 종목 장기 자료는 06 초기 사본을 우선 사용한다. 보고된 경로는 `state/ml/research/poc6_06/bootstrap/20261023T011918Z_72843194/prices.json`이다. 실제 파일·manifest·sha256과 OHLCV 행 형식은 PLAN에서 확인한다.
3. KODEX200(069500)은 기존 POC6-03의 일관된 장기 사본에서 재사용한다. 해당 가격 파일의 실제 경로·해시·끝일·가격 의미와 기존 검증 범위를 PLAN에 적는다. 표본 24종에 벤치마크를 학습 종목으로 추가하지 않는다.
4. 날짜 축은 이미 보관한 한국 연구 축 하나를 고정한다. PC 운영 표의 계속 바뀌는 최신 행이나 08-27에 멈춘 파생 feature 표는 쓰지 않는다.
5. 서로 다른 ticker의 일관된 계열을 같은 날짜로 비교하는 것은 허용한다. 반드시 같은 날 수신했어야 하는 것은 아니다. 반면 한 ticker의 서로 다른 수신 창을 이어 장기 이력을 만들지 않는다. KRX 무조정 가격을 네이버 조정 계열의 빈칸에 넣지 않는다.

기본 외부 조회는 0회다. 기존 보관본에 유효한 069500 장기 계열이 없으면 PLAN에서 그 사실만 질문한다. 필요할 때의 최대 대안은 **기존 FDR/네이버 경로로 069500 한 종목 1회·재시도 0·별도 연구 사본 저장**이다. 판정과 구체적인 사용자 승인 전에 조회하지 않는다. 24종 재수집·전 ETF 장기 백필로 넓히지 않는다.

### 2-2. 끝일·시험 구간

- 이번 자료 상한은 **2026-10-22**다. T는 이 상한, 24종 초기 사본 전체의 가장 늦은 날짜, 고정 벤치마크 끝일 중 가장 이른 날짜 이하의 마지막 연구 축 날짜로 고정한다. 각 종목의 부족 때문에 종목별 시험 끝일을 바꾸지 않는다.
- T보다 축 20거래일 전을 anchor로 하고, anchor로 끝나는 마지막 189개 축 날짜를 오래된 순서로 63개씩 세 구간으로 나눈다. 실제 날짜 여섯 개와 목표 끝 범위를 PLAN에 잠근다.
- 각 시험 시작일 s보다 **목표 종료일이 이른** 예제만 그 구간 학습에 쓴다. 구간 안 재학습·무작위 분할·early stopping은 없다. 종목 행을 쌓은 뒤 행 개수만으로 gap을 두지 말고, 공통 날짜 경계를 먼저 정해 모든 ticker에 적용한다.
- 기본 가격 feature·목표가 유효한 학습 예제 252개 이상, 시험 날짜 42/63개 이상을 세 구간 모두 충족한 ETF를 평가 적격 집합으로 고정한다. 5종 미만이면 `DATA_SHORT`다. 기준을 낮추거나 유리한 다른 ETF로 바꾸지 않는다.
- 적격 판정에는 날짜·자료 품질·개수만 사용한다. 목표의 크기·모델 오차를 보지 않는다. 상장 전·공백·가격 기준·이력 부족을 분리해 보고한다.

이 자료는 나중에 확보한 장기 가격을 사용하는 **회고 연구**다. 당시 가용 가격/PIT·새로운 독립 확증 시험으로 부르지 않는다. 이미 본 역사 구간의 반복 사용, 현재 상장 목록의 선택, 조정 가격과 겹치는 목표의 한계를 남긴다.

## 3. 목표와 입력 — 추가 정보는 두 개

목표는 기존 D20 그대로다. `D20(t) = min(0, min(C(t+h)/C(t)-1, h=1..20))`. 다음 20거래일의 최저 종가 변화이며, +20일 수익률·장중 저점·MDD·개인 손익이 아니다. 미래 가격은 목표에만 사용한다.

기존 P 5열의 순서와 계산은 02/06을 재사용한다: 5·20·60거래일 종가 변화, 최근 20개 로그수익률의 모집단 표준편차, 최근 60개 종가 고점 대비. 모든 입력은 t 이하만 쓴다.

| 추가 열 | 정의와 단위 | 유효 조건 |
|---|---|---|
| V: `volume_ratio_20d` | `V(t) / mean(V(t-20), …, V(t-1))`, 단위 배 | 같은 종목 가격 사본의 당일+직전 20축 날짜 거래량. 기준일은 평균에서 제외하며 0도 평균에 포함 |
| R: `relative_return_20d` | `[C(t)/C(t-20)-1] - [B(t)/B(t-20)-1]`, 소수 수익률 차 | 종목과 069500의 시작·끝 날짜가 정확히 같고, 각각 해당 21축 날짜의 기존 가격 기준 검사를 통과 |

- 거래량은 유한한 0 이상 수치다. 당일 0·직전 평균 양수이면 배수 0이 유효하다. 직전 평균 0·날짜 부족·거래량 누락/손상은 V 결측과 사유로 남긴다. 음수·무한 값을 0으로 고치지 않는다.
- 기존 거래량 함수가 이 정의의 반올림 전 값을 제공하면 재사용한다. 화면 표시 배수·구간 배지·반올림한 두 자리 값을 모델 입력으로 쓰지 않는다. 정의가 다른 기존 함수를 바꾸어 PUSH에 영향을 주지 않는다.
- R의 종목 20일 변화는 기존 P의 두 번째 값과 같은 정의다. **R을 추가하면 기존 종목 변화와 함께 벤치마크 변화 정보도 알 수 있다.** 따라서 결과를 RS 순위의 효용이나 ‘강한 ETF 선별 능력’으로 부르지 않는다. 여기서 검증하는 것은 시장 대비 입력의 효과다.
- 서로 다른 기간·종목별 마지막 날짜·이웃 날짜로 R을 대신 계산하지 않는다. 벤치마크 가격 문제는 R 결측이다. 기본 종목 가격/목표가 유효한 행까지 삭제하지 않는다.
- V/R에 로그 변환·임의 상한·구간화·추가 결측 표시 열을 만들지 않는다. 유한한 계산 결과만 사용하고, 수치 범위 밖 결과는 결측과 사유로 둔다.
- 새 열 결측은 보관 파일에 `null`+사유로 남기고 HGB 입력에서만 NaN으로 전달한다. 0·평균·미래 값으로 채우지 않는다. HGB가 결측 여부도 이용할 수 있으므로 효과는 ‘수치와 가용성 정보 묶음’의 효과다.
- 파일 손상·해시 불일치·읽기 실패는 `CHECK_REQUIRED`다. 이를 평범한 feature 결측으로 숨기지 않는다. 원본 파일은 수정하지 않는다.

## 4. 여섯 구성 — 같은 행·같은 설정

| 구성 | 입력 | 역할 |
|---|---|---|
| MEDIAN_P | 기존 P 예제의 종목별 목표 중앙값 | 단순 기준선 |
| RIDGE_P | P 5열 | 기존 종목별 기준선 |
| HGB_P | P 5열 | 추가 정보 효과의 직접 대조군 |
| HGB_PV | P + V, 6열 | 거래량 추가 |
| HGB_PR | P + R, 6열 | 시장 대비 정보 추가 |
| HGB_PVR | P + V + R, 7열 | 두 정보 함께 추가 |

세 후보 PV·PR·PVR을 결과 전에 모두 고정한다. 각 후보를 같은 기준으로 평가하고 전부 보고한다. 하나만 잘됐다고 처음부터 단일 후보였던 것으로 쓰지 않는다. 추가 정보 하나만 유용하면 그 결과도 보존한다. 결과를 보고 기간·입력 조합·seed·파라미터를 바꾸지 않는다.

HGB 4구성의 설정은 동일하다: `loss=absolute_error`, `learning_rate=0.05`, `max_iter=100`, `max_leaf_nodes=7`, `max_depth=3`, `min_samples_leaf=50`, `l2_regularization=1`, `max_bins=63`, `early_stopping=False`, `categorical_features=None`, `random_state=42`. 나머지는 기존 설치 환경의 값을 recipe에 명시한다. HGB에 별도 표준화·대입기를 추가하지 않는다.

RIDGE는 기존 종목별 StandardScaler → Ridge(alpha=1, solver=svd, fit_intercept=True), MEDIAN은 짝수 개일 때 중앙 두 값 평균이다. scaler는 각 학습 구간에만 fit한다. 여섯 구성 모두 예측을 [-1,0]으로 제한하고 원시 예측도 보존한다.

각 구간의 학습·시험 행은 기본 P와 목표의 유효성으로 정한 같은 집합이다. V/R 결측으로 후보 행만 빼지 않는다. HGB 공동 학습의 날짜 d 행 가중치는 1/n_d로 하고 네 HGB 모두 같은 행·가중치를 쓴다. MEDIAN/RIDGE는 같은 집합 안에서 종목별 날짜 동일 비중이다. ticker·이름·유형·계좌는 입력이 아니다.

**06에서 이미 학습한 가중치로 과거 시험 구간을 평가하지 않는다.** 그 가중치는 해당 시험 날짜를 학습했을 수 있다. 기존 recipe·작은 계산 접점만 재사용하고, 이번 구간별 모델은 잠근 입력에서 새로 학습한다. 원래 06 가중치·예측·protocol은 바꾸지 않는다.

추가 열이 부족해 실행하지 못한 구성은 `DATA_SHORT`로 남긴다. 실행 오류·비유한 예측은 계산 결함/실행 실패이며 다른 구성의 예측으로 대체하거나 실패 행만 몰래 제외하지 않는다.

## 5. 분석 범위와 자료 충족 — 결과 전에 고정

평가 범위는 아래 둘뿐이다. 새 분류기·ETF 유형 편집 화면을 만들지 않는다.

## 6. 평가 — 정보 효과와 사용 후보를 분리

### 6-1. 공통 수치

주 지표는 기존 날짜 균형 MAE(%p)다. 같은 평가 행의 날짜별 절대오차 평균을 구한 뒤 날짜 평균을 낸다. 전체 189일·세 구간·종목별을 남긴다. 상대 개선율은 `(기준 MAE - 후보 MAE) / 기준 MAE`이며 판정은 반올림 전 수치로 한다.

각 후보에 대해 HGB_P 대비 추가 정보 효과, RIDGE_P·MEDIAN_P 대비 결과를 모두 보고한다. 기준 MAE가 0이면 개선율은 null이며, 그 기준을 이긴 것으로 쓰지 않는다. 해당 A/B 판정은 `NO_BASELINE_HEADROOM`으로 구분한다.

큰 하락 보조 지표는 실제 D20 ≤ -8% 행의 MAE와 **하락을 작게 추정한 정도** `U = 날짜별 mean(max(예측 - 실제, 0))의 날짜 평균`(%p)다. 해당 행이 있는 날짜만 이 평균의 분모로 쓰고 날짜 수·ticker 수·행 수를 적는다. 최대 과소추정도 별도 표시하되 한 행의 최댓값만으로 전체 후보를 기각하지 않는다. 방향 적중률·매매 수익률·사전 감지율로 바꾸지 않는다.

### 6-2. A — 추가 정보 효과

자료 충족 범위에서 PV·PR·PVR 각각이 다음을 만족하면 `FEATURE_GAIN_SUPPORTED`다.
1. HGB_P 대비 전체 날짜 균형 MAE **5% 이상 감소**.
2. 세 구간 중 **두 구간 이상**에서 HGB_P보다 MAE가 작음.
3. 어느 구간도 HGB_P보다 MAE가 **5% 넘게 커지지 않음**. 기준 0인 구간은 후보도 0이어야 함.

충족하지 못하면 `FEATURE_GAIN_NOT_SHOWN`이다. 이 HGB 설정·자료·범위에서 입증하지 못했다는 뜻이며 거래량/RS 자체의 무용성을 확정하지 않는다. 모든 ETF·모든 구간에서 개선돼야 한다고 요구하지 않는다. 종목별 악화와 손익 교환을 그대로 보인다.

### 6-3. B — 다음 사용 검증 후보

A를 충족한 후보만 다음을 추가 판단한다.
1. 같은 평가 범위의 RIDGE_P 대비 전체 MAE도 **5% 이상 감소**, MEDIAN_P보다 전체 MAE가 작음.
2. 큰 하락 행이 시험 날짜 **20개 이상·ticker 3종 이상**에 존재하고, U가 RIDGE_P보다 **5% 넘게 악화되지 않음**. RIDGE의 U=0이면 후보 U도 0이어야 함.

둘 다 만족하면 `RESEARCH_CANDIDATE`, 큰 하락 수가 부족하면 `TAIL_DATA_SHORT`, 비교 기준이나 과소추정 조건을 못 넘으면 `FEATURE_GAIN_ONLY`로 남긴다. A와 B를 한 개의 ‘ML 실패’로 합치지 않는다. 위 5%·20날짜·3종은 이번 사전 판단 기준이며 투자 효용을 보장하는 수치가 아니다. 겹치는 목표 때문에 20날짜를 20독립 사건으로 설명하지 않는다.

G_ALL과 G_REVIEW는 각각 판정한다. 전체가 기준 미달이어도 사전 고정 보조 범위가 통과하면 **그 범위 한정 연구 후보**로 명시할 수 있다. 주 결과를 보조 결과로 바꿔치기하지 않는다. 종목별 우연한 최상위 결과로 세 번째 범위·새 조건부 모델을 만들지 않는다.
