## 2. F5 — 계산·결론 검증과 생성 이력 보장을 구분

### 2-1. 재현 사실은 수용한다

예산 정지 직후 아직 시작하지 않은 바로 다음 학습의 원문 파일을 추가하고 해시 목록을 맞춰도 verify가 OK라는 F5는 유효한 발견이다. 결과서 §4-8·§6의 ‘흐름이 그 단계까지 실제로 쓰는 파일만 허용’이라는 보장은 현재 코드가 충족하지 못한다. 검증자가 제출된 보장 문구를 기준으로 반려한 것을 잘못된 판정으로 바꾸지 않는다.

다만 이 재현은 중단 상태 BUDGET_STOP과 H1·후속 후보 NOT_JUDGED를 유지한다. 추가 원문이 정상 모델 기록·예측·장부·결론의 근거로 쓰였거나, 최신 공식 실행에 실제로 존재한다는 지적은 아니다.

### 2-2. 이번 연구에서 유지할 필수 보장

| 해시·재계산 | 필수 파일 손실이나 사용된 근거 변경을 검사. 해시 목록을 다시 맞춘 것만으로 의미상 불일치를 승인하지 않음 |

F1~F3의 잠금·미래 cutoff·필수 근거 누락 검출과 F4의 올바른 중단 처리 정정은 그대로 필요하다. 이를 이번 범위 결정으로 되돌리거나 검사를 제거하지 않는다.

### 2-3. 제외하는 보장과 F5의 처리

이번 단계는 **NOT_JUDGED로 끝난 묶음의 사용되지 않는 부가 원문까지 실제 파일 생성 순서와 정확히 같다는 보장**, 또는 저장 기록을 모두 일관되게 바꾼 경우의 실제 실행 이력 인증을 제공하지 않는다. 외부 시각 인증·서명·별도 감사 시스템도 추가하지 않는다.

이에 따라 F5는 **발견 사실 유지·비차단 공개 한계**로 처리한다. ‘F5 코드 정정 완료’라고 쓰지 않는다. 동일한 미사용 원문이 남아 있어도 중단 기록의 일관성 검사는 통과할 수 있으며, 그것이 해당 학습의 실행·완료·모델 유효성을 인증하지 않는다고 명시한다.

이 결정은 모든 추가 파일을 허용하거나 정상 실행의 파일 검사를 완화하는 지시가 아니다. 추가 파일이 실제 사용된 예측·장부·결론의 근거가 되거나, 필수 근거 누락을 가리거나, 중단 상태를 완료/판정 가능 상태로 올리는 경우는 여전히 차단 대상이다. 현재 있는 검사를 걷어 내는 코드 변경도 필요 없다.

기록을 일관되게 바꿔 정상 실행을 ‘예산 정지’ 또는 ‘복원 차이 정지’로 낮춘 경우 실제 이력을 구별하지 못한다는 기존 한계도 수용한다. 이때 NOT_JUDGED는 ‘검증된 연구 성과’가 아니다. verify OK는 그 상태에 요구되는 대조 통과이며 run OK·연구 채택과 구분한다.

**개발자가 결과서의 현재 보장 문구를 실제 구현 범위로 좁히는 것으로 처리한다. 추가 파일 단계 추적기·새 위조 탐색 라운드·이 한계를 막기 위한 F5 코드 수정은 이번 종료 조건으로 요구하지 않는다.** 이 범위를 먼저 명확히 정하지 못해 검증 보강이 길어진 부분은 설계에서 정리한다.

## 3. OpenMP — 고정 연구 환경의 제한적 수용

결과서 §4-2의 LightGBM 선적재, prepare/run/verify의 역순·경로 가드, 별도 프로세스 시험을 **이번 고정 연구 환경의 실행 조건**으로 수용한다. LightGBM 단독과 실제 연구 경로의 최대 학습 규모 예측이 비트 단위로 같았다는 개발자 대조, 검증자의 가드 확인을 근거로 한다.

공식 FAQ는 복수 OpenMP 런타임이 충돌·잘못된 결과를 일으킬 수 있으며 한 런타임 사용을 권한다.[1] 따라서 세 런타임의 동반 적재가 근본적으로 해결됐다거나, import 순서만 맞으면 모든 환경에서 안전하다고 표현하지 않는다. 이번 수용은 해당 환경·경로·검사에 한정한 설계 판단이다.

- 기존 환경·실제 로드 경로·순서·가드를 기록한 채 보존한다. torch 선적재 등의 부적합 조건이면 계속 강행하지 않고 확인 필요로 멈춘다.
- 기존에 금지한 라이브러리 연결/패치·보안 완화나 KMP_DUPLICATE_LIB_OK 사용으로 충돌을 숨기지 않는다.
- 운영 import 경로·OCI·일반 시험 프로세스로 이 방식을 확대하지 않는다. 향후 환경이 바뀌면 그 환경의 실행 가능성을 다시 확인하며 이번 결과를 안전성 보증으로 재사용하지 않는다.

이미 제출·검증된 확인을 다시 하기 위한 역순 세그폴트 재현이나 공식 학습은 요구하지 않는다. 가드가 모든 종류의 네이티브 충돌을 사전에 잡는다는 보장도 하지 않는다.

## 5. 시험 40bp만 미확정인 경우 — 전체 NOT_JUDGED 유지

기존 PLAN 판정 §3-3과 구현의 보수 처리를 유지한다. 이번 연구는 20bp·40bp 필수 곡선을 포함한 하나의 제출 묶음이다. 어느 필수 곡선의 보유 평가가 미확정이면 전체 H1 및 후속 후보 지위를 NOT_JUDGED로 둔다.

20bp 곡선의 확인된 수치와 H1 수치 조건의 충족 여부는 진단으로 남길 수 있다. 이를 완결된 H1 판정으로 승격하거나, 40bp를 빼고 비용 강건성 기준을 바꿔 합격 결과를 만들지 않는다. 미확정은 성과 미달 또는 비용 민감의 입증으로도 쓰지 않는다.

이 경우가 이번 공식 실행에서는 발생하지 않았다는 보고를 수용한다. 실제 최신 결과의 상태를 이 가상 경우 때문에 NOT_JUDGED로 바꾸지 않는다. 향후 다른 연구에서 기본 비용 효과와 비용 검증 상태를 독립 판정할 필요가 있으면 그 연구의 성과를 보기 전에 계약을 따로 정한다.
