## 1. 판정 근거와 범위

첨부 DESIGN V1과 PLAN V1을 대조했다. PLAN은 08 정정 실행의 저장된 시험 예측·정답·P 입력으로만 이번 질문을 계산할 수 있다고 확인했고, 새 학습·가격 조회·외부 수집이 필요하지 않다. 설계 목적과 부딪히는 변경은 없다.

제출한 6파일 전체 해시·필드 대응·행 연결 조사와 개수 표를 실행 전 고정값으로 수용한다. report.md/json의 해시 두 개는 설계에 적힌 정정 실행과 같다. 시험 3,969행·189날짜, G_ALL 매일 21종·G_REVIEW 매일 15종·2,835행, 구간별 63일과 검토 수 k=3을 그대로 쓴다.

이는 **개발자의 읽기 전용 구조 확인과 첨부 문서의 대조를 수용한 판정**이다. 설계자가 사용자 PC의 원본 6파일을 직접 열어 재측정하거나 순위·큰 하락 수·효용을 계산한 확인은 아니다. PLAN PASS는 연구 결과가 유망하다는 판정이 아니다.

## 3. 구현 시 명확히 할 순서와 검증 — PLAN 재제출 없음

### 3-1. 실제 사용하는 입력과 해시를 일치시킨다

각 파일에서 **한 번 읽은 같은 바이트**로 고정 SHA-256을 대조하고 엄격 JSON 읽기를 한다. 그 파싱 결과를 계산에 사용한다. 해시만 확인한 뒤 파일을 다시 읽어 다른 바이트를 계산에 쓰지 않는다.

예측의 fold/ticker/date와 예제의 시험 위치를 함께 확인한다. `(ticker, date)` 연결이 일대일인 사실을 이용할 수 있지만, 학습 행이나 다른 fold가 섞이지 않도록 PLAN의 i·folds 대조도 유지한다. 20일 변화는 p[1]이라는 위치뿐 아니라 고정 P 열 순서의 chg20 의미와 일치해야 한다. 불일치는 행 삭제·다른 값 대체가 아니라 CHECK_REQUIRED다.

### 3-2. run 안에서 protocol을 계산보다 먼저 남긴다

PLAN의 단일 run 흐름을 다음 순서로 확정한다.

1. 실행 잠금·재실행 사유 확인 → 입력 6파일의 해시·형식·연결·개수 사전 대조.
2. 사전 대조를 통과하면 실행 ID를 정하고 **그 직후부터 실패 기록 범위**에 들어간다. 새 폴더도 그 범위 안에서 만든다.
3. 고정 입력 해시·조건·방법·범위·코드 해시·출처·이전 실행/정정 관계가 담긴 protocol을 먼저 저장한다.
4. 그다음 Y·순위·선택 비중·P/R·판정을 계산하고 rows·report·완료 상태를 저장한다.

별도 lock 단계나 새 승인 절차를 추가하는 뜻이 아니다. 사전 대조 실패는 새 연구 실행/산출물을 만들기 전의 CHECK_REQUIRED로 보고한다. 실행 잠금 파일의 부수 쓰기와 ‘파일 쓰기 자체가 전혀 없음’을 혼동하지 않는다. 실행 ID 뒤의 protocol 저장·계산·결과 쓰기 실패와 중단은 기존 계획대로 FAILED 기록을 남기고 원래 오류를 보존한다.

### 3-3. verify는 이번 실행의 연결과 계산을 확인한다

고정 08 입력에서 재계산해 rows.json·report.json 전체 및 report.md를 대조하는 방식으로 진행한다. 함께 **09 protocol의 입력 해시·고정 조건·실행 ID와 run.json의 성공/실패·정정 관계가 같은 실행을 가리키는지** 확인한다. 실패·미완료 실행을 정상 연구 결과로 반환하지 않는다.

verify는 조작된 protocol에 적힌 임의 k·경계·방법을 새 규칙으로 받아들이지 않고 이번 고정 계약과 대조한다. 09의 검증 책임은 행 연결·선택 비중·날짜 평균·판정과 저장 설명의 정합성이다. 08 모델 학습 자체를 다시 증명하는 작업으로 늘리지 않는다.

## 4. 과학적 조건과 보고는 제출안 그대로

- 큰 하락은 실제 D20≤−0.08, 순서는 제한 예측 또는 PRICE20 값이 낮은 쪽이다. −8% 예측 도달 여부로 검토 종목을 정하지 않는다.
- 두 범위 안에서 매일 독립 순위를 계산하고 경계 동점 비중을 적용한다. 동점은 원래 저장 숫자로 판단하며 반올림·epsilon·티커 순으로 우열을 만들지 않는다.
- P는 모든 날짜 평균, R은 M>0인 날짜만 평균한다. R의 정의 불가를 0이나 1로 채우지 않는다. 모든 지표의 날짜·종목·행 분모를 같이 남긴다.
- 표본 조건, 두 모델×두 범위, 세 기준 각각과의 5%p 차이·2구간 우위·구간 악화 한도·R 조건은 설계 §6·PLAN §4 그대로다. 5%p 절대 차이와 08의 5% 상대 개선을 구분한다.
- 표본 부족 DATA_SHORT, 충분하지만 조건 미충족 PRIORITY_GAIN_NOT_SHOWN, 조건 충족 PRIORITY_RESEARCH_SIGNAL을 구분한다. 요약 상태뿐 아니라 조건별 값·차이·참거짓·동점·반복 선택 집중·미포착을 공개한다.
- 08의 예측/결과를 이미 본 회고 연구이며 현재 표본·나중에 수신한 가격·목표 겹침의 한계를 유지한다. 처음 본 시험·독립 급락 사건 수·매매 승률·투자 수익으로 해석하지 않는다.

새 지표·구간·종목·모델을 추가하거나 유리한 범위를 사후 선택하지 않는다. V/R 조합·MLP를 다시 시험하지 않고 08의 A/B 판정을 뒤집지 않는다.
