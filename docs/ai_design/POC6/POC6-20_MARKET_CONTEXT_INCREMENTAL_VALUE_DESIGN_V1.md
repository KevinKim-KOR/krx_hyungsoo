기존 H1은 가격·거래량 30열과 LightGBM의 주간 선별이 모멘텀보다 유용하다는 기준을 충족하지 못했다. POC6-19로 긴 수급·원/달러·WTI 사본을 확보했지만, 이 추가 정보의 효용은 아직 비교하지 않았다.

**이번 가설: 동일한 모델·대상·학습 행·시점·주간 운용에서, 시장 정보 4열을 추가한 순위가 가격·거래량 30열만 쓴 순위보다 비용 후 모의 성과를 개선하는가.**

한 가설·추가 입력 묶음 하나만 비교한다. 정보 묶음 전체의 추가 효과를 보며, 수급/환율/WTI 각각의 단독 기여나 최적 조합을 찾는 단계는 아니다. 이전 H1 결론은 보존한다.

## 3. 입력 사본과 추가 4열

가격·OHLCV·당시 집합/이름·069500은 기존 봉인 `krx_etf_universe_v1` 읽기 전용 판을 재사용한다. 수급은 POC6-19 실행 `20261103T171931Z_b0ea4fcf`의 검증된 사본, 매크로는 수용 근거로 고정한 낮 실행 `20261103T044323Z_92947186`의 장기(B) 관측을 쓴다. 입력 경로·해시·자료 의미를 잠금에 연결한다.

매크로는 A 표본 116행을 장기 이력에 중복 합치지 않는다. B의 원/달러 3,310일·WTI 3,175일을 사용한다. 원시·정규화·기존 보고는 수정하지 않는다. 운영 DB·새 API·새 공급자·새 가격판으로 빈 곳을 채우지 않는다.

| 추가 열 | 고정 정의 |
|---|---|
| 외국인 수급 방향 | §4에서 가용한 마지막 예상 코스피 거래일을 끝으로 한 20거래일의 외국인 순매수 합 / 같은 창 순매수 절댓값 합 |
| 기관계 수급 방향 | 같은 20거래일 창의 기관계 순매수 합 / 같은 창 순매수 절댓값 합 |
| 원/달러 변화 | 가용한 최신 유효 관측값 / 그보다 20개 유효 관측 앞의 값 − 1 |
| WTI 가격 차이 | 가용한 최신 유효 관측값 − 그보다 20개 유효 관측 앞의 값(USD/bbl). 비율·로그·선물 투자수익률로 바꾸지 않음 |

수급은 20개 예상 한국 거래일 모두 유효해야 한다. 실패 4일을 건너뛰어 창을 줄이거나 직전 값으로 채우지 않는다. 모든 값이 정상 0이라 절댓값 합도 0이면 방향값은 0이며, 없는 관측을 0으로 만든 경우와 구분한다. 기관계만 쓰며 세부 7개·국가를 더하지 않는다. 규모의 시간 변화를 줄이고 부호의 일관성을 보는 고정 비율이며 시장 거래대금 대비 비중은 아니다.

매크로의 20은 **20개 유효 관측 간격**으로, 한국 20거래일이나 완전한 원천 20거래일이라는 뜻이 아니다. 끝점까지 21개 관측이 필요하다. WTI 비자정 23일 등 현행 제외는 그대로 적용하고 사용한 원천 날짜·실제 달력 길이를 남긴다. 원/달러는 양수, WTI는 유한한 0·음수도 유지한다. 이번 입력 묶음을 보고 나서 기간·열을 바꾸지 않는다.

## 4. 정보 이용 시각 — 회고 가정 고정

신호일 D는 H1처럼 한국 거래 주의 마지막 거래일이다. 회고 판단 마감은 **D 23:59:59 KST**, 체결은 기존대로 D 뒤 두 번째 한국 시장 거래일의 합성 시가다. 당일 종가를 당일 체결에 쓰지 않는다.

| 원천 관측일 d | 이번 연구에서 가정하는 이용 가능 시각 |
|---|---|
| 코스피 수급 | d 다음 한국 시장 거래일 12:00 KST |
| 원/달러·WTI | 저장된 원천 시간대에서 d+2달력일 00:00을 만든 뒤 KST로 변환한 시각 |

판단 마감 이하인 관측만 사용한다. 수급 창의 끝은 성공한 마지막 날짜가 아니라 위 시각 규칙으로 정한 **예상 거래일**이다. 해당 관측이 실패했으면 창은 미확인이다. 매크로는 각자 원천 시간대·관측일을 유지하고 가용 시각 기준으로 과거 관측을 찾는다. 같은 날짜 문자열끼리 바로 붙이지 않는다.

이 지연은 사후 자료를 쓰는 이번 회고 비교의 보수적 설계 가정이다. 실제 과거 공개 시각이나 당시 수신판을 인증한 값은 아니다. 2026년 수신 시각을 과거로 소급하지 않는다. 공급자 정정·가격 조정·이미 본 시험 기간 한계를 유지하며 지연 길이 민감도 탐색은 추가하지 않는다.

## 5. 공통 날짜·학습 행·운용

추가 4열이 모두 정의되는 주만 P/M의 공통 학습·정기 순위 날짜로 사용한다. 같은 날짜의 ETF 자격·정답·행 순서·가중치는 완전히 같아야 한다. P도 이 공통 자료 조건을 적용한 새 대조군이며, 예전 H1의 저장 예측·성과를 그대로 가져오지 않는다. 이 조건은 현재 사본의 가용성에 따른 것이며 당시 실제 자료 결측 이력으로 해석하지 않는다.

4열을 만들 수 없는 주에는 P/M/B 모두 새 정기 순위·신규 편입·통상 순위 교체를 만들지 않는다. 기존 보유와 일별 가격 보호 처리는 동일 계약으로 계속한다. K는 공통 자료 조건으로 정한 첫 실행일에 진입해 보유한다. P/M 실제 첫 매수일에 K 진입일을 맞추지 않는다. 첫 날짜는 PLAN에서 성과 없이 확정한다.

신규 입력 결측 때문에 미래 정답 부족 ETF를 현재 자격에서 삭제하지 않는다. 정답 성숙·날짜별 20종/95%·가중치·분기 학습은 H1 계약대로다. 시장 공통 관측을 ETF 행 수만큼 독립 표본으로 늘려 세지 않는다. 자료 650주와 실제 학습/평가 가능 주는 별도로 보고한다.

추가 효용 축과 후속 검토 후보 축을 분리한다. 추가 효용만 맞아도 프로젝트 목적 달성/모델 채택으로 쓰지 않는다. 모든 경제적 축이 맞아야 제한된 후속 검토 후보이며, 어느 결과든 운영 채택·총수익 검증은 NO다. 불확실성과 이미 본 기간의 한계는 후보 여부와 함께 표시한다.

## 8. 변경 범위·유지할 것·완료 기준

기존 `app/weekly_selection/{data,features,model,policy}.py`의 직접 계약과 검증 기록을 재사용하고, 시장 입력/공통 날짜/두 모델 비교를 맡는 최소 연구 모듈과 실행 경로를 PLAN에서 제안한다. 기존 H1·POC6-19의 결과와 실행 동작은 보존한다. 새 일반 거래 엔진·Qlib 이식·DB·공급자·UI·운영 API·OCI/PUSH·주문·06 전향 모델 변경은 없다. 설치·공유 코드 변경이 실제로 필요하면 정확한 충돌만 PLAN에 적는다.

완료 기준 AC:

1. 원천/봉인 판·코드·환경·4열 정의·가정 가용 시각·공통 날짜/행·모델·기간·운용·비용·판정·예산을 성과 계산 전에 잠금.
2. 미래/마감 뒤 관측을 바꿔도 과거 입력·선정이 바뀌지 않음. 미확보 4일, 정상 0, 국가 중복, WTI 음수·제외 봉, 시간대 경계가 정의대로 처리됨.
3. P/M은 입력 추가 4열 외 같은 학습/운용 계약. 값과 시각의 원시 연결·대표 손계산 및 저장 예측→정책→장부→판정 재계산을 확인.
4. P/M/B/K 전체와 고정 구간·20/40bp 결과, 보유기간/회전율·현금·원인/유형 의존·불확실성·사용/제외 주 수를 보고. 기존 H1 곡선과 새 대조군의 범위 차이도 명시.
5. 실패·중단과 기존 원본을 보존하고 검증자 확인 뒤 설계자 RESULT 판정. 연구 수행 완료·추가 효용·후속 후보·운영 채택을 구분.

완벽한 위조 인증이나 기존 F5 보장 한계 해소를 새 선행 목표로 만들지 않는다. 변경 경로 중심으로 확인하고 공유 코드/프런트 변경이 없으면 전체 회귀·프런트 검사를 관성적으로 추가하지 않는다.
