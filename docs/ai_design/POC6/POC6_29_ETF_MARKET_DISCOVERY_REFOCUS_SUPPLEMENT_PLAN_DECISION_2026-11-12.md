# POC6-29 보완 PLAN 설계자 판정

**2026-11-12 KST · 보완 PLAN 승인 · 아래 조건 반영 후 구현**

첨부 PLAN §9와 목업 R1~R4, 형수님의 목업 확인 회신을 기준으로 판정한다. RESULT 상태는 보완 실측과 화면 확인 후 재판정한다. 개발자 실측에서 6시간 대기 중 보유 현재가만 갱신됐고, 대기 뒤에는 같은 거래일의 KODEX 200 저장 가격이 85,045원에서 84,240원으로 바뀌었다. 이번 보완은 빠른 시세와 같은 날 다시 저장된 자료를 사용자가 구별할 수 있게 한다.

## Q-R1~Q-R6 판정

| 질문 | 판정 |
|---|---|
| **Q-R1 · 네이버 빠른 시세** | 채택한다. [최신 자료 갱신]을 눌렀을 때 코스피·코스닥 지수와 기존 KODEX 200 종목 경로를 조회한다. 화면 진입과 [요약 다시 읽기]는 저장값만 읽는다. 새 지수 주소의 실제 호출은 사용자 확인 범위로 기록하고, 응답 사본을 사용한 구현·시험부터 진행할 수 있다. |
| **Q-R2 · 시장 전체 갱신 대기** | 기존 6시간 대기의 범위는 시장 전체 단계다. 대기 중에도 빠른 시세와 보유 현재가를 받는다. 빠른 시세는 완료되는 대로 먼저 반영하고, 시장 전체 단계에는 다음 가능 시각을 표시한다. |
| **Q-R3 · 코스피 두 수치** | 상단은 「네이버 시세」와 원천 표기 시각·장 상태, 아래는 「코스피 공식 종가(KRX)」와 실제 자료 거래일을 표시한다. 아래 차트는 공식 종가 줄 바로 아래에 둔다. 화면은 저장된 거래일을 표시하고, 자료일이 늦으면 기존 최신성 상태를 함께 보인다. |
| **Q-R4 · 비교 상세 범위** | (a)를 채택한다. 현재 상세 응답의 항목으로 카드와 접기를 만든다. 거래량·흔들림은 이번 비교 카드의 새 항목에서 제외한다. |
| **Q-R5 · 통합한 C 화면 이력** | 「진단·상태 › 미사용 기능 › 신규 ETF 관찰 점검」을 하위 메뉴로 둔다. C가 제공하던 기능의 새 위치는 그 페이지의 「자세히」에서 연결한다. 기능 설명·이동 이유·현재 사용처와 실행 버튼은 펼치지 않고 읽을 수 있게 한다. |
| **Q-R6 · 시장 판정과 VIX** | 상단 문장에는 국면과 근거, VIX의 값·변화와 각 자료 기준일을 둔다. 상세 판정 줄과 수치는 접기 ①·②에서 읽는다. 외국인 수급 아래의 「최근 큰 변화」는 기본 화면에서 보인다. |

## 구현에서 확인할 세 가지

1. **빠른 시세의 시각과 상태** · 항목별 원천 표기 시각, 조회 시각, 장중·마감 상태를 구분한다. 마감 뒤 원천 표기 시각만 달라지고 같은 거래일의 값·등락·장 상태가 같으면 ‘조회 성공 · 시세 변동 없음’으로 표시한다. 거래일이나 장 상태가 바뀐 경우는 새 상태로 보여 준다. 일부 항목이 실패하면 그 항목의 마지막 성공 값과 시각을 표시하고, 보유·시장 단계는 계속 진행한다. 성공 이력이 없으면 ‘시세 미확인’으로 표시한다. 연타나 다른 탭은 진행 중인 같은 묶음 작업을 이어 보고, 빠른 시세 조회도 그 작업에서 한 번 실행한다. 시장 판정·순위·판단 근거에는 각각의 저장 자료와 기준 시각을 쓴다.
2. **같은 날 다시 저장된 시장 자료** · 날짜와 저장 시각을 대조해 ‘같은 거래일에 다시 받음’을 보여 준다. 값이 확인된 경우 이전 값과 새 값을 보여 준다. KODEX 200의 09:53 장중 85,045원 → 15:56 마감 뒤 저장 84,240원이 재현 사례다. 화면 다시 읽기에 실패하면 표시 중인 값의 기준 시각과 실패를 함께 적는다. 목업의 빠른 시세 단계는 구현 예정 예시로 표시한다.
3. **비교 차이 줄** · 두 수익률의 실제 시작일과 끝일이 모두 같고, 확인된 장중·마감 가격 상태도 서로 맞을 때 차이를 `%p`로 표시한다. 둘 다 장중이면 잠정 비교로 표시한다. 기간이나 가격 상태가 다르면 그 사유를, 비교할 수치나 상태를 확인할 수 없으면 자료 상태를 적는다.

## 격리 검증과 사용자 확인

- §9-0에서 공개 시세 세 건을 격리 설정으로 이미 읽었다. 마지막 실제 갱신 확인은 **같은 격리 설정과 자료 사본**에서 버튼 → 빠른 시세 응답 → 화면 세 칸을 한 번 연결해 확인한다. 전체 갱신의 대기와 KRX·OCI 단계의 실제 결과도 각각 기록한다. 본 폴더 `.env` 전체 연결 요청은 이 보완 확인의 범위에서 제외한다.
- 형수님 확인 사항은 **버튼을 눌렀을 때 네이버 코스피·코스닥 공개 지수 주소를 실제로 조회할지** 한 가지다. 개발자가 PLAN §9-5 Q-R1에서 별도 확인을 요청했다. 수동 버튼의 두 지수 조회만 대상으로 한다.
- R1~R4 실화면과 변경 경로 시험을 제출하고, 기존 r3 검증 근거를 재사용한다. 실제 빠른 시세 반영과 보완 화면을 확인한 뒤 RESULT를 다시 판정한다.
