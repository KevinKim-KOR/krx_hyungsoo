# POC6-12 DESIGN V1 — ETF 분배·총수익 자료 검증

작성: 설계자 · 2026-10-27 · 독자: 개발자·사용자·검증자

저장 권장 위치: docs/ai_design/POC6/POC6-12_ETF_DISTRIBUTION_AND_TOTAL_RETURN_DATA_VALIDATION_DESIGN_V1.md

**목적:** 공식 원가격과 분배·권리 자료를 연결해, 같은 기간 ETF와 KODEX200을 분배금까지 포함한 동일 기준으로 평가할 수 있는지 소수 고정 표본에서 확인한다. 다음 ML·추천 검증에 쓸 자료 계약을 확보하는 작업이다. 새 모델·전략의 성과 실험, H1 재실행, 운영 수집기 개편은 하지 않는다.

**지금 지시하는 일은 짧은 PLAN 작성이다.** 기존 파일·공식 자료의 정의와 정상 제공 경로를 확인하고 실제 빈자리만 질문한다. PLAN 판정 전 신규 이력 수집·구현·설치·DB/OCI 쓰기를 시작하지 않는다.

## 1. 왜 이 작업이며, 기존 연구와 무엇이 다른가

사용자 보고상 POC6-11은 구현 549af63c·종료 기록 da643ed5로 push됐고 IMPLEMENTED_VERIFIED_CLOSED다. 설계자가 원격 main을 직접 확인한 보고는 아니다. H1 미충족·운영 미채택 결론을 유지한다.

최근 비교는 KRX_BASEPRICE_CHAIN 합성 가격지수였다. 수익 목적은 정했지만 그 값이 분배금 포함 투자자의 총수익과 같다는 확인은 없었다. 가격·분배금·분할의 의미를 맞추라는 상위 계약 §4~§5의 남은 전제다. 이 빈자리를 둔 채 모델만 바꿔 실제 추천 채택의 근거를 늘리지 않는다.

| 질문 | 이번 범위 |
|---|---|
| 새로 확인할 것 | 공식 가격·현금 분배·권리 시점으로 재현 가능한 수익 기준을 구성할 수 있는가 |
| 기존 H1과 다른 점 | 모델의 우열이 아니라 평가 자료의 경제적 의미와 가용성을 검증 |
| 사용자 목적과 연결 | 향후 후보·보유 권고를 같은 기간 KODEX200과 비교할 때 배당 누락·이중 반영·미지급 현금 사용을 피함 |
| 끝내는 단위 | 고정 4종·2025년의 출처/가용성 표, 정규화 사건, 재구성·검산 보고. 불가하면 구체적 부족과 미실행 영역까지 |
| 이번에 완료하지 않는 것 | 수익 우위·추천 기능·유용한 ML 연결·#3/#55/#57/#62 전체·과거 모든 ETF의 총수익 |

분배금을 반영하면 미채택 모델이 좋아질 것이라고 전제하지 않는다. POC6-10·11 공식 파일·판정을 수정하거나 총수익으로 다시 계산하지 않는다. 목표는 다음 검증을 위한 전제 확인이며 이번 실패를 되돌리는 것이 아니다.

## 2. 설계자가 확인한 출처와 아직 확인하지 못한 것

공식 운용사 공지에는 분배금, 분배락일, 지급기준일, 지급 예정일이 서로 구분된 사례가 있다.[1][2] ‘지급 예정’ 공지를 실제 지급 완료 기록으로 읽지 않는다.

| 공식 경로 | 이번 설계에서 확인한 수준 | PLAN에서 좁게 확인할 것 |
|---|---|---|
| SEIBro ETF 분배금 지급현황 | 공식 조회 화면의 존재·검색상 필드 안내. 설계자 웹 도구에서는 본문 행을 읽지 못함[3] | 2025년 4종 이력·범위·실지급일·내보내기·이용 조건. 전체 이력/API 사용 가능을 아직 주장하지 않음 |
| KODEX 분배 현황·공지 | 현황 진입점과 정적 공지의 날짜·금액 표 확인. 현황의 동적 행은 미확인[1][4] | 지정 3종 이력 범위·정정 공지·분배락 근거·공식 내려받기 |
| TIGER 분배 현황·공지 | 공식 진입점 확인. 설계자 도구의 직접 열람은 403이어서 실제 행 미확인[5] | 사용자 PC의 정상 공개 화면/내보내기 가능 여부. 차단 우회 지시 아님 |
| 기존 봉인 KRX | POC6-11에서 쓴 판의 원가격·등락·거래량과 연결 지수 접점 재사용 | 네 코드의 2025년 원행·기준가격 의미·기업행사 접점. 라이브 표·FDR로 대체하지 않음 |

**권장 경로는 공식 내보내기/공개 문서의 작은 입력 묶음이다.** 먼저 재현 가능한 원본을 확보하고 해시를 고정한다. 이 단계에 전용 로그인 수집기·브라우저 스크래퍼·새 데이터 플랫폼을 만들지 않는다. 사용자가 정상 공식 화면에서 받은 CSV/XLS/PDF도 가능하나 원본·추출 위치를 함께 보존하며 기억으로 수기 입력하지 않는다.

공식 출처끼리 값이 다르면 우선순위로 조용히 덮지 않는다. 원본과 차이를 남겨 정정 근거로 해소하거나 EVENT_CONFLICT로 둔다. 비공식 사이트의 배당표로 필수 근거를 채우지 않는다. 검색 결과나 예정일 공지 하나로 연간 이력의 완전성을 선언하지 않는다.

## 3. 대상·기간 고정

| 코드 | 설명용 이름 | 고른 이유 |
|---|---|---|
| 069500 | KODEX 200 | 향후 비교 기준 자체의 분배·가격 의미 확인 |
| 379800 | KODEX 미국S&P500 | 해외주식형과 분배 정책 이력의 확인 접점 |
| 458730 | TIGER 미국배당다우존스 | 다른 운용사·현금 분배 이력 접점 |
| 214980 | KODEX 단기채권PLUS | 채권/현금성 구조의 접점 |

이름·분배 빈도·정책의 실제 적용일은 공식 자료로 확인한다. 표의 설명만으로 과거 분배 정책을 확정하지 않는다. 종목/ISIN을 연결하며 이름 변경 때문에 새 종목으로 세지 않는다. 개인 보유·seed·좋았던 수익률로 고른 표본이 아니다.

- 기간은 **2025-01-01~2025-12-31**의 봉인 KRX 공통 시장일이다. 2026년 시점의 직전 완결 연도로 정한 자료 검증 창이며 수익 결과로 고른 기간이 아니다.
- 첫·끝 평가일은 그 창의 공통 시장일에서 정하고 PLAN에 실제 날짜를 적는다. 종목마다 유리한 시작일·끝일을 골라 쓰지 않는다.
- 권리는 이 기간에 분배락이 발생한 사건을 대상으로 한다. 지급이 다음 해로 넘어가면 그 사건의 실제 지급 확인 자료만 필요한 범위에서 읽는다. 미래 전체 가격을 더 받지 않는다.
- 분배락이 시작일 당일인 사건은 첫날 종가에 편입하는 단위 보유의 권리에서 제외한다. 실제 보유 직후 발생한 사건만 반영한다.
- 네 종목의 원행/이력이 없으면 다른 종목·연도로 자동 대체하지 않는다. PLAN에서 그 사실만 질문한다. 해석 가능한 종목만 골라 성공 표본으로 바꾸지 않는다.
- 4종 확인은 1,419종·상장폐지 종목·다른 연도의 검증을 뜻하지 않는다. 전체 확대는 가용 범위·비용을 보고 별도로 판단한다.

## 4. 저장 자료 계약 — 사건·출처·알게 된 시각

원본은 새 연구 폴더에 보존하고 정규화 파일은 원본 참조를 갖는다. 필수 핵심은 다음이다.

| 묶음 | 필요한 내용 |
|---|---|
| 식별 | ticker·ISIN/식별 근거·당시/원문 이름·통화·주당 단위 |
| 현금 사건 | 확정 금액·그 금액의 기준 단위·분배락일·권리 기준일·지급 예정일·확인된 실제 지급일. 없는 값은 null과 사유 |
| 단위 변경 | 분할/병합 등 실제 사건일·전후 단위 비율·원문 근거. 정산이 필요한 미확인 사건은 확인 필요 |
| 출처 | URL/공식 파일명·원본 sha256·문서의 행/페이지·공시/정정 식별자·출처별 조회 범위·수신 시각 |
| 시각·정정 | effective/ex 날짜, 문서에 확인된 published_at, 실제 observed_at, 정정 전후 연결. 미확인 공표 시각을 사건일로 채우지 않음 |
| 완전성 | 종목/기간별 complete·partial·unknown, 확인 근거, 누락/충돌·미지급 확인 상태 |

‘조회 결과 0행’과 ‘해당 기간에 분배 없음이 확인됨’을 구분한다. 연간 합계·월별 정렬·페이지/조회 범위 등 원천이 제공하는 근거로 누락 여부를 확인하며 빈 구간을 임의 0으로 채우지 않는다.

이번 원본을 지금 받았으면 observed_at은 실제 수신 시각이다. 과거 공시일을 알더라도 그때 시스템이 받았던 판이라고 소급하지 않는다. 사후 확정 사건으로 과거 수익을 재구성하는 일과 과거 신호의 실제 정보 가용성은 다르다. **이 산출물을 그대로 과거 ML 특징에 넣거나 PIT 입력으로 인증하지 않는다.**

분배락일은 공식 사건 자료를 우선 쓴다. 제공되지 않으면 해당 시기의 공식 결제 규칙과 공통 시장 달력으로 유일하게 도출 가능한지 근거를 제시한다. 단순히 지급일/기준일에서 하루·이틀을 빼는 추정은 금지한다. 도출한 경우 방법·규칙·캘린더 판을 저장한다.

## 5. 가격 기준과 기업행사 처리

가격은 기존 봉인 KRX 원시 O/H/L/C와 거래량을 읽기 전용으로 사용한다. 실제 자료를 읽는 데 필요한 접점은 재사용하고 공용 reader를 고치지 않는다. 합성 가격·FDR 조정주가에 분배금을 다시 더하지 않는다. NAV는 출처 대조 보조 자료이며 거래 가격이나 지급 현금의 대체값이 아니다.

- 유효 종가·거래량 0은 보유 평가에 사용할 수 있다. 거래 가능이나 매수가 가능하다는 뜻은 아니다. 첫날 참고 편입 가격/거래 가능 조건이 충족하지 않으면 임의 다른 날짜로 옮기지 말고 사유를 기록한다.
- 원시 값·계산값의 유한성, 가격의 양수 여부, 중복 날짜·종목·사건을 검사한다. 필수 값 손상은 확인 필요이며 행을 버려 연속 창을 만들지 않는다.
- 원천 등락/기준가격과 전일 원가격 사이 차이를 사건 날짜 확인에 쓸 수 있으나, 그 차이를 현금 분배금으로 역산해 사실로 저장하지 않는다. 기준가격 칸/관계식의 의미는 PLAN에서 기존 근거를 확인한다.
- 공식 분배·단위 변경으로 설명되지 않는 기준 변화는 PRICE_BASIS_UNRESOLVED다. 가격을 소급 배율로 임의 보정하거나 06의 연결 검사만 통과했다는 이유로 모두 설명됐다고 하지 않는다.
- 분할은 공식 비율과 유효일에 맞춰 단위를 바꾼다. 병합의 단수 정산·합병·상장폐지 등 현금/권리 조건이 미확인인 실제 사건은 보류한다. 이번에 기업행사 전체 처리 엔진을 새로 만들지 않는다.
- 분배와 단위 변경이 같은 날이면 금액의 전/후 단위와 사건 순서가 확인돼야 한다. 확인되지 않으면 계산하지 않는다. 없는 실제 유형은 작은 격리 자료로만 확인한다.

## 6. 산출할 두 기준과 하나의 대조값

**둘 다 세전·거래비용 0인 자료/회계 검증 기준이다. 실제 계좌·세후 성과·전략 채택 결과가 아니다.** 세전은 투자자별 원천징수·계좌 과세를 적용하지 않는다는 뜻이다. 펀드 가격에 이미 반영된 비용·세금을 복원하거나 별도로 다시 차감하지 않는다. 이 네 표본의 거래 가격·분배금은 원화 단위를 공식 원본에서 확인하고, 기초자산이 해외라는 이유로 환율을 다시 곱하지 않는다.

### 6-1. A — 분배락 종가 재투자 가정의 총수익 지수

단위 변경이 없는 날에는 다음을 사용한다.

r_t = (C_t + D_t) / C_(t-1) − 1

T_t = T_(t-1) × (1 + r_t), 시작 지수 100

D_t는 그날 분배락이 되는 확정 현금 분배금이다. 이 지수는 분배락 종가로 즉시 재투자하는 **이론적 지수 규약**이다. 지급 전에 현금을 실제로 사용할 수 있다는 뜻이 아니며, 실제 매수 주문이나 재투자 가능성을 주장하지 않는다.

단위 비율 a_t가 있으면 전일 1좌가 당일 a_t좌가 된 것으로 평가한다. 현금 D_t도 전일 단위로 환산 근거가 확정돼야 하며 r_t = (a_t × C_t + D_t) / C_(t-1) − 1로 계산한다. 현금/단위가 혼합된 미확인 사건에 이 식을 억지 적용하지 않는다.

### 6-2. B — 미재투자 보유의 현금·미수 분배금 원장

첫 평가일 종가에 1좌를 보유하기 시작하는 단위 검산이다. 이후 가격 기준 단위가 바뀌면 공식 사건에 따라 수량을 조정한다. 새 후보 선정·교체·시장 타이밍은 없다.

- 분배락 직전 권리를 가진 수량에 대해 현금 받을 권리(미수)를 인식한다. 분배락일 신규 매수에는 해당 권리가 생기지 않으며 분배락일 매도만으로 기존 권리가 없어지지 않는 경계는 격리 확인한다.
- 지급 예정일은 가용 현금이 아니다. 실제 지급 확인일에 미수를 현금으로 옮긴다. 같은 금액의 이동 자체로 자산이 늘지 않아야 한다.
- 일별 자산 = 보유 원가격 평가액 + 현금 + 확인된 미수. 분배락의 가격 하락을 손실로만 보거나 지급 때 같은 분배금을 다시 이익으로 더하지 않는다.
- 지급일이 평가 끝 뒤면 확정 미수를 따로 남긴다. 확정 금액/권리가 불명확하면 임의 추정하지 않는다. 실제 지급일이 미확인이면 현금 가용성 검증은 미완료다.
- 현금 이자는 0, 재투자는 없다. A의 이론적 재투자와 다른 관행이므로 두 누적 수익이 같아야 한다는 시험을 만들지 않는다.

### 6-3. C — 기존 KRX_BASEPRICE_CHAIN

같은 종목·기간에서 기존 연결 지수를 시작 100으로 환산해 A·B와 나란히 둔다. 차이 날짜·사건·수익 기준의 차이를 기록하되, 단순 불일치만으로 기존 reader 결함이나 H1 수치 오류로 판정하지 않는다. A·B·C의 정의 차이와 자료 결함을 구분한다.

예를 들어 **가짜 자료**에서 전일 종가 100, 분배 5, 분배락 종가 95면 A와 B의 자산은 모두 100이다. 지급 시 미수 5가 현금 5로 옮겨져도 B의 자산은 같다. 다음 날 종가 96이면 A의 지수는 약 101.0526, B는 101이다. 재투자 관행이 달라 생기는 정상 차이이며 어느 쪽을 억지로 맞추지 않는다.

## 7. 성공·부족·종료 기준
