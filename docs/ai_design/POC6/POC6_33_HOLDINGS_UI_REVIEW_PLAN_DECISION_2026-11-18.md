## 1. 보유 현황

| Q5·Q9·Q10 | 펼친 상세에서 요약과 반복되는 수량·평균 매입단가를 뺀다. 상세에는 매입금액·평가금액·매입 기준 비중·시세 정보와 현재가를 둔다. 현재가 `미확인`, 평가금액 `평가 불가`, 매입 기준 비중 `비중 계산 불가`를 각각 표시한다. |

## 2. 종목 관리

- **Q17·Q46.** 상단 [가격 비교 기준일 설정] 일괄 버튼을 제거한다. `ReferenceDateDialog`와 창 전용 대상 선택 함수는 함께 보관하고 사유를 문서에 남긴다. 화면의 기간별 설정·수정·해제는 [History]에서 확인하고, 다건 저장 API 계약은 기존 시험으로 확인한다. 일괄 화면 경로를 내리는 결정을 KS-2 기록에 적는다.
- **Q18~Q21.** [History]의 표시와 개별 편집 라벨을 `비교 시작일`로 맞춘다. 실제 용도는 [시장 흐름 보기]의 종가 변화 설명과 재진입 검토의 비교 출발일이다. PLAN과 목업에서 앞 설계의 ‘그래프 시작점’ 설명을 정정한다. 저장된 값을 열어 볼 수 있고 기준일 없는 새 잔고 등록도 [History]에서 개별 설정할 수 있게 한다. 화면 진입을 설명하는 기준일 코드 주석을 고친다.

## 3. 확인 근거

| 질문 | 반영할 내용 |
|---|---|
| Q22·Q24·Q49·Q52 | 화면 진입 때 기존 `GET /market/etf-compare/summary`를 주간 점검과 같은 기본 인자로 한 번 조회한다. 1개월 상위 30과 인버스·레버리지·합성·선물 제외 조건을 적용한다. 순위는 해당 조회의 실제 기간과 종료 가격 상태로 표시한다. 모집단 안의 하위 30은 `순위권 밖`으로 표시한다. 순위 또는 순위권 밖 결과에 장중 또는 마감 미확인 상태가 있으면 함께 표시한다. 확인 불가 시 `저장 가격 없음` 또는 `같은 기간 수익률을 구하지 못함`처럼 확인된 사유를 쓴다. 순위 조회 실패 상태에서도 해당 종목의 보유·가격 근거를 읽을 수 있게 한다. |
| Q23·Q28·Q33 | PC 화면에서 옛 `Market Discovery TOP 10`, 상세 수치의 반복 안내, 범위 없는 구성 중복 문구를 거른다. 자료 부족처럼 사용자가 확인해야 할 안내는 남긴다. 기존 하락 구간·자료 확인 사유는 행에 표시한다. 개별 주식이 확인되면 `ETF 순위 대상 아님`과 `NAV·ETF 구성종목 해당 없음`을 표시한다. |
| Q25~Q27·Q51 | 겹침은 1개월 상위 10개 후보 목록의 범위와 실제 비교 범위를 구별한다. **현재 응답에는 실제 비교에 사용한 구성 기준일·행 수가 없으므로 `비교 범위 확인 불가`로 안내한다.** `중복 없음`과 겹침 건수는 같은 계산에서 나온 범위를 확인할 때 표시한다. 상위 10행은 비교 상한으로 설명한다. 선택 ETF의 주요 편입과 상태는 상세를 열 때 기존 구성 요약에서 읽고 그 자료의 기준일을 붙인다. |
| Q29~Q32·Q47·Q48·Q50 | 상세를 클릭한 행 바로 아래에 펼친다. 같은 행을 다시 누르면 닫히며, 위 상세가 닫혀 아래 행이 밀릴 때도 클릭한 행의 화면 위치를 유지한다. 5·20 `저장일` 단위를 적용한다. 보유 저장 시각은 분 단위 한국 시각으로 표시하고, 중복된 PC 가격 흐름 기준일은 한 번 표시한다. 시장 기준일이 따로 필요한 경우 이름을 붙인다. 20저장일 KODEX 200 대비는 확인 근거 응답에서 계산된 값을 표시한다. PC 저장 종가의 의미는 도움말에 둔다. |
| Q34~Q37 | 펼친 화면에서는 등락·시장 대비, 가격·거래량·가격 흔들림을 읽고, 세부 창에서는 차트와 선택한 날의 수치를 읽는다. 실측상 10/21은 수익률의 시작 종가, 10/22는 20개 가격을 보여 주는 차트의 첫날이었다. 실제 자료가 주는 날짜를 해당 역할로 표시한다. 0.00%는 `변화 없음`으로 읽고, NAV 원문 안내는 [자세히]에 둔다. |

## 4. 선택 종목의 NAV와 데이터 상태

- **Q3·Q53·Q54.** 두 화면의 첫 표기는 `순자산가치(NAV)`로 쓴다. 선택 상세의 한 묶음에서 시장가·NAV·괴리율·기준일·출처·수집 상태를 읽을 수 있게 하고, 괴리율의 뜻은 도움말에 둔다. 선택 상세의 전체 ETF 표 이동 버튼을 제거한다. 전체 표는 「데이터 상태」에서 조회한다. 사전 밖 출처는 `기타 출처`, 확인되지 않은 상태는 `상태 확인 필요`를 쓴다. 필요하면 [자세히]에서 원문을 확인한다.
- **Q38~Q42·Q44.** 기존 `괴리 확인 필요(3% 이상)`과 `괴리 주의(5% 이상)`의 절대값 기준과 색상을 사용한다. 수집 상태는 `수집됨`·`이전 목록 재사용`·`확인 불가`로 표시한다. 요약은 `가장 최근 기준일`, 각 행은 해당 날짜를 표시한다. 이전 목록 재사용으로 날짜가 재설정된 행의 날짜는 `재저장일`로 표시한다. 사용자용 한국어 표기는 프런트에서 재사용한다.
- **Q43·Q45.** ‘기타’ 요약 건수와 필터 결과를 같은 전체 조회 결과와 조건으로 맞춘다. `partial`을 포함한 고정 자료에서 건수를 대조하고, 수집 상태·출처·괴리율 경계와 음수값도 화면 시험으로 확인한다.

## 5. 문서와 완료 확인

- **Q0~Q2.** 설계·PLAN·목업·결과서에 POC6-33 번호를 사용한다. 목업의 요약과 행 아래 상세 배치를 적용한다. 상세 순서는 가격 방향, 순위, 필요한 자료 안내, 가격·거래량·흔들림 요약, 차트, 구성, NAV다. 사용자 문구는 위 표기를 적용한다.
- PLAN §5로 검증한다. 격리 화면에서 보유 행을 펼치고, 이력에서 비교 시작일을 읽고, 위에서 아래 행으로 확인 근거 상세를 바꿔 연다. 주간 순위는 같은 조건과 자료로 대조한다. 문서와 목업은 공개 저장소의 보유 정보 가림 기준을 적용한다.
- **Q55.** `docs/PROGRAM_TRUTH.md`의 POC6-32 반영 상태 정정만 별도 커밋·push해도 된다. 커밋 대상과 실제 커밋 파일 목록이 그 한 파일인지 대조한다.
