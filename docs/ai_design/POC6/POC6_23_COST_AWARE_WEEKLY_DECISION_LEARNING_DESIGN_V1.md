## 3. 학습 정답 — 20거래일 동안의 행동 결과 차이

### 3-1. 공통 참조 상태

학습에 쓸 상태는 **20bp R0 정책 하나의 과거 경로**에서만 얻으며 학습용 분기도 20bp만 생성한다. 최초 공통 자료 가능 신호부터 현금 100으로 시작해, 당시 정보만으로 R0를 순차 재생한다. R0는 기존 RET_120 후보·RET_60 추세 점수·h=log(1.002/0.998)·비적격 보류·보호 규칙을 그대로 사용한다. 이 h를 새 손실에 맞춰 조정하지 않는다.

한 D에 참조 상태 하나를 두고, 그 상태의 모든 허용 행동을 P/S가 함께 학습한다. S가 방문한 상태를 보고 재학습 자료를 보태거나 반복 수집하지 않는다. 참조 상태 재생과 아래 정답 계산은 실제 가격의 경로 계산이므로 **공식 실행 승인 뒤에만** 한다.

평가 때 P/S는 참조 상태를 복사하지 않는다. 각자의 실제 모의 보유·현금·의도 상태에서 결정하고 다음 상태로 진행한다. 참조 상태와 학습 정책이 방문하는 상태의 차이는 학습 분포의 한계로 기록한다. 이를 없애기 위한 강화학습·반복 정책 학습은 추가하지 않는다.

### 3-2. 정답 정의

같은 참조 상태를 행동 수만큼 분기해 각 행동을 E부터 기존 체결 규칙으로 실행하고, **E를 1일로 센 20번째 한국 거래일 종가 T**까지 평가한다. 분기 중 새 주간 통상 의도는 만들지 않으며, 일별 평가·보호와 발생한 체결 이연은 계속한다. 기존 가격 연결·평가 유효성 계약을 유지한다.

`g(D,a) = [NAV_T(D에서 a 선택) − NAV_T(D에서 KEEP 선택)] / NAV_D`

g는 **20거래일 모의 경로의 비용 포함 평가자산 차이**다. 60일 로그변화·D20·단일 ETF 수익률·총수익·전체 운용 가치가 아니다. KEEP의 g는 정확히 0이다. T의 열린 보유는 평가하고 만기 매도나 가상 청산 비용을 넣지 않는다. 실제 정책에도 20일 만기를 만들지 않는다.

수수료는 분기에서 실제 체결한 거래에 한 번만 적용한다. 과거에 이미 지급한 비용은 시작 상태에 들어 있으며 다시 부과하지 않는다. 거래하지 않은 가격 변화·취소 의도에는 비용을 넣지 않는다.

당시 행동 집합을 먼저 고정한 뒤 미래 자료 유효성을 확인한다. 어떤 행동만 정답이 없으면 그 행동을 삭제해 최선 행동을 바꾸지 않고 **해당 D의 학습 상태 전체를 제외**한다. 정상 취소·이연의 결과가 기존 계약으로 끝까지 평가 가능하면 유효한 정답이다. KEEP만 있는 날은 학습에서 제외하되, 실제 장부에서는 정상 무변경 주로 유지한다. 제외 사유·수와 미래 가용성에 따른 학습 선택의 한계를 기록한다.

20일 분기에는 그 이후의 통상 선택·장기 보유 효용이 들어 있지 않다. 이 짧은 관측 손실이 수주~수개월 운용에 도움이 되는지는 실제 순차 장부로 판단한다. 분기 최선의 누적 수익을 실현 가능한 전략 기준선으로 제시하지 않는다.

## 4. 같은 모형에서 손실만 비교

### 4-1. 모형·입력 변환

P/S 모두 ETF별 34열과 현재 행동의 매수·매도 예정금액 비율을 사용하는 **공유 선형 모형 70계수**다. ETF 코드·과거 실현손익·최근 거래 간격은 학습 입력에 넣지 않는다. 후자는 §5의 사후 평가로만 본다.

판단일 표준화 34열을 u라 하고, 매수/매도 역할 각각 `[1,u]` 35열을 둔다. 해당 행동의 매수 예정금액 비율 b와 매도 평가금액 비율 s를 곱해 두 블록을 연결한다. 없는 역할 블록과 KEEP은 0이다. 이 합성은 금액 규모와 역할을 표현하기 위한 것이며 새 시장 factor를 탐색하는 것이 아니다.

예정금액은 D에서만 계산한다. `v=NAV_D`, `h=현금_D/v`, `s=선택 매도 보유의 D 평가금액/v`, `b=min(0.2,h+(1−c)s)/(1+c)`다. 매도 없으면 s=0, 매수 없으면 b=0. 이는 비용 포함 예산의 **판단용 근사**이며 E의 실제 수량 산식을 대체하지 않는다. 예상 비용 비율은 `k(D,a;c)=c(b+s)`다.

분기별 학습 자료에서만 34열의 평균·표준편차를 정한다. 참조 상태의 후보/보유 중 필요한 서로 다른 ETF를 날짜 내 동일 가중, 날짜 간 동일 가중으로 센다. 상수 열은 0으로 변환하고 수치·목록을 보존한다. 미래 날짜의 통계나 P/S의 평가 중 방문 상태를 표준화에 넣지 않는다.

학습 정답의 규모 s_g는 날짜 간 동일 가중·날짜 내 KEEP 외 행동 동일 가중으로 센 g의 RMS와 10^-6 중 큰 값이다. 두 모형이 같은 u·s_g·행동·정답을 공유한다. `||β||_1 ≤ 1`로 모형군을 고정한다.

`q_beta(D,a;c) = β^T z(D,a) − k(D,a;c)/s_g`

q는 정규화된 순효용 점수이며 KEEP은 0이다. 기본 비용 학습에는 `y_a=g(D,a)/s_g`를 쓴다. 점수에서 비용을 반영했다고 실제 장부 수수료를 면제하지 않으며, 정답 g에서 비용을 한 번 더 차감하지 않는다.

### 4-2. 손실

- **P:** 날짜별 KEEP 외 행동의 `|q_a−y_a|` 평균을 먼저 구한 뒤 날짜 간 평균을 최소화한다.
- **S:** `a_star=argmax_a y_a`일 때 아래 SPO+ 손실의 날짜 간 평균을 최소화한다.

`L_S = max_a(2q_a−y_a) − 2q_(a_star) + y_(a_star)`

이 식은 SPO 원문의 최소 비용 정의에 `cost=−utility`를 대입한 최대 효용 형태다. 실제 선택 손실 `max(y)−y_(argmax q)`의 상계이며 음수가 되면 계산 결함이다. 예측과 정답이 같으면 0이어야 한다. 식 자체의 성질은 유한 행동 집합별로 확인하며, 원문의 모집단 일관성 정리가 우리 상태 의존 자료에서도 자동 성립한다고 주장하지 않는다.

학습·행동 동점은 현재 정보로 정한 고정 순서(통상 거래 수가 적은 것 → KEEP/SELL/BUY/SWITCH → 종목코드)로 처리한다. 미래 결과를 동점 해소에 사용하지 않는다. 예측 선택은 q 최대 행동 하나이며 새 성과 문턱·강화 배수는 없다.

두 손실과 계수 제한은 선형계획으로 표현할 수 있어 전체 장부의 미분이나 새로운 학습 프레임워크를 요구하지 않는다. 기존 환경의 SciPy/HiGHS 사용 가능 여부·버전은 PLAN에서 확인한다. 설치·업데이트 없이 사용 가능해야 한다. 학습은 분기당 두 모형 하나씩, 고정 열·행동 순서·고정 solver 설정으로 한 번씩이며 모형군·계수 한도·관측 기간·정규화·solver를 결과 보고 바꾸지 않는다. 학습용 LP가 여러 최적해를 가지면 고정 환경에서 얻은 반환 계수를 그대로 보존한다.

solver 정상 최적 종료, 계수 제한·제약 위반 최대 10^-7 이내, 직접 계산한 손실과 solver 목적의 차이 10^-7 이내를 확인한다. 수치 허용오차는 정규화된 학습 문제 기준이다. 실패를 다른 optimizer 탐색이나 정상 모형으로 대체하지 않는다.

### 4-3. 시간순 학습

분기 첫 판단부터 사용할 모형은 그 분기 시작 전에 고정한다. C를 분기 첫 한국 거래일의 직전 한국 거래일로 정한다. D가 분기 시작일의 5년 전 같은 날짜 이상이고, T의 한국 거래일 축 위치가 C의 위치보다 최소 20 작거나 같은 참조 자료만 사용한다. 정보와 정답의 끝을 모두 검사한다. 최소는 **KEEP 외 선택과 완전한 정답이 있는 서로 다른 D 104개**이며, 104는 이번 소규모 선형 연구의 계약이지 ML 일반 최소 요건이 아니다. 과거 5,000 ETF 행 기준을 상태 단위에 그대로 옮기지 않는다.

2018~2020 선행 재생과 2021~2026-09-21 주 평가의 최대 35분기·총 70 fit이다. 입력/달력에 따른 정확한 분기는 PLAN과 잠금에서 확인하며, 부족한 분기에 창을 늘리거나 다른 모형을 대신 넣지 않는다. 정답 제외 후 104개 미만이면 INSUFFICIENT_DATA로 중단·보고한다.

40bp 장부도 20bp에서 배운 같은 β·표준화·s_g를 사용하고, 판단용 k와 실제 체결 비용만 40bp로 바꾼다. 자기 장부 상태는 비용별로 따로 진행한다. 40bp 최적 모형을 새로 학습한 결과가 아니다.

## 5. 평가와 AC

2018~2020은 P/S/R/K 20bp 4장부의 유효성 재생이며 설정 선택에 사용하지 않는다. 유효하면 같은 공식 실행에서 2021~2026-09-21의 P/S/R/K × 20/40bp 8장부로 이어간다. 주 평가 보조 구간은 2021~2022·2023~2024·2025~종료다. 모두 독립 시작하며 K도 해당 공통 첫 실행일을 사용한다. 낮은 성과를 이유로 재생을 멈추거나 모형을 선택하지 않는다.

새 정답 가용성 때문에 학습 날짜는 과거 연구와 달라진다. 실제 장부 달력은 POC6-20·21의 공통 입력 가능 주를 재사용하고 **미성숙 미래 정답이나 분기 가용성이 확인되지 않은 미래 가격으로 평가 주를 골라내지 않는다.** 입력 공백 주에도 기존 보유·보호·평가를 유지한다. 이미 본 2021~2026년 구간을 새 독립 시험으로 부르지 않는다.

이 공통 달력의 기확인 값은 선행 계획 153주·주 평가 289주·보조 99/100/90주, K 첫 실행일 2018-01-03·2021-01-05다. 새 연구의 학습 상태 수와 혼동하지 않는다. 같은 reader·입력 계약을 연결했는데 이 값이 달라지면 전수 재조사에 앞서 그 차이 지점만 확인한다.

| AC | 완료 기준 |
|---|---|
| AC1 · 비교 유효성 | 같은 입력·참조 상태·정답·모형군·행동 규칙에서 손실만 다른 P/S. 학습 시점·정답 성숙·자기 상태 평가·기존 코드 불변·수치 조건 충족 |
| AC2 · 순차 장부 | 네 곡선의 체결·보호·현금·비용·취소·Q4 보류를 유효하게 복원. 후보와 실제 행동을 전수 연결 |
| AC3 · 학습 목적의 추가 효용 | 20bp CAGR(S)−CAGR(P) ≥ 연 1.0%p, 보조 세 구간 중 S의 기간 수익이 P보다 높은 구간 ≥2개 |
| AC4 · 사용자 목적 | 20bp CAGR(S)−CAGR(R) ≥ 연 1.0%p, CAGR(S)−CAGR(K) ≥ 연 1.0%p |
| AC5 · 위험·부담 | 20/40bp 각각 S의 낙폭 크기가 P·K 각각보다 5%p 넘게 크지 않고, 최장 고점 미회복 거래일이 K보다 126거래일 넘게 길지 않으며, 연 회전율 ≤6 |
| AC6 · 비용 스트레스 | 40bp에서 CAGR(S)가 P·R·K 각각보다 높음. 재학습이나 비용 설정 탐색 없음 |
| AC7 · 증거·해석 | 아래 필수 보고와 불확실성, 실행/예산/검산 기록이 완비. 연구 수행과 모델 효용 판정을 구분 |

위 차이·허용 범위는 기존 연구와 목적을 참고해 성과 전에 고정한 **이번 연구의 문턱**이며 논문이 입증한 최적 수치나 영구 운용 정책이 아니다. MDD는 음수 표기와 별도로 낙폭의 양수 크기로 비교한다. 회복은 POC6-21의 끝 미회복 포함 계산을 재사용한다.

불확실성은 20bp 주간 S−P 수익 차이에 기존 13주 원형 블록·2,000회·seed 20261026 bootstrap을 적용한다. 통상 판단이 없는 주를 포함한 완결 주 전체를 쓰고 마지막 불완전 주만 제외한다. 주간 평균의 95% 구간이며 CAGR 차이 구간이 아니다. 0을 포함하면 UNCERTAIN, 하한>0이면 이번 연구 내 양의 근거, 상한<0이면 음의 근거다.

AC1·2·7이 유효하면 수행 RESULT는 성과와 무관하게 수용할 수 있다. AC3 충족 시 DECISION_GAIN_OBSERVED, 미충족 시 NOT_SHOWN이다. **후속 검토 후보는 AC3~6과 bootstrap 하한>0을 모두 충족할 때만** 인정하며 그 외는 NOT_CANDIDATE다. 어떤 경우에도 이번 결과의 OPERATION_ADOPTION=NO·TOTAL_RETURN_VALIDATED=NO다.

필수 보고는 CAGR·기간 수익·MDD·최장 고점 미회복·회전율·실제 비용·현금/보유 노출·행동/취소 수, 학습 상태 수·행동 수·제외 사유·각 분기 수치 조건, Q4 보류의 주/금액 노출이다. 최근 0~10한국 거래일의 재진입/재이탈·실제 직전 거래의 이익/손실/동률·반복 묶음 순손익은 POC6-21의 실제 체결 기준으로 비교한다. 해당 사례가 0이면 효과를 판단하지 않으며, 강화가 자동 학습됐다거나 과거 손익별 효과가 인과적으로 입증됐다고 말하지 않는다.

## 6. 범위·진행·문서

### 6-1. 변경 범위와 읽기 전용 PLAN

새 연구의 행동·분기 정답·선형 학습·주간 선택·감사·실행/보고만 새 격리 범위에 둔다. 가격 reader·34열·H1 체결/보호·일반 지표·거래/묶음/회복·기존 bootstrap·잠금 구조는 계약이 같은 부분을 재사용한다. **H1·19·20·21·22 기존 코드/시험/산출물 수정은 0**이다. 새 연구 산출물만 `state/ml/research/poc6_23/`에 쓰고 Git에서 제외한다.

우선 접점은 `app/trend_switch/policy.py`의 상태/체결·보호 호출, `trades.py`, `study.py`, `protocol.py`, `flow.py`, `verify.py`와 그 직접 import다. 시장 입력·가격/자격·감사 접점은 기존 PLAN과 RESULT의 조사 결과를 재사용한다. 전체 저장소·공급자 이력 재조사는 하지 않는다. 함수명·helper 위치 등 같은 계약 내 구현 세부는 개발자가 정한다.

개발자의 다음 산출물은 **실행 가능성 사실과 짧은 PLAN을 한 문서에 묶은 것**이다. 코드·필드·기존 설치 패키지와 날짜/성숙 가능 상한·최대 분기만 읽기 전용으로 확인한다. 참조 장부·g 정답 값·점수·성과는 계산하지 않는다. 상태 의존 유효 학습 D의 정확한 수는 공식 실행의 참조/정답 생성 뒤에만 확정하므로, PLAN에서 이를 이미 실측했다고 쓰지 않는다.

PLAN에는 최소 변경·재사용 범위, SciPy/HiGHS 버전·설치 없음 여부, 자원 추정과 70 fit 상한, 데이터 뜻·계약을 바꾸는 실제 충돌만 적는다. 설치 필요·기존 코드 수정 필수·대규모 새 학습 환경 필수라면 그 사실을 설계자에게 올리고 임의 확장하지 않는다. 설계 판단은 설계자가 맡는다. 별도 역할·중복 설계 검토 라운드를 추가하지 않는다.

### 6-2. 승인 뒤 실행의 경계

공식 실행은 한 번의 고정 묶음이다. 참조 경로·정답 생성 → 분모/성숙/수치 조건 → 최대 70 fit → 선행 재생 → 주 평가 → 보고/검산 순서이며 성과에 따른 선택은 없다. 상한은 **90분·RSS 8GiB·CPU 최대 4스레드**, 학습 solver는 단일 스레드로 고정한다. 실행 시간 추정은 아직 실측하지 않았으며 PLAN에서 제시한다.

작은 가짜 자료로 행동 제약·분기 정답·SPO+ 부호/상계·손계산·수치 조건·장부 연결을 확인한다. 기존 연구 전체를 재실행해 검증하지 않는다. 공식 산출물 검산은 저장 입력/계수·행동·장부·지표·원문 해시를 확인하고 재학습하지 않는다. F1/F2 교훈대로 보고·목록·해시 등 후처리 계산까지 끝난 뒤 정상 완료 직전 한 곳에서 최종 예산을 확인한다.

계약 충돌·자료/학습 부족·수치 실패·상한 초과는 정상 성과로 덮지 않는다. 부분 산출물과 중단 사유를 보존하고 해당 원인을 먼저 판정한다. 성과 미달은 오류 수정 실행의 사유가 아니다. 한도·기간·모형·손실 조합을 바꿔 합격할 때까지 반복하지 않는다.

PLAN 판정 뒤 이번 연구의 구현·격리 확인·공식 실행에 필요한 사용자 승인 범위를 별도로 확인한다. 기존 POC6-21·22 승인이나 적용성 판정은 이 실행 승인이 아니다. 이 설계에는 커밋·push·배포 명령이 없다.

### 6-3. 문서와 한정 예외

이 설계와 적용성 판정 원문을 보존하고, STATE_LATEST·PROGRAM_TRUTH는 단계의 실제 상태만 갱신한다. 기존 POC6-22 CLOSED·Q6 OPEN·운영 ML 미승격·총수익 및 #3/#55/#57/#62 미완료는 유지한다. 사용자 소유 handoff·원자료·과거 산출물은 수정하지 않는다.

세 기반 문서의 기존 예외에 다음 독립 원문을 추가하는 범위다. 기존 문장·다른 연구 예외를 삭제하거나 전역 ML 허용으로 바꾸지 않는다.

Q6 OPEN·운영 ML 미승격을 유지한다. 이 예외는 기술 범위이며 구현·공식 실행은 해당 단계의 유효한 사용자 승인 범위에서만 진행한다.

## 7. 하지 않는 것과 보류 위험

이번에는 부분 축소·연속 비중 학습·개인화 손익 학습·새 국면 탐지·강화학습·새 자료원·UI/권고 연결·자동 주문을 넣지 않는다. 기존 POC6-21의 강화 배수·기간을 재시험하지 않는다. 새 프레임워크·일반 반사실 플랫폼·전체 장부의 미분 가능 재구축도 하지 않는다.

남는 위험은 참조 상태와 실제 방문 상태의 차이, 20일 분기와 장기 운용의 차이, 선형·가산적 행동 표현의 한계, 이미 본 기간, 총수익 부재, 비적격 보유 보류다. 모두 결과 해석에 남기며 이번 연구의 성공으로 해결 처리하지 않는다.

- 보류 사유: 추가 자료·학습 방식·운영 연결을 동시에 바꾸면 이번 학습 목적 비교가 흐려진다.
- 보류된 위험: 위 한계로 인해 연구 결과를 실제 계좌·운영 효용으로 옮길 수 없다.
