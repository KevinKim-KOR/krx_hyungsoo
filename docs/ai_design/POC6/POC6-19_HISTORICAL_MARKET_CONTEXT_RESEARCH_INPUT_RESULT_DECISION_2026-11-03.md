## 1. 판정과 재개 지점

**단계 판정: PARTIAL — 코드·시험·Yahoo 선행 결과는 수용한다. 중단 계약 1건의 정정과 키움 실제 결과 확인이 남았다. POC6-19 전체 종료나 다음 ML 연구 착수는 아직 아니다.**

최신 결과서 §13의 검증자 r3 VERIFIED를 해당 범위의 근거로 수용한다. 앞선 r1·r2 REJECTED의 F1·F2·F3는 정정·재검증으로 해소됐으며, 이를 미해결 결함으로 다시 요구하지 않는다. 다만 검증자가 명시적으로 설계자 판단에 남긴 계약 차이는 별도로 판정한다.

붙여 넣은 최초 PLAN 보고의 ‘외부 조회·구현 0’보다 첨부 RESULT의 최신 이력이 우선한다. PLAN 재작성이나 완료된 구조 조사는 요구하지 않는다. 사용자 ‘모두 승인’과 ‘Yahoo 실측·코드 검토 먼저’ 결정은 제출된 PLAN·RESULT의 결정 기록으로 수용하며 같은 승인을 다시 묻지 않는다.

### WTI 사본의 정확한 의미

이번 `ARCHIVE_READY`는 원시를 확보하고 **명시된 현행 정규화 규칙에 따른 사본을 검산했다**는 뜻이다. 모든 완료 일봉을 빠짐없이 담았다는 인증은 아니다. 원시에는 있지만 기존 비자정 필터로 제외된 23일과 빈 종가 5일, 휴장 가능성이 섞인 평일 공백을 구분한다.

이번 단계에서 공유 Yahoo 어댑터를 고치거나 성공 자료를 재조회할 필요는 없다. 해당 원시와 제외 목록을 보존한다. 이후 실제 연구 입력을 정의할 때 이 23일의 완료 일봉 여부·날짜 해석과 포함 방식을 원시 근거로 정하며, 그 결정을 성과를 본 뒤 바꾸지 않는다. 현재 정규화 자료를 완전한 WTI 거래일 계열이라고 전제한 연구로 넘어가지 않는다.

신규 BACKLOG는 추가하지 않는다. 공급자 중단 계약은 이번 Step의 정정 대상이며, 자료 한계는 이번 결과와 이후 입력 정의에 연결해 남긴다.

## 4. 같은 POC6-19에서 남은 처리

1. **개발자가 중단 계약을 정정한다.** A의 날짜·구조 연속 3건 실패로 공급자가 중단되면, 같은 실행의 해당 공급자 B 요청은 0회여야 한다. 이미 확보한 원시와 실패 기록은 보존한다. 다른 공급자·심볼은 기존 분리 계약에 따라 계속할 수 있다. 인증 실패·호출 제한·구간/자원 상한의 기존 중단 조건은 유지한다.
2. **변경된 경로만 확인한다.** 위 A→B 중단과 이미 확인된 연속 통신 실패 경로를 관련 시험으로 확인하고, 검증자는 그 변경분을 확인한다. PARTIAL 보고에 평일 공백을 쓰는 경우 §3의 해석 한계도 포함한다. 전체 회귀·프런트 검사·59종 변이 전수·기존 F1~F3 심사 전체를 반복 요구하지 않는다. 기존 Yahoo 원본과 과거 검증자 원문은 수정하지 않는다.
3. **등록 IP 망 전제가 충족되면 기존 승인 범위에서 실제 키움 A→조건부 B를 진행한다.** 사용자 결정으로 이미 예정된 공식 전체 실행 1회는 인정한다. Yahoo를 다시 받아야 한다는 새 검증 요구는 없다. 선행 사본은 계속 보존한다. 이미 등록망 실행을 마쳤다면 새로 실행하지 말고 그 기록·결과부터 제출한다.
4. **실제 결과를 채우고 결과 부분을 확인한다.** 키움 요청일·응답 날짜의 직접/간접 근거·지수 대조·13분류·단위·실패/중단·실제 확보 범위와 검산, 봉인 가격과의 날짜·주 공통 범위를 보고한다. 자료별 상태를 분리한다. 앞선 68일은 ‘지수 대조 근거 없음·미요청’이지 공급자 미제공이 아니다.
5. **기존 PLAN·RESULT와 STATE를 현재 사실에 맞춘다.** ‘승인 대기’, ‘실제 조회 전부 0’, ‘키움 실행 예정’ 같은 문장은 적용 범위를 밝혀 최신 상태와 구분한다. 현재는 코드/Yahoo 확인 완료·키움 미확인·설계자 중단 계약 정정 필요다. PROGRAM_TRUTH는 확인된 구현·현재 운영 경계만 반영하며, 당시 원문과 과거 실행 이력은 보존한다.

현재 PARTIAL 판정으로 전체 작업을 종료하거나 기존 조건부 커밋·push 게이트를 완료했다고 처리하지 않는다. 코드 변경분 확인과 실제 결과 확인 뒤 같은 POC6-19의 최종 RESULT 판정으로 가져온다. 별도 POC·새 PLAN·전체 인계는 만들지 않는다. 접근이 계속 막히면 확인된 차단 근거와 확보 범위를 보고해 종료 범위를 판단한다.

## 5. 유지할 전체 방향

이 단계는 다음 연구에 쓸 시장 자료를 확보하는 작업이다. 12년 이상의 Yahoo 이력이 실제 확보됐다는 점은 진전이며, 저장된 57주를 공급자의 최대 이력으로 볼 이유가 없어졌다. 수급에 대해서는 아직 같은 결론을 내리지 않는다.

과거 자료 연구와 전향 축적을 병행한다. 이번 사본을 과거 당시 확보 판·새 미사용 시험·ML 성과·운영 채택으로 바꾸어 부르지 않는다. 한국 신호 시점에 이용 가능한 정보 시각, 연구 가설·목표·모델·분할·비용·채택 기준은 이번에 정하지 않는다.

Q6 OPEN·운영 ML 미승격·#3/#55/#57/#62 미완료·총수익 자료 한계와 기존 운영은 유지한다. 다음 기능 단계는 이번 미완료를 해소한 뒤 별도 설계에서 판단한다.
