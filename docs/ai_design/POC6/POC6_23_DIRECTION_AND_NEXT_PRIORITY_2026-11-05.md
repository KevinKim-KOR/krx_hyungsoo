# POC6-22 이후 방향 정리와 다음 우선순위

작성: 총괄 설계자 · 2026-11-05

## 1. 현재 판단

**프로젝트가 정보 누적만 하며 기다리는 상태는 아니다.** POC6-22에서 보류한 것은 기존 자료·목표에서 모델 이름이나 문턱만 바꾸는 반복 실험이다. 새로운 접근의 근거를 찾고, 우리 운용 목적에 맞는지 판단하는 설계 작업은 진행한다.

최신 사용자 완료보고 기준 POC6-22는 PASS · IMPLEMENTED_VERIFIED_CLOSED이며 `d050c83d`의 push까지 끝났다. 이 문서는 종료를 다시 심사하거나 POC6-22에 작업을 추가하지 않는다. 실제 저장소·PC·OCI를 여기서 새로 확인한 결과는 아니다.

## 2. 완료와 미완료 구분

| 구분 | 현재 판단 |
|---|---|
| POC6-19~22의 정해진 조사·구현·진단 | 각 최종 판정대로 종료 |
| 유용한 ML의 추가 효용과 운영 채택 | 미완료 |
| 비용 후 KODEX200 대비 투자 효용 입증 | 미완료 · 총수익 검증도 미완료 |
| 기존 수집·전향 기록·실제 주간 검토 | 계속 사용하고 기록 |
| 같은 시험에서 문턱·모델만 바꾸는 반복 | 보류 유지 |

POC6-20의 한정 추가 효용 관측과 POC6-21의 NOT_CANDIDATE·UNCERTAIN을 함께 유지한다. 연구 수행 PASS를 모델 채택 PASS로 바꾸지 않는다.

## 3. 지금 설계자가 맡을 단일 과제

**예측값의 오차를 줄이는 학습과 별개로, 거래비용·교체 부담을 포함한 운용 효용을 학습에 연결하는 접근이 우리 계약에서 검토할 가치가 있는지 판단한다.**

POC6-22에서는 MAE 감소와 운용 효용을 같은 것으로 볼 수 없음을 확인했다. 이것이 기존 실패의 원인을 학습 목적 하나로 확정한 것은 아니다. 다음 검토는 그 미확정 원인을 단정하지 않으면서, 기존 실험과 다른 방법론의 근거를 평가하는 일이다.

‘무릎에 진입해 어깨에서 이탈’하려는 목적을 유지한다. 바닥·고점의 정확한 예측이나 매매 횟수 자체의 증가를 목표로 바꾸지 않는다.

## 4. 외부 방법의 1차 확인과 우선순위

| 방법 | 원문에서 확인한 내용 | 우리 프로젝트와의 차이 | 이번 판단 |
|---|---|---|---|
| 운용 효용·비용을 반영하는 학습 | Deep Momentum Networks는 추세·포지션 크기를 함께 학습하고 Sharpe 목적과 turnover regularisation을 제시한다. [1] | 88개 연속 선물, 변동성 조정 포지션, 다른 비용·거래 구조다. 초록의 2~3bp 성과를 우리 20/40bp 성과 근거로 옮길 수 없다. | **우선 적용성 검토. 그대로 도입하지 않음.** |
| 온라인 변화점 탐지 | 변화점의 위치·심각도를 활용해 느린 추세와 빠른 반전을 결합한다. [2] | 빠른 포지션 반전은 수주~수개월 보유·교체 부담 관리와 충돌할 수 있다. | 비교 후보로만 남김. 병행 구현·실험하지 않음. |

확인 범위는 두 논문의 초록과 [1]의 서론·비용 처리 관련 본문 일부다. 전체 최신 본문, 저자 코드, 라이선스, 재현 가능성을 모두 검토했다고 주장하지 않는다. 논문 결과는 국내 ETF에서의 유효성 증거가 아니다.

## 5. 적용성 판단에서 해결할 사항

다음 판단은 총괄 설계자가 맡으며, 현재 개발자에게 구현 PLAN이나 추가 성과 집계를 요구하지 않는다.

1. 비용 후 KODEX200 초과성과라는 주목적을 유지하면서 이 방법의 어떤 부분을 사용할 수 있는지 설명한다. Sharpe 개선만으로 성공을 대신하지 않는다.
2. 한국 상장 ETF의 매수·보유·현금 운용, 주간 검토, 일별 보호 확인 및 교체 부담을 학습 문제와 모순 없이 연결할 수 있는지 판단한다. 선물 포지션·공매도·레버리지를 가져오지 않는다.
3. 기존 자료로 가능한 범위와 새로운 자료가 실제로 필요한 부분을 구분한다. 총수익 자료의 한계를 숨기거나 신규 데이터 플랫폼을 자동 선행조건으로 만들지 않는다.
4. 이미 본 2021~2026년 기간을 새 독립 시험으로 부르지 않는다. 후속 연구를 제안하려면 탐색 예산과 시간순 평가의 한계를 먼저 명시한다.
5. 이론·자료·운용 제약 중 핵심 충돌이 남으면 ‘현재 적용 부적합’으로 끝낸다. 모델을 돌려서 적용성을 대신 판단하지 않는다.

이 판단의 완료 산출물은 **적용 가능 / 제한적 가능 / 부적합과 그 이유**, 기존 연구와의 차이, 필요한 변경·자료·평가의 범위다. 제한적 가능 이상이어도 연구의 가치가 부족하면 새 실험을 열지 않는다. 구체적 근거가 충분할 때에만 하나의 후속 Step을 별도 설계한다.

## 6. 유지할 경계

- 확정 운용 방향, 사용자 최종 판단·주문, PC 검토 권고 및 Telegram 관찰·브리핑 계약을 유지한다.
- 기존 수집·전향 기록·주간 실사용은 계속한다. 자체 자료가 몇 년 쌓여야만 설계할 수 있다는 조건을 만들지 않는다.
- 이번 문서는 새 모델·factor·라벨·문턱·실행 횟수를 확정하지 않는다. 학습·백테스트·외부 데이터 API 실행·운영 채택을 승인하는 문서가 아니다.
- 닫힌 실험의 원본·결론을 수정하거나 반복 실행하지 않는다. 제품 코드·UI·OCI 변경, 커밋·push·배포 지시는 없다.
