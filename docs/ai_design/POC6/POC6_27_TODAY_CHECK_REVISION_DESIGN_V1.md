## 2. 요약과 자료 최신화

[?]에는 다음 문장만 먼저 보여준다.

> 저장된 값만 다시 읽습니다. 시장 판정과 요즘 잘 오르는 ETF 목록은 이 버튼으로 다시 계산하지 않습니다.

[요약 다시 읽기]와 [AI용 시장 정보 복사]는 각각 사용할 저장 자료의 상태를 먼저 확인한다. 오래된 자료나 기준 확인이 필요한 자료가 있으면, 화면에 요약을 반영하거나 원문을 복사하기 전에 선택을 받는 것으로 PLAN을 작성한다.

| 상태 또는 선택 | 화면 동작 |
|---|---|
| 사용하려는 자료가 최신이고 확인됨 | 해당 동작을 바로 진행한다. |
| 사용하려는 자료가 오래됐거나 상태를 확인할 수 없음 | “최신 상태를 확인해야 할 자료가 있습니다. 현재 저장된 자료로 계속할까요?”를 띄운다. 자료별 마지막 저장일과 확인 사유를 한 줄씩 표시한다. 기대 기준일은 확인되는 경우에 붙인다. |
| [이 자료로 계속] | 해당 자료의 기준일과 오래됨·확인 불가 표시를 붙여 요약하거나 복사한다. |
| [취소] | 확인 상자를 닫고 상단의 두 최신화 버튼을 사용할 수 있게 한다. |
| 최신화 버튼을 누름 | 보유 현재가와 시장 자료는 각각 기존 갱신 동작을 사용한다. 진행 중에는 같은 작업을 중복 실행하지 않고, 완료·일부 실패·실패와 실제로 갱신된 기준일을 구별한다. |

최신성은 자료별 기존 기준으로 확인한다. 코스피 종가는 11/6까지 있고 외국인 수급은 11/5까지 있을 수 있다. 이 경우 ‘공통 비교는 11/5까지’라고 설명하고, 실제로 최신화가 필요한 자료가 있을 때 그 사유를 따로 표시한다. 구성종목·NAV의 자료 확인 건수와 연구 진행 상태는 그 자체로 시장·보유 요약의 진행 여부를 묻는 조건으로 쓰지 않는다.

11/9 확인 사례에서는 기대 기준일이 11/6이다. 코스피·KODEX 200·WTI는 11/6 자료가 있고 외국인 수급과 원/달러는 11/5 자료까지 있어 두 항목을 확인 창에 표시한다. 지연 원인은 확인 전 상태다.

기대 기준일은 기존 완료 거래일과 각 자료의 날짜 기준에서 확인한다. 기준일을 확인할 근거가 부족한 항목은 ‘기준 확인 필요’로 표시한다. 외국인 수급과 원/달러의 최신성 판정에 필요한 기존 경로와 적용할 규칙은 PLAN에 명시하고 설계 판정에서 확인한다.

## 3. 시장 흐름

### 먼저 읽는 내용

- **시장 판정**에는 기존 KODEX 200 판정값과 기준일을 붙인다. 화면 사례의 판정은 ‘하락장 · 21거래일째 · 11/6 기준’이다.
- **코스피 흐름**에는 6개월 변화의 방향을 글자 배지로 보여주고, 최근 20·60거래일 변화와 각 기준일을 줄을 나눠 보여준다. 20·60거래일은 기존 시장 판정 응답의 거래일 기준 수익률이다. 6개월은 수급과 맞춘 기존 시장 흐름 응답의 기간 값을 쓴다.
- **KOSPI 가격 흐름 차트**는 코스피 수치 바로 아래에 둔다. 화면에서 쓰는 기존 저장 종가 시계열 전체를 표시한다. 외국인 수급은 차트 아래에서 시작한다.
- **최근 변화와 외국인 수급**은 각각 한 문장으로 적는다. 가격의 움직임과 매도 속도 변화가 같이 보이도록 한다.

화면에서 읽히는 문장 예시

> 11/6 코스피는 **5,059.69**에 마감했습니다. 전날보다 **324.11pt(6.02%) 하락**해 11/5의 최근 저점 5,383.80을 밑돌았습니다.
>
> **20거래일 −23.64% · 60거래일 −19.16%**(11/6 기준)
>
> **6개월 [하락] −22.39%**(5/4~11/5 · 수급과 같은 기간)
>
> 외국인은 이 6개월 동안 **164.3조원 순매도**했습니다. 하루 평균 순매도액은 직전 20거래일 **1.2조원**에서 최근 20거래일 **1.1조원**으로 줄었습니다(11/5까지).

‘최근 저점’ 옆의 [근거 보기]에서 비교에 쓴 날짜·종가를 확인한다. 사건의 괄호에는 비교 구간의 최저값과 날짜가 나오고, 사건 발생일의 종가는 저장 종가에서 읽는다. 11/5 종가 5,383.80은 앞선 저점인 10/26의 5,469.47보다 낮았고, 11/6 종가 5,059.69는 11/5의 저점을 다시 밑돌았다. ‘60거래일 최저’ 같은 표현은 해당 기간의 최저값을 자료에서 확인할 수 있을 때만 쓴다.

원/달러나 WTI에서도 기존 자료에 값과 비교 대상이 함께 있는 최근 변화는 필요할 때 한 줄로 풀어 보여 준다. 상세에는 6개월 비교 구간, 외국인 수급 비교 기간, 최근 사건의 전체 근거와 자료별 기준일을 둔다. 11/5와 11/6처럼 날짜가 다르면 ‘가격은 11/6까지, 수급과 함께 보는 비교는 11/5까지’처럼 해당 값과 이유를 짝지어 적는다.

상단 시장 배지는 §3과 같은 KODEX 200 판정값을 사용하고, 보유 배지는 기존 보유 하락 구간을 표시하는 안이다. 보유 근거를 다시 읽을 때 계산되는 시장 판정값은 해당 상세에서 기준을 붙여 읽는다. 11/9 대조에서는 두 값이 하락장 · 21거래일째로 일치했다. 보유 수와 하락 구간 수는 종목 기준으로 표시하고 같은 종목의 계좌별 비중은 합산한다. 현행 하락 구간은 저장 종가 21개로 계산한 20구간 변화가 소수 첫째 자리 반올림 후 −5.0% 이하인 경우다. 26개 중 23개는 10% 이상, 3개는 5~8% 구간이다. 기본 화면은 저장 종가 기준을 밝히고, 구간 판정이나 비중을 확인하지 못한 경우에는 해당 범위와 사유를 표시한다.

[확인 근거 보기]에서 개별 종목과 상세 판단 근거를, [보유 현황 보기]에서 보유 금액과 구성을 확인한다. 시장 국면 일수·구간 판정 가능 건수처럼 의미를 검산하는 내용은 상세나 [?]에 둔다.

### 잘 오르는 ETF

현재 ‘외 9개’는 1위와 함께 같은 1개월 목록을 구성하는 나머지 9개다. ‘상위 3개’는 그 10개에서 앞의 세 종목을 아래에서 다시 보여 준다는 뜻이다. 현행 대시보드는 1개월 기준으로 따로 조회한다.

「오늘의 투자 점검」과 「요즘 잘 오르는 ETF」는 **같은 기간·정렬 기준과 방향·제외 조건**을 사용한다. 이번 PLAN 기준은 **같은 브라우저 탭에서 메뉴를 이동하는 동안 마지막 적용 조건을 공유**하는 것이다. 화면을 새로 고치면 기존에 저장한 기본 기간과 기존 기본 정렬·제외 조건으로 시작한다. 두 화면과 아래 첫 3개는 그때 실제 적용한 조건을 표시한다.
