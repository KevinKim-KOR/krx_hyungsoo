## 2. 결과와 해석

| 항목 | 결과 |

| A 무조정 가격 수익 | +89.98% |
| B 분배금 포함 현금 보유수익 | +92.64% |
| C 기존 연결 가격 수익 | +94.24% |
| B − A 현금 수령 기여 | +2.67%p |
| C − A 두 가격 기준의 차이 | +4.27%p |

차이는 표시 전 값에서 계산해 각각 소수 둘째 자리로 반올림한다. 이 표본에서 연결 가격 장부는 분배금 현금 보유 장부보다 1.60%p 높았다. 팩트시트 성과의 분배금 재투자와 이번 현금 보유 장부는 각각의 정의로 해석한다. 기존 연구의 성과는 각 연구가 사용한 가격 기준으로 해석하며, 프로젝트의 분배금 포함 성과 검증은 이번 표본과 구분해 미확보로 기록한다.

기존 승인 ④의 조건이 충족됐다. 이 판정 원문을 `docs/ai_design/POC6/`에 보관하고 결과서·PLAN·STATE_LATEST·PROGRAM_TRUTH에 RESULT PASS와 `SAMPLE_RECONCILED` 범위를 반영한다. 결과서 §10의 검증자 기록은 보존하고 그 뒤에 최종 판정과 종료 기록을 추가한다.
