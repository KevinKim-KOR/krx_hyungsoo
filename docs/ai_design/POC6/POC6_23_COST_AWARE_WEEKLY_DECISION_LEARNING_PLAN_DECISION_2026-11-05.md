## A. PLAN 판정

**PLAN = PASS. Q1~Q3는 모두 (a)를 수용하고, 아래 데이터·행동·수치 계약으로 확정한다. 기존 PLAN에 반영한 뒤 별도 재제출 없이 사용자 승인 한 묶음 단계로 진행한다.**

이는 구현·공식 실행 승인이나 모델 채택 PASS가 아니다. 아직 유효한 사용자 승인이 없다는 PLAN §7의 경계는 유지한다. 이번 판정문 뒤의 B는 변경을 반영한 전체 통합 설계 V1 개정 2이며, 원 설계 V1과 충돌하면 이 판정과 B를 우선한다. 원 설계는 보존한다.

### A-2. Q1 — 정상 특징 결측의 한정 평균 대치: (a) 수용

후보 3,095행 중 결측 9행(8일)이 있다는 사실을 근거로, 결측마다 행동을 삭제하거나 장부를 중단하는 대신 **P/S 선형 입력 사본의 표준화 단계에만 평균 대치**를 허용한다. 표준화 뒤 0은 그 분기의 학습 평균 위치라는 뜻이며 원래 factor 값 0을 관측했다는 뜻이 아니다.

확정 계약은 다음과 같다.

1. H1 특징 계산에서 정의된 정상 특징 결측(None)만 대상으로 한다. 원시/봉인 사본·기존 특징 파일·H1·시장 4열 정의·R0 원본 정책은 수정하지 않는다. 가격·보유 평가·필수 읽기 오류·예상 밖 비유한 값·시장 공통 입력 공백을 평균으로 덮지 않는다.
2. 실제 해당 분기의 유효 학습 D에 필요한 후보/보유 ETF를 사용한다. 같은 D·ETF가 여러 행동에 쓰여도 통계에서 한 번만 센다. KEEP의 0 블록·없는 역할의 0 블록은 관측 값이 아니다.
3. 열별로, 각 날짜의 결측 아닌 ETF들에 같은 비중을 주고 해당 열의 관측이 있는 날짜들에 같은 비중을 준다. 평균 μ를 이 가중치로 구하고, 분산은 같은 가중치의 `(x−μ)^2` 평균인 모집단 분산으로 구한다. 열 전체가 결측인 날짜는 그 열의 통계에서만 빠지며 유효 정답 D를 자동 삭제하지 않는다.
4. 유효 관측이 전혀 없는 필수 열이면 CHECK_REQUIRED로 중단한다. 관측은 있지만 표준편차가 0인 상수 열은 기존대로 변환값 0이다. 나머지 열은 결측 아닌 값을 `(x−μ)/σ`로 표준화한 뒤, 정상 결측 칸만 0으로 둔다.
5. 평가에서도 해당 분기의 같은 μ·σ를 사용한다. 평가 자료로 통계를 다시 맞추지 않는다. 결측 지시 열을 추가하지 않아 70계수 모형군을 유지한다. 행동·후보·공통 달력은 결측 대치 때문에 바꾸지 않는다.
6. 분기별 열의 관측 수·결측 수·상수 여부와 장부별 대치 칸 수를 기록한다. D·ETF·열 기준과 행동별 중복 사용 수를 혼동하지 않는다. 원자료 관측과 대치를 구분해 보고한다.

이것은 H1의 ‘0·중앙값 채움 없음’을 전역 변경하는 판정이 아니다. **POC6-23 P/S 선형 표현에 한정한 예외**이며 B §6-3의 독립 예외 원문에도 반영했다. R0의 RET_60·RET_120, 자격·Q4 규칙은 그대로다.

### A-3. Q2 — 보호 예정 슬롯과 잔차 예산: (a) 수용

보호 매도가 이미 예정된 보유는 예상 빈자리로 셀 수 있다. 당시 확정된 의도를 이용하는 것이며 미래 체결 성공을 알고 빈자리로 세는 것이 아니다.

P/S 행동 생성과 학습 분기의 행동 집합에서 다음을 고정한다.

- 이전 통상 의도가 미결이면 먼저 KEEP만 허용한다.
- 예정 슬롯 = `5 − 현재 보유 수 − 살아 있는 매수 대기 수 + 이번 행동의 매도 수 + 현재 보유 중 살아 있는 보호 매도 수`. 서로 다른 보유를 세며 보호 예정 종목을 이번 통상 매도로 중복 선택하지 않는다. BUY를 포함하려면 예정 슬롯 ≥1이다.
- 예산 조건은 `h+(1−c)s > 10^-9`다. h·s는 NAV_D로 나눈 비율이며 c는 그 장부의 비용이다. 보호 예정 매도의 예상 대금은 이 식에 더하지 않는다.
- 10^-9는 계산 잔차를 0 예산으로 구분하는 고정 수치 경계다. 원화 최저 매매금액·수익 문턱·모형 선택 기준이 아니며 장부 잔액을 사후 보정하는 값도 아니다.
- 실제 매수 직전에는 실제 매도/보호 체결이 반영된 보유 수·현금·매매 가능 여부를 확인한다. **빈자리가 실제로 없으면 매수를 취소하며 보유 5종을 초과하지 않는다.** 이미 체결된 매도를 되돌리지 않는다. 기존 체결 함수가 슬롯 검사를 보장한다고 추정하지 말고, 필요하면 새 연구 경계에서 보장한다. 기존 코드 수정 0은 유지한다.

새 결정은 R0 기준선 정책을 바꾸라는 뜻이 아니다. P/S 행동 집합과 참조 상태의 행동별 분기에 같은 계약을 적용하고, R0는 기존 정책대로 재생한다. 미래 가격으로 행동을 미리 삭제하거나 체결 실패를 가상 성공으로 바꾸지 않는다.

### A-4. Q3 — 40bp의 b·z·k: (a) 수용

40bp 장부에서는 **행동 예산 조건·b·z의 매수 블록·k 모두 c=0.004**를 사용한다. s·h·NAV_D는 해당 40bp 자기 장부 상태에서 구한다. β·μ·σ·s_g는 20bp 학습값을 그대로 사용한다.

20bp로 만든 b를 40bp z에 넣고 k만 바꾸지 않는다. 원 설계의 ‘판단용 k와 실제 비용만 40bp’는 **모형을 다시 학습하지 않고, 장부 비용이 들어가는 행동/표현 계산을 일관되게 40bp로 바꾼다**는 뜻으로 명확히 한다. 40bp 학습 정답·별도 fit·새 정규화·비용 탐색은 없다.

### A-5. 추가 명확화 — LP 전체 목적값과 절대 차이

PLAN §3의 ‘직접 계산 손실 − solver 목적 ≤10^-7’는 **절대 차이**로 고친다. 한쪽 방향의 차이만 검사하면 큰 음의 오차를 통과시킬 수 있다.

SPO+의 q에는 알려진 비용 오프셋이 있다. 다음처럼 정의한다.

`κ_a = k_a/s_g`, `q_a = β^T z_a − κ_a`

LP 변수 m_D의 제약은 PLAN대로 `m_D ≥ 2q_a−y_a`이며 KEEP도 포함한다. LP 구현에서 β와 무관한 상수항을 목적에서 생략했다면 전체 목적값은 다음과 같다.

`C_fixed = 날짜 평균(2κ_(a_star)+y_(a_star))`

`LP_full = solver.fun + C_fixed`

이때 solver.fun의 가변 부분에는 `날짜 평균(m_D−2β^T z_(a_star))`가 모두 들어 있어야 한다. 상수까지 목적에 이미 표현했다면 다시 더하지 않는다. 구현 방식과 무관하게 **직접 계산한 전체 평균 손실과 동일한 양**을 비교한다.

고정 기준: 정상 최적 종료·L1/제약 위반 ≤10^-7·`abs(직접 평균 손실−LP_full) ≤10^-7`. raw solver.fun·고정 상수·전체 목적·직접 손실·절대 차이를 저장한다. 상수항을 빼둔 raw solver.fun이 음수라는 사실만으로 SPO+ 손실이 음수라고 판단하지 않는다. 실제 SPO+ 상계·0/음수 경계는 전체 손실로 확인하며 수치 허용오차와 산술 오류를 구분한다.

가짜 자료의 기존 손계산/작은 LP 확인에 비용 오프셋이 0이 아닌 경우와 양/음 방향의 목적 오차를 포함한다. 이 명확화 때문에 기존 시간 측정이나 전체 연구를 다시 돌릴 필요는 없다.

### A-6. 실행·비교 해석의 확정

1. SciPy/HiGHS 옵션 전달은 현재 버전에서 측정한 동작으로 한정한다. 공식 연구는 새 Python 프로세스에서 시작하고, **첫 solver 호출부터 모든 호출을 같은 도우미·threads=1**로 처리한다. 기본값 선행 호출·설정 실패 뒤 기본값 대체를 하지 않는다. 옵션 전달 알림을 전체 경고 무시로 확대하지 않는다. 버전·solver 방법·스레드 환경은 잠금/실행에 보존한다.
2. 168~248은 날짜/성숙 조건만 적용한 상한이다. 실제 유효 D의 최소 104개는 공식 참조·정답 생성 뒤 확인한다. 부족하면 INSUFFICIENT_DATA로 멈추고 창·행동·기준을 바꾸지 않는다.
3. 독립 시작은 2018 선행과 2021 주 평가 두 번이다. 보조 99/100/90주는 같은 주 평가 장부의 연속 경로에서 기간 수익을 자른 값이다. 보조 구간마다 자산 100으로 다시 시작하지 않는다.
4. 참조 루프가 같은 시작의 기존 R0와 일치해야 한다는 PLAN 확인을 수용한다. 가짜 자료 동일성은 실제 2014~2017의 평가 유효성을 보장하지 않는다. 공식 자료에서 필수 평가가 불확정이면 CHECK_REQUIRED로 보고한다.
5. 20분·3GiB는 추정이다. 공식 70 fit·90분·8GiB·CPU 최대 4스레드·solver 단일 스레드, 후처리 뒤 최종 예산 판정과 실패 보존을 유지한다. 성과 미달로 재실행하지 않는다.

### A-7. 문서 반영과 사용자 승인 한 묶음

판정 원문을 보관하고 원 설계에는 이 판정/B가 우선한다는 연결 줄만 추가한다. 원 설계를 새로 쓰지 않는다. 기존 PLAN §3·§4·§6·§7 및 상태 문구에 이번 확정 사항을 반영하고 STATE_LATEST·PROGRAM_TRUTH를 실제 진행 상태에 맞춘다. Q1~Q3의 제출 당시 질문은 이력으로 보존해도 된다.

실제 충돌이나 새 범위 변경이 없으면 **PLAN 재제출·추가 설계 검토·반복 조사 없이**, PLAN §7의 다음 네 항목을 사용자에게 한 묶음으로 확인한다.

1. 세 기반 문서에 **B §6-3의 갱신된 독립 예외 원문** 추가. 기존 제한/예외 삭제 없음.
2. 새 격리 연구 패키지·CLI·시험 구현과 가짜 자료 확인.
3. PC의 잠금 1회·공식 실행 1회·저장 산출물 검산. 외부 조회·설치·운영 DB 쓰기·OCI·PUSH 변경 없음.
4. 검증자 확인과 설계자 최종 RESULT 뒤 관련 코드·문서 종료 반영 및 커밋·push. 연구 원자료·모델/잠금/실행 산출물·사용자 handoff 제외, OCI 배포 없음.

이 판정은 위 승인을 이미 받았다고 처리하지 않는다. 승인을 받으면 같은 범위의 중간 작업마다 다시 묻지 않는다. 코드 결함으로 별도 공식 정정 실행이 필요할 때는 원인·동일 조건 여부·기존 기록 보존을 보고하고 그 실행만 별도 확인한다. 낮은 성과는 정정 실행 사유가 아니다.

설계자·개발자·검증자 역할을 유지한다. 이번에 새 BACKLOG 등록·UI·공급자·별도 handoff를 추가하지 않는다. POC6-22 CLOSED·Q6 OPEN·운영 ML 미승격·총수익 미검증·기존 미완료 요구는 그대로다.

### 1. 현재 문제와 단일 목표

POC6-22는 최신 사용자 보고대로 `d050c83d` push까지 끝난 CLOSED다. POC6-20의 한정 추가 효용과 POC6-21의 NOT_CANDIDATE·UNCERTAIN을 유지한다. 기존 연구를 다시 열거나 실패 원인을 하나로 단정하지 않는다.

**이번 목표는 같은 입력·같은 선형 모형·같은 허용 행동에서, 손익 예측 오차를 줄이는 학습보다 잘못된 행동 선택의 경제적 손실을 줄이는 학습이 비용 후 성과와 교체 부담을 개선하는지 확인하는 것이다.**

새 근거는 SPO 원문의 의사결정 손실 학습이다. DMN·LSTM이나 외국 선물 운용을 이식하지 않는다. 미래 60일 가격변화를 예측해 고정 문턱에 넣었던 POC6-21과 달리, 이번에는 **현재 상태에서 가능한 행동들의 비용 포함 결과 차이**를 배운다. 이로써 국내 ETF에서 성공할 것이라고 가정하지 않는다.

| 비교 장부 | 역할 |
|---|---|
| P · 예측 오차 학습 | 행동별 손익 차이의 절대 오차(MAE)를 줄이는 선형 모형 |
| S · 의사결정 손실 학습 | 같은 모형에서 SPO+ 손실만 사용하는 주 평가 대상 |
| R · 규칙 기준선 | POC6-21의 강화 없는 R0 정책 |
| K | 같은 시작일의 KODEX200 보유 |

P와 S의 차이에만 학습 목적의 추가 효용을 귀속한다. R과 과거 POC6-21 대비 차이에는 새 행동·목표·모형이 함께 들어가므로 그 원인을 손실함수 하나로 설명하지 않는다.

### 2. 유지할 계약과 허용 행동

가격은 기존 봉인 판의 연결 종가 I와 합성 시가 O*다. 가격·거래량 30열과 POC6-19 시장 4열은 POC6-20·21의 정의·순서·이용 시각 가정을 그대로 쓴다. 개인 평단·개인 실거래 손익·새 데이터는 넣지 않는다.

| 항목 | 고정 계약 |
|---|---|
| 검토·체결 | 한국 거래 주 마지막 날 D, 23:59:59 KST 판단. D 뒤 두 번째 한국 거래일 E의 시가부터 기존 체결·이연 계약 적용 |
| 후보 | 당시 적격 ETF의 RET_120 상위 5종·동점 종목코드 순. P/S 예측으로 후보 집합을 바꾸지 않음 |
| 보유·예산 | 최대 5종. 실행일 H1 시가 평가·처리 순서의 자산×0.2와 현금 중 작은 매수예산. 수수료 포함 수량·전량 매도·차입 금지·상시 비중 재조정 없음 |
| 일별 보호 | H1 보유 최고 종가 대비 −15% 보호·체결 이연·보호 우선·중복 취소 계약 유지 |
| 최초 상태 | 각 재생/평가 장부는 현금 100에서 시작. 첫 공통 신호만 R0의 최초 편입을 P/S/R에 공통 적용하며, 이후 P/S 학습 행동으로 전환. 최초 편입은 학습 효용으로 세지 않음 |
| 비용 | 편도 20bp가 기본, 40bp는 같은 학습 계수의 비용 스트레스. 현금 수익 0·K도 같은 체결/비용 정의 |
| 실제 권한 | 독립 모의 연구만 수행. 사용자 최종 판단·주문, PC 권고·Telegram 관찰 계약 유지 |

각 D의 상태는 당일 체결·평가·보호 처리를 마친 뒤, 새 주간 의도를 만들기 전 상태다. 그 상태에서 다음 **의도 묶음 하나**를 고른다.

| 행동 | 뜻 |
|---|---|
| KEEP | 새 통상 의도 없음. 기존 평가·보호·이미 확정된 보호 의도는 계속 |
| BUY(j) | 후보 중 미보유 1종 편입 |
| SELL(i) | 보유 1종 전량 이탈 |
| SWITCH(i,j) | 보유 1종 전량 이탈과 후보 미보유 1종 편입을 함께 계획 |

통상 변경은 주당 최대 1편입·1이탈이다. 동일 종목 동시 매수/매도·중복 의도·보유 한도 초과는 허용하지 않는다. 현금 또는 선택한 매도 대상의 D 평가금액으로 매수예산이 생길 수 있어야 BUY를 포함한다. 미래 E 가격·미래 체결 성공 여부로 행동을 미리 삭제하지 않는다. 실제 수량·현금·매매 불가 판단은 E의 기존 체결 순서가 맡으며, 매수 자금이나 슬롯이 없으면 매수만 취소하고 체결된 매도를 되돌리지 않는다.

이전 통상 의도가 미결이면 먼저 KEEP만 허용한다. 그 외 예정 슬롯은 5−현재 보유 수−살아 있는 매수 대기 수+이번 행동의 매도 수+현재 보유 중 살아 있는 보호 매도 수이며, BUY를 포함하려면 1 이상이어야 한다. 보호 예정 보유와 이번 통상 매도를 중복 계산하지 않는다. 예산은 h+(1−c)s > 10^-9여야 하며 보호 예정 대금은 더하지 않는다. 이 수치 경계는 NAV 비율의 계산 잔차를 거르는 기준이다. 실제 매수 직전 실제 슬롯과 현금을 다시 확인해 보유 5종을 넘지 않게 하며, 여유가 없으면 매수만 취소한다. KEEP을 포함해 통상 최대 36행동이다. 이 계약은 P/S와 학습용 행동 분기에 적용하며 R0 기준선 원본은 바꾸지 않는다.

시장 4열 공백 등 설계된 무계획 주는 공통으로 통상 판단을 쉬고 보호·평가를 계속한다. 신규 자격에서 정상 제외돼 입력이 없는 보유는 POC6-21 Q4대로 통상 판단 보류·보호 지속이다. 점수를 0/−무한대로 채우거나 강제 매도하지 않는다. 필수 대상의 계산 실패·비유한 값·보유 평가 불확정은 CHECK_REQUIRED로 구분한다. Q4의 주 비율·금액 노출·최대 노출을 별도 공개하며 인과 효과로 해석하지 않는다.

### 3. 학습 정답 — 20거래일 동안의 행동 결과 차이

#### 3-1. 공통 참조 상태

학습에 쓸 상태는 **20bp R0 정책 하나의 과거 경로**에서만 얻으며 학습용 분기도 20bp만 생성한다. 최초 공통 자료 가능 신호부터 현금 100으로 시작해, 당시 정보만으로 R0를 순차 재생한다. R0는 기존 RET_120 후보·RET_60 추세 점수·h=log(1.002/0.998)·비적격 보류·보호 규칙을 그대로 사용한다. 이 h를 새 손실에 맞춰 조정하지 않는다.

한 D에 참조 상태 하나를 두고, 그 상태의 모든 허용 행동을 P/S가 함께 학습한다. S가 방문한 상태를 보고 재학습 자료를 보태거나 반복 수집하지 않는다. 참조 상태 재생과 아래 정답 계산은 실제 가격의 경로 계산이므로 **공식 실행 승인 뒤에만** 한다.

평가 때 P/S는 참조 상태를 복사하지 않는다. 각자의 실제 모의 보유·현금·의도 상태에서 결정하고 다음 상태로 진행한다. 참조 상태와 학습 정책이 방문하는 상태의 차이는 학습 분포의 한계로 기록한다. 이를 없애기 위한 강화학습·반복 정책 학습은 추가하지 않는다.

#### 3-2. 정답 정의

같은 참조 상태를 행동 수만큼 분기해 각 행동을 E부터 기존 체결 규칙으로 실행하고, **E를 1일로 센 20번째 한국 거래일 종가 T**까지 평가한다. 분기 중 새 주간 통상 의도는 만들지 않으며, 일별 평가·보호와 발생한 체결 이연은 계속한다. 기존 가격 연결·평가 유효성 계약을 유지한다.

`g(D,a) = [NAV_T(D에서 a 선택) − NAV_T(D에서 KEEP 선택)] / NAV_D`

g는 **20거래일 모의 경로의 비용 포함 평가자산 차이**다. 60일 로그변화·D20·단일 ETF 수익률·총수익·전체 운용 가치가 아니다. KEEP의 g는 정확히 0이다. T의 열린 보유는 평가하고 만기 매도나 가상 청산 비용을 넣지 않는다. 실제 정책에도 20일 만기를 만들지 않는다.

수수료는 분기에서 실제 체결한 거래에 한 번만 적용한다. 과거에 이미 지급한 비용은 시작 상태에 들어 있으며 다시 부과하지 않는다. 거래하지 않은 가격 변화·취소 의도에는 비용을 넣지 않는다.

당시 행동 집합을 먼저 고정한 뒤 미래 자료 유효성을 확인한다. 어떤 행동만 정답이 없으면 그 행동을 삭제해 최선 행동을 바꾸지 않고 **해당 D의 학습 상태 전체를 제외**한다. 정상 취소·이연의 결과가 기존 계약으로 끝까지 평가 가능하면 유효한 정답이다. KEEP만 있는 날은 학습에서 제외하되, 실제 장부에서는 정상 무변경 주로 유지한다. 제외 사유·수와 미래 가용성에 따른 학습 선택의 한계를 기록한다.

20일 분기에는 그 이후의 통상 선택·장기 보유 효용이 들어 있지 않다. 이 짧은 관측 손실이 수주~수개월 운용에 도움이 되는지는 실제 순차 장부로 판단한다. 분기 최선의 누적 수익을 실현 가능한 전략 기준선으로 제시하지 않는다.

### 4. 같은 모형에서 손실만 비교

#### 4-1. 모형·입력 변환

P/S 모두 ETF별 34열과 현재 행동의 매수·매도 예정금액 비율을 사용하는 **공유 선형 모형 70계수**다. ETF 코드·과거 실현손익·최근 거래 간격은 학습 입력에 넣지 않는다. 후자는 §5의 사후 평가로만 본다.

판단일 표준화 34열을 u라 하고, 매수/매도 역할 각각 `[1,u]` 35열을 둔다. 해당 행동의 매수 예정금액 비율 b와 매도 평가금액 비율 s를 곱해 두 블록을 연결한다. 없는 역할 블록과 KEEP은 0이다. 이 합성은 금액 규모와 역할을 표현하기 위한 것이며 새 시장 factor를 탐색하는 것이 아니다.

예정금액은 D에서만 계산한다. `v=NAV_D`, `h=현금_D/v`, `s=선택 매도 보유의 D 평가금액/v`, `b=min(0.2,h+(1−c)s)/(1+c)`다. 매도 없으면 s=0, 매수 없으면 b=0. 이는 비용 포함 예산의 **판단용 근사**이며 E의 실제 수량 산식을 대체하지 않는다. 예상 비용 비율은 `k(D,a;c)=c(b+s)`다.

분기별 유효 학습 자료에서만 34열의 평균·표준편차를 정한다. 필요한 같은 D·ETF는 여러 행동에 등장해도 한 번만 센다. 열마다 결측 아닌 ETF에 날짜 내 동일 가중, 관측이 있는 날짜에 날짜 간 동일 가중을 준다. 평균 μ와 같은 가중치의 (x−μ)^2 평균인 모집단 분산을 사용한다. 열 전체 결측인 날짜는 그 열의 통계에서만 제외한다. 필수 열의 유효 관측이 전혀 없으면 CHECK_REQUIRED이며, 관측이 있으나 σ=0인 상수 열은 변환값 0이다. 나머지는 관측값을 (x−μ)/σ로 변환하고 정상 특징 결측 칸만 0, 즉 학습 평균 위치로 대치한다. 시장 공통 입력 공백·가격/평가 장애·예상 밖 비유한 값은 대치하지 않는다. KEEP/빈 역할 블록의 0을 관측값으로 세지 않는다. 같은 μ·σ를 P/S와 해당 분기 평가에 적용하며 평가 자료로 재추정하지 않는다. 원본 특징·자격·후보·R0를 바꾸거나 결측 지시 열을 추가하지 않는다. 분기별 관측/결측/상수 여부와 장부별 대치 칸 수를 보존한다.

학습 정답의 규모 s_g는 날짜 간 동일 가중·날짜 내 KEEP 외 행동 동일 가중으로 센 g의 RMS와 10^-6 중 큰 값이다. 두 모형이 같은 u·s_g·행동·정답을 공유한다. `||β||_1 ≤ 1`로 모형군을 고정한다.

`q_beta(D,a;c) = β^T z(D,a) − k(D,a;c)/s_g`

q는 정규화된 순효용 점수이며 KEEP은 0이다. 기본 비용 학습에는 `y_a=g(D,a)/s_g`를 쓴다. 점수에서 비용을 반영했다고 실제 장부 수수료를 면제하지 않으며, 정답 g에서 비용을 한 번 더 차감하지 않는다.

#### 4-2. 손실

- **P:** 날짜별 KEEP 외 행동의 `|q_a−y_a|` 평균을 먼저 구한 뒤 날짜 간 평균을 최소화한다.
- **S:** `a_star=argmax_a y_a`일 때 아래 SPO+ 손실의 날짜 간 평균을 최소화한다.

`L_S = max_a(2q_a−y_a) − 2q_(a_star) + y_(a_star)`

이 식은 SPO 원문의 최소 비용 정의에 `cost=−utility`를 대입한 최대 효용 형태다. 실제 선택 손실 `max(y)−y_(argmax q)`의 상계이며 음수가 되면 계산 결함이다. 예측과 정답이 같으면 0이어야 한다. 식 자체의 성질은 유한 행동 집합별로 확인하며, 원문의 모집단 일관성 정리가 우리 상태 의존 자료에서도 자동 성립한다고 주장하지 않는다.

학습·행동 동점은 현재 정보로 정한 고정 순서(통상 거래 수가 적은 것 → KEEP/SELL/BUY/SWITCH → 종목코드)로 처리한다. 미래 결과를 동점 해소에 사용하지 않는다. 예측 선택은 q 최대 행동 하나이며 새 성과 문턱·강화 배수는 없다.

두 손실과 계수 제한은 선형계획으로 표현한다. 개발자 측정의 기존 SciPy 1.18.0·HiGHS 1.12.0·numpy 2.4.6 환경을 설치/업데이트 없이 사용하며 버전 차이는 잠금에서 거절한다. 새 연구 프로세스의 첫 solver 호출부터 모든 호출을 하나의 도우미에서 highs-ds·기본 presolve·threads=1로 고정한다. 기본값 선행 호출이나 설정 실패 뒤 기본값 대체를 하지 않는다. BLAS/OpenMP 환경도 import 전 단일 스레드로 설정하고 잠금/실행에 기록한다. 옵션 전달 알림을 전체 경고 무시로 확대하지 않는다. 학습은 분기당 두 모형 하나씩 한 번이며 모형군·계수 한도·관측 기간·정규화·solver를 결과 보고 바꾸지 않는다. 여러 최적해가 있으면 고정 환경의 반환 계수를 그대로 보존한다.

solver 정상 최적 종료, L1 한도 초과량 max(0,||β||_1−1)와 다른 제약 위반 최대 10^-7 이내, abs(직접 전체 평균 손실−LP_full) ≤10^-7을 확인한다. κ_a=k_a/s_g일 때 SPO+ LP에서 상수항을 생략했다면 LP_full=solver.fun+날짜 평균(2κ_(a_star)+y_(a_star))이다. 가변 목적에는 날짜 평균(m_D−2β^T z_(a_star))가 모두 있어야 한다. 상수항을 이미 포함했다면 중복 가산하지 않는다. raw 목적·고정 상수·전체 목적·직접 손실·절대 차이를 저장한다. 실제 SPO+의 상계/부호는 전체 손실로 확인하고 수치 허용오차와 산술 오류를 구분한다. 상수항을 제외한 raw 목적이 음수인 것을 SPO+ 음수 결함으로 오인하지 않는다. 허용오차는 정규화된 문제 기준이며 실패를 다른 optimizer/설정 탐색으로 대체하지 않는다.

#### 4-3. 시간순 학습

분기 첫 판단부터 사용할 모형은 그 분기 시작 전에 고정한다. C를 분기 첫 한국 거래일의 직전 한국 거래일로 정한다. D가 분기 시작일의 5년 전 같은 날짜 이상이고, T의 한국 거래일 축 위치가 C의 위치보다 최소 20 작거나 같은 참조 자료만 사용한다. 정보와 정답의 끝을 모두 검사한다. 최소는 **KEEP 외 선택과 완전한 정답이 있는 서로 다른 D 104개**이며, 104는 이번 소규모 선형 연구의 계약이지 ML 일반 최소 요건이 아니다. 과거 5,000 ETF 행 기준을 상태 단위에 그대로 옮기지 않는다.

2018~2020 선행 재생과 2021~2026-09-21 주 평가의 최대 35분기·총 70 fit이다. 입력/달력에 따른 정확한 분기는 PLAN과 잠금에서 확인하며, 부족한 분기에 창을 늘리거나 다른 모형을 대신 넣지 않는다. 정답 제외 후 104개 미만이면 INSUFFICIENT_DATA로 중단·보고한다.

40bp 장부도 20bp에서 배운 같은 β·μ·σ·s_g를 사용한다. 행동 예산 조건·b·z의 매수 블록·k와 실제 체결 비용에는 모두 c=0.004를 적용한다. s·h·NAV_D는 각 비용의 자기 장부 상태에서 구한다. 20bp b를 40bp z에 고정하지 않는다. 참조 경로/정답은 20bp만 만들고, 40bp에서 새 학습·정규화·비용 탐색을 하지 않는다.

계약 충돌·자료/학습 부족·수치 실패·상한 초과는 정상 성과로 덮지 않는다. 부분 산출물과 중단 사유를 보존하고 해당 원인을 먼저 판정한다. 성과 미달은 오류 수정 실행의 사유가 아니다. 한도·기간·모형·손실 조합을 바꿔 합격할 때까지 반복하지 않는다.

이 설계와 적용성 판정 원문을 보존하고, STATE_LATEST·PROGRAM_TRUTH는 단계의 실제 상태만 갱신한다. 기존 POC6-22 CLOSED·Q6 OPEN·운영 ML 미승격·총수익 및 #3/#55/#57/#62 미완료는 유지한다. 사용자 소유 handoff·원자료·과거 산출물은 수정하지 않는다.

> POC6-23에 한해, 기존 봉인 KRX 합성 가격지수·거래량의 30열과 POC6-19 검증 시장 사본의 4열을 사용해 PC에서 비용을 반영한 주간 의사결정 학습을 연구한다. 고정 R0 참조 상태에서 KEEP·편입·전량 이탈·1대1 교체의 허용 행동별 20한국 거래일 체결·보호·평가 경로 차이를 정답으로 삼고, 같은 70계수 선형 모형에서 MAE와 SPO+ 학습 목적의 추가 효용을 비교한다. 원본 특징과 R0 정책은 유지하며, P/S의 선형 표현에 한해 분기 학습 자료의 관측값으로 날짜 균형 평균·표준편차를 구하고 정상 특징 결측을 표준화 후 평균 위치 0으로 대치한다. 결측 지시 열은 추가하지 않으며 시장 공통 입력 공백·가격/평가 장애는 대치하지 않는다. 2018~2020 유효성 재생과 2021~2026-09-21의 P/S/R/K 모의 장부를 편도 20bp·40bp로 평가하며, 입력 시각·성숙·상태·비용·평가·수치·예산은 POC6-23 설계와 판정대로 성과 계산 전에 고정한다. 이는 이미 본 기간의 합성 가격지수 탐색 연구이며 총수익 검증·운영 채택·자동 주문이 아니다. 새 산출물은 PC의 state/ml/research/poc6_23/에만 보존하고, 새 외부 조회·설치·운영 DB 쓰기·OCI·PUSH·기존 전향 모델 변경은 하지 않는다. Q6 OPEN·운영 ML 미승격을 유지한다. 이 예외는 기술 범위이며 구현·공식 실행은 해당 단계의 유효한 사용자 승인 범위에서만 진행한다.
