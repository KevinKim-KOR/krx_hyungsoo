## 4. Q1·Q2 · 조회 조건과 표시 정보

**각 화면은 자기 조회 조건을 쓴다.** 후보리스트에서 바꾼 기간·정렬·제외 조건은 그 화면에 적용한다. A의 미리보기, 섹터요약, 보유와 후보 비교는 각 화면의 조건으로 읽는다. 순위 계산에는 POC6-28의 공통 기간 기준을 각 화면의 조건으로 사용하며, A의 상위 3개는 A의 조건으로 계산한 목록에서 뽑는다. 각 목록 머리에 실제 조건과 시작일·끝일을 표시한다.

**Q1 · 기본 조회 기간은 이 브라우저에서 화면별로 저장한다.** 기간을 기본으로 저장하면 새로고침하거나 다시 들어올 때 그 화면에서 저장한 기간으로 시작한다. 저장값이 없는 화면은 해당 화면의 기본 기간으로 시작한다.

**수익률을 정하는 데이터와 표시 정의는 공통으로 쓴다.** 보유·후보리스트·보유와 후보 비교에서 종목의 아래 항목을 같은 단위와 의미로 보여 준다. 목록을 간결하게 볼 때에도 행 상세에서 전체 수치에 도달할 수 있게 한다.

| 항목 | 표시와 비교 기준 |
|---|---|
| **1·3·6·12개월 수익률** | 기존에 조회한 값과 실제 사용한 시작일·끝일을 함께 읽는다. 조회한 화면에서 값이 들어오는 범위를 확인하고, 필요한 곳에 기존 저장 가격과 계산 경로를 연결한다. 기간을 맞출 수 없는 경우 양쪽 실제 날짜를 각각 표시한다. |

## 5. 최신 자료 갱신과 호출 제어

- 기본 동작은 A의 **[최신 자료 갱신] 한 번**이다. 실행 가능한 기존 보유 현재가와 시장 자료 갱신을 이어서 실행한다. 완료 시 보유 현재가, ETF 가격·NAV, 코스피·VIX·수급 등 실제 처리된 자료별 기준일과 성공·일부 실패·대기 상태를 보여 준다. 같은 데이터를 이미 받은 경우에는 새 호출을 공유할 수 있는 범위에서 재사용한다.
- **[요약 다시 읽기]는 PC에 저장된 자료를 읽는 동작**으로 구분한다. 한 자료만 다시 받을 필요가 있는 경우에는 [VIX 다시 받기]처럼 기존 재시도나 별도 실행이 필요한 항목만 해당 상세에 둔다. 시장 갱신 대기 중에도 실행 가능한 다른 갱신을 진행하고, 기다려야 하는 단계의 사유·가능 시각을 표시한다.
- 기존 기록상 보유 현재가 갱신은 네이버, 시장 갱신은 기존 FDR 등 공급자 경로, 투자자 수급은 OCI 보관본 반영을 쓴다. PLAN에서 버튼별 실제 호출과 증권사 TR ID를 대조한다. 형수님이 전달한 **국내주식 계좌 TR 19개의 초당 1회 변경**은 발행처·대상 TR·시행일·집계 단위를 원문으로 확인한다. 공개 키움 이용안내에는 계좌·토큰 및 요청 종류에 따라 호출 제한이 안내돼 있다. [키움 REST API 이용안내](https://openapi.kiwoom.com/intro)
- 실제 사용하는 계좌 TR이 적용 대상이면 **서버의 공통 호출 경로에서 초당 1회 한도와 적용 단위**를 지킨다. 같은 제한 범위의 일반 조회·연속조회·재시도는 함께 세고, 여러 번 누르거나 다른 탭에서 시작해도 진행 중 작업을 이어 본다. 유량제어로 대기할 때는 연속 재호출을 막고 남은 작업과 직전 자료일을 알린다. 자동 작업이 같은 계좌·토큰으로 같은 제한을 쓰는 경우 그 호출도 함께 고려한다.

## 6. 개발자 목업과 실제 화면 완료 기준

1. **A 목업**에서 보유 점검과 잘 오르는 ETF가 각 한 카드다. 시장 근거가 자료·연구 상태 바로 위에서 닫힌 채 시작하고, 펼치면 기존 시장 배경과 VIX·수급·환율·유가의 상세를 확인한다.
2. **B 목업**의 네 메뉴와 보유·후보 선택 상세에서 1·3·6·12개월, 20구간 KODEX 200 차이, NAV·괴리율을 찾는다. 같은 종목·같은 자료 기준일이면 각 화면의 값과 단위가 맞고, 후보리스트의 조건 변경 뒤에도 다른 화면의 선택 조건은 각자의 값을 사용한다.
3. C의 기존 판단 미리보기·AI·구성종목 전달이 새 위치에서 실제 선택한 대상과 날짜를 사용한다. 필요한 진입점을 A·B 또는 해당 운영 위치에서 찾을 수 있다.
4. [최신 자료 갱신]을 연속으로 눌러도 같은 갱신이 중복 실행되지 않는다. 일부 갱신이 제한되거나 실패하면 성공한 자료와 이전 자료의 기준일을 구분한다. 적용 계좌 TR이 확인된 경우 연속조회·재시도까지 한도를 지키는지 확인한다.
5. A의 잘 오르는 ETF를 3개월, 후보리스트를 1개월로 각각 기본 저장하면 새로고침 후 각 화면은 저장한 기간으로 시작한다. 「ETF 구성종목」과 「AI 투자 세션」은 같은 그룹에서 열 수 있다. 「개발·실험용 › 미사용 기능」에서 관찰 후보 갱신 버튼과 두 설명을 읽을 수 있고, 기존 수동 초안에서 갱신 결과를 사용할 수 있다.

근거는 11/11 첨부 화면과 형수님 결정, POC6-27·28 결과, 기존 수익률·NAV·판단 상세 구현 기록이다. 관찰 후보 결과를 쓰는 수동 초안 두 곳은 개정 목업에 첨부된 개발자 조사 결과를 따랐다. 계좌 TR 공지의 대상 ID와 시행일은 PLAN에서 대조한다.
