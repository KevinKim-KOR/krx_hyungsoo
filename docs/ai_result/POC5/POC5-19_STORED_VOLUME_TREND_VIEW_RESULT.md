## 0. 요약

- **자료(백엔드 · 1차 구현 그대로)** — `app/stored_volume_evidence.py :: compute_volume_trend`
  - 입력은 POC5-09 거래량 칸 · 가격 흐름이 이미 쓰는 종목별 읽기 행 `rows_by_ticker`(종가가 유효한 저장 행 · 최신순 · 최대 21행)다. 새 DB 읽기는 없다.
  - 창 = 그 행의 앞 20개(기준일 D 포함) → 오래된 순 `points: [{date, volume}]`. 거래량이 null · 숫자 아님 · 음수 · 비유한 · bool 이면 `volume = null`(날짜 자리 유지 · 더 오래된 행으로 채우지 않음 · 0 으로 바꾸지 않음). 저장된 0 은 0.
  - `asof_date` = 창의 가장 최근 날짜 · `missing_count` = null 개수 · 행이 없으면 빈 목록. 종목 항목 선택 필드 `volume_trend`(같은 종목 여러 계좌 같은 값 · 다른 필드 · 평균 · 배수 · 기준일 판정 그대로).
- **「확인 근거」 종목 상세(개정 뒤 최종)**
  1. 제목 줄 = '종목코드 상세' + 오른쪽 **[세부 흐름 보기] 하나**(아래쪽 펼침 영역 없음).
  2. 자료 확인 안내(있을 때만 · 그대로).
  3. **세 묶음**(`EvidenceGroups.tsx` · 1차 구현 그대로): 가격 흐름(5일 · 20일 · KODEX200 대비 20일 · 하락 구간) / 거래량(거래량 · 평균 대비 · 직전 20개 저장일 평균 · 기존 '과거 저장 자료' 안내) / 가격 흔들림(최근 · 직전 20구간 · 비교 또는 사유). 묶음마다 실제 기준일 한 줄과 ? 하나(가격 흔들림 필드가 없으면 '확인 불가'만 · ? 없음). 계산 불가 · 기준일 다름은 그 묶음에 기존 사유. 좁으면 이름 위 · 값 아래.
  4. 가격 차트(기존 자리 · 받은 전체 저장 기간 · 아래 공통 차트 읽기 적용) → NAV · 괴리율 · 구성종목(그대로).
- **세부 흐름 창**(`DetailFlows.tsx` 버튼 + 창 · `DetailFlowsBody.tsx` 본문)
  - 기존 「종목 관리」 창 틀(`holdings_manage/Dialog.tsx`)을 쓴다. Esc · × · 바깥 누르기로 닫힘(창 안 ? 도움말이 열려 있으면 Esc 는 도움말만) · 닫으면 [세부 흐름 보기]로 초점 · 열면 첫 차트에 초점(좌우 화살표 바로 · 차트가 없으면 닫기(×)) · 종목을 바꾸면 창 · 고른 날짜를 이어받지 않음(key).
  - 제목 = 종목명 · 부제 '종목코드 · PC 저장 종가 · 저장 거래량'.
  - 첫 부분(`evidenceStrip.ts`) = 세 근거의 실제 기준일 + 핵심 값 한 줄씩(받은 값 · 기존 문구만). 거래량 기준일이 PC 비교 기준일과 다르면 그 줄에 기존 '과거 저장 자료' 안내.
  - '같은 날짜로 맞춘 최근 N개 저장일 · 시작 ~ 끝' + ?(기간 기준 · 날짜로 찾음 · 평균은 기준일 하나의 값 · 해당하는 제한).
  - 차트 위 고정 줄 '날짜 · 종가 N원 · 거래량 N주'(처음 = 가장 최근 저장일) → 종가 선 → 거래량 막대. 한 날짜를 고르면 두 차트가 같은 날을 가리킨다.
  - 종가는 기본 화면 가격 차트가 이미 받은 가격 시계열에서 **같은 날짜**를 찾는다(배열 위치로 짝짓지 않음). 그날 종가가 없으면 '종가 자료 없음'으로 두고 선을 끊는다(다른 날 값으로 채우지 않음). 같은 공유 조회 키(`priceSeriesKey`)를 **구독만**(`lazy`) 한다 — 창은 조회를 시작하지 않아 열고 닫아도 · 앞 조회가 실패했어도 새 GET 이 없고, 요청 중이면 그 결과를 기다린다('가격 시계열 불러오는 중...'). 가격 시계열을 쓸 수 없으면 기본 가격 차트와 같은 구분 문구.
  - 거래량 없는 날 점선 빈칸 · 저장된 0 은 바닥선 · 결측 안내 한 줄 · 흐름 자료 0개는 기존 '거래량 자료 없음'.
  - 아래쪽 = 가격 흐름 기간 · 하락 구간 세부 문장 · 거래량 출처와 비교 구간 · 가격 흔들림 기간.
- **차트 세 곳 공통 읽기**(`components/charts/SeriesChart.tsx` · `ReadableLineChart.tsx` · `lib/chartScale.ts`)
  - 대상: 코스피(「오늘의 투자 점검」 · 최근 120개 · pt) · 종목 가격(「확인 근거」 · 「ETF 비교하기」가 같이 쓰는 `workbench/PriceChart.tsx` · 원) · 세부 거래량(주).
  - 가로: 저장일 순서(달력 연속 관측 아님) · 날짜 눈금 4~5개(양끝 + 중간 · 첫 눈금과 해 바뀜은 연도까지).
  - 세로: 실제 값을 덮는 보기 좋은 눈금 3~5개(원 · 주는 1 보다 잘게 나누지 않아, 전부 0 처럼 범위가 1 이하이면 '0주 · 1주' 두 개)와 단위 · 같은 좌표의 옅은 가로선 · 거래량은 0 에서 시작 · 일정한 값 · 전부 0 · 1개여도 범위가 0 이 아님.
  - 고르기: 마우스 올리기 · 누르기 · 터치 끌기 · 좌우 · Home · End. 고른 날 = 점선 세로줄 + 점(선) / 진한 막대 · 값은 차트 위 고정 줄(툴팁에 기대지 않음 · 눈금은 '4만주'처럼 짧게 · 고른 값은 '12,864주'처럼 그대로).
  - 결측 = 선 끊기 / 점선 빈칸. 선 색은 기존 계약 그대로(정상 `var(--accent)` · 지연 · 실패 `var(--warn)` — `stroke` 속성).
  - 가격 차트 아래 '제공 기간 … · N일' → '… · N개 저장일' · 코스피 차트 아래 '최근 120거래일 · 최종 X' → '최근 120개 저장일 · 최종 Xpt'(달력 · 연속 거래일로 읽히지 않게 · 단위).
- 계산 · API · 수집은 1차 구현의 선택 필드 하나뿐이다. 개정은 화면만 바꿨다(백엔드 변경 0). 검증된 종합 위험 등급 · 매매 의견 아님.
