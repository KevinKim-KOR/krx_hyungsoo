## 0. 요약

- **공통 판정 함수**(`holdings_risk_evidence/riskCombination.ts :: riskStateFromQueries`)
  - 입력: 이미 받은 보유 평가 · 근거 두 조회의 상태와 자료. 두 화면이 같은 함수를 쓴다.
  - 시장 M = 근거 응답 `judgment_summary.market_position`
    - `available` 이고 `bear` → 하락
    - `available` 이고 `bull` · `neutral` → 하락 아님(판정 함수 `app/market_regime.py :: _label_from_score` 의 코드)
    - 그 밖(`available=false` · `unavailable` · 없음 · 모르는 코드) → 미확인. 화면 문구를 거꾸로 읽지 않는다.
  - 보유 H(이 순서)
    - 정상 응답의 빈 보유 → 대상 없음(근거가 실패해도)
    - 쓸 자료 없음(`error`) → 미확인
    - 13 요약 N > 0 → 하락 있음(일부 판정 불가여도)
    - N = 0 · A = B → 하락 없음
    - 그 밖 → 미확인
  - 받는 중이면 판정하지 않는다. 다시 읽기가 실패해도 받은 자료가 있으면(`success` · `stale`) 그 자료로 판정한다.
  - 「확인 근거」는 목록용으로 이미 만든 행을 넘겨 다시 만들지 않는다.
