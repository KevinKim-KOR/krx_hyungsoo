## 4. 지시문 외 변경 · 구현 판단

1. **기존 시험은 '모두 펼친 상태'에서 돈다**
   - `TodayInvestmentCheckView.test.tsx` 렌더 함수가 데이터 반영 뒤 접기 버튼(`button.tc-fold-btn[aria-expanded=false]`)을 모두 누른다.
   - 다른 네 파일은 시험마다 해당 칸을 편다.
   - 기존 확인 문장은 하나도 지우지 않았다. 값이 '없다'를 보는 시험이 접힌 칸 때문에 그냥 통과하지 않게 했다(판정 §3).
2. **같은 카드 안 반복 정리**(설계 §4)
   - KOSPI 상태는 차트 아래(배지 · 기준 줄)에 남기고, 기본 화면 오른쪽에는 사유 문장만 둔다. 사유 문장은 화면 판정 `kospiValuesUsable` 이 거짓일 때만 나오고, 정상 · 휴장이면 일간 값이 나온다.
   - 접힌 '코스피 수익률·위치'는 배지 · 기준 줄 · 사유를 예전처럼 모두 보인다(공용 `KospiStatusNote` 무변경).
3. **접힌 시장 칸 안내 대상**: 펼친 칸이 '자료 없음 · 자료 부족 (n/20) · 계산 불가 · 확인 불가'로 그리는 값만 셈한다(PLAN §3 표).
   - 코스피 1년 · 최근 1년 고점 대비 · 지속일 · KODEX200 거래량 칸별 · 시장 판정 확인 불가가 대상이다.
   - 코스피 1개월 · 3개월은 운영 판정 ok 면 산출되고, 펼친 칸 표시도 '-' 라 대상이 아니다.
   - '거래량' 칸은 이름이 겹쳐 `KODEX200 거래량 자료 없음` 으로 쓴다. '평균 대비'는 '계산 불가'(평균 0)일 때만 따로 센다.
4. **손익 미산출 안내**
   - 최대 3개 행에서 보유 조회는 됐는데 종목 합산 손익률이 없으면(매입 합 0 등) `확인 필요: 손익 자료 없음` 을 보인다(판정 Q3).
   - 보유 조회 전 · 실패면 비중 · 손익을 모두 보이지 않는 기존 규칙 그대로다. 이때 손익 안내는 내지 않는다.
5. **두 하위 구역 제목 글자**: 아래 묶음 안 h3 이라 20px → 17px 이 됐다(`.tc-h3`). 묶음 제목(h2 20px)과 단계를 구분하려는 것이다. 본문 · 값 글자 크기는 줄이지 않았다.
6. **날짜 이름 띄어쓰기 · 줄바꿈**: 실제 폭 캡처에서 '2026-10-13(저 / 장된'처럼 글자 중간이 끊겨서 두 가지를 고쳤다.
   - 표기를 `… 최신일 D (저장된 전체 종목 기준)` 로 띄어 썼다.
   - 펼친 칸에 단어 단위 줄바꿈(`word-break: keep-all`)을 줬다.
7. **버튼 접근 이름**: 같은 글자 버튼이 여러 개라 아래처럼 붙였다. 화면 글자는 PLAN 그대로다.
