### 보존한 기존 계약 (전부 무변경)

집계·상태 판정 로직은 한 줄도 고치지 않았다. 표시 형태만 바뀐다.

- `aggregateHoldings` — 같은 ticker 다계좌 한 행 집계
- 부분 평가 `(N/M)` — 평가손익·비중·평가액 각각 (부분값을 전체값처럼 보이지 않게)
- 다계좌 `count > 1` → 평가수익률 "계좌별 상이"
- 후보포함 / 보유여부 **3-state** (`relationState`) — 미포함과 "확인 불가" 구분
- `holdingEvidenceState` — Evidence 부재/실패는 "정상" 아닌 "확인 불가"
- NAV / 구성종목 상태 **분리 표시**
- stale 줄 `⚠ 이전 조회값 (재조회 실패 — 최신 아님)`
- 행 클릭 → `onSelect(ticker)` → 하단 `PriceChart`
- 빠른 필터 4종 · 검색 (부모 컴포넌트, 무변경)
- 후보 탭 정렬 키 6개와 재클릭 asc/desc 전환 동작

## 5) 알려진 한계 / 미완성

1. **사용자 실화면 확인 전.** 두 탭 모두 사용자가 아직 눈으로 확인하지 않았다.
   자동 테스트는 통과하지만 레이아웃·폭·가독성은 실화면 기준이어야 한다.
2. **`확인 필요` 탭 미전환** (`AttentionTab`). 표가 아니라 항목 목록이라 성격이 달라 손대지 않았다.
3. **`일간` 은 항상 `—`.** 목업에는 값이 있는 것처럼 그렸으나, Holdings 응답에 일간 필드가
   없어 값을 만들 수 없다. §7.6 명시 항목이므로 자리는 두고 미제공만 표시한다 (기존 동작과 동일).
4. **`보유` 배지가 보유 탭 모든 행에 붙는다.** 그 목록은 전부 보유 종목이라 정보량이 0이다.
   목업에서 승인된 형태라 그대로 넣었으나, 실화면에서 거슬리면 제거 후보다.
5. 우측 지표 열은 236px 고정, 900px 미만에서 카드 아래로 내려간다. 실제 사용 폭에서의
   적정성은 미검증.
6. 후보 탭 정렬 바는 보유 현황의 `.holdings-sortbar` 스타일을 재사용한다. 클래스명이
   holdings 계열이라 의미상 어색할 수 있다 (CSS 중복을 피하려는 선택).

## 6) 다음 검증자(Codex)에게 알릴 점

1. **테스트 10건의 표기 기준을 바꿨다.** 검사 항목은 유지하고 조회 방식만 고쳤으나,
   화면 문구 자체가 바뀐 곳이 있다. 과거 검증 라운드에서 확정된 표시 계약이므로 중점 확인 바람.
   - `◆ 후보` → `후보 포함` 배지 (보유 탭)
   - `◆ 보유` → `보유` 배지 / 미보유 행은 `미보유` 배지 (후보 탭)
   - 열 헤더 존재 검사 → 지표 라벨 존재 검사 (+ `일간` 값이 `—` 인지 함께 확인)
   - `getAllByText("확인 불가")` → `getAllByText(/확인 불가/)` (배지 문구가 `NAV 확인 불가`
     처럼 라벨을 포함하게 되어 완전일치가 깨짐)
   - 정렬 테스트: 열 헤더 클릭 → 정렬 바 버튼 클릭. 카드 안에도 `1M` 라벨이 생겨
     `.holdings-sortbar` 범위 안에서만 찾도록 좁혔다.
   - 3-state 구분(포함/미포함/확인 불가, 보유/미보유/확인 불가)은 문구만 바뀌고 구분은 유지.
2. **후보 탭 정렬은 "제거"가 아니라 "이전"이다.** 사용자는 보유 표 기준으로
   "정렬 바 빼고 카드 전환만" 을 선택했는데, 그때 전제는 "보유 표에는 정렬 기능이 없다" 였다.
   후보 표에는 헤더 클릭 정렬이 실제로 있어 그대로 빼면 기능 손실이므로, 그 답을 확대 적용하지
   않고 정렬을 세그먼트 바로 옮겨 보존했다. 이 판단의 타당성 확인 바람.
3. `role="button"` + `tabIndex={0}` + `aria-pressed` 로 행을 만들었다. 표에서 목록으로
   바뀌면서 접근성 시맨틱이 달라졌다 (`row`/`columnheader` → `button`).
4. 목록 루트에 `data-testid`(`wb-holding-list` / `wb-candidate-list`)를 추가했다.
   테스트 조회용이며 화면에는 영향 없다.
