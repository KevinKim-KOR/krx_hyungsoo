## 2. 질문 1 — 기존 `spike_or_falling` 이 실제 위험 신호인가 → **아니오**

### 2.1 판정 근거 (실측)

`state/universe/universe_momentum_latest.json` (OCI, 읽기 전용):

| 항목 | 값 |
|---|---|
| `spike_trigger_type` | `falling` |
| `spike_direction` | `down` |
| `falling_threshold_pct` | **−10.0** |
| `ranking_basis` | **`one_month_return_pct`** |
| `score_basis_text` | "pykrx 가격 히스토리 기반 **1개월 수익률**" |
| `falling_candidate` | `396520` TIGER 차이나반도체FACTSET · **−10.51%** |
| `price_history_basis` | `base_date 2026-08-05` (14,180) → `latest_date 2026-09-04` (12,690) |

### 2.2 설계자 지적 4가지 — 전부 사실 확인

| 지적 | 실측 |
|---|---|
| 장중 급락이 아니라 1개월 하락 | **사실** — `base_date 2026-08-05` ~ `latest_date 2026-09-04`, **한 달 구간** |
| 보유종목이 아님 | **사실** — 보유 고유 29종목에 `396520` **없음** |
| 단일 ETF 한 종목 | **사실** — 후보 20종 중 `falling_candidate` **1건** |
| 왜 지금 봐야 하는지 없음 | **사실** — 근거가 "1개월 −10.51%" 뿐 |

2026-09-07 09:30 실제 발송 본문:

```
[급등락·상승 관찰 신호]
기준 시각: 9월 7일 09:30
• [신규 falling] TIGER 차이나반도체FACTSET (396520): 1개월 -10.12%
  (현재가 12,745원, 2026-09-07T09:29:18+09:00).
```

**이름은 "급등락" 인데 실제로는 한 달 하락 스크리닝이다.** 보유와 무관하고
장중 급변과도 무관하다.

### 2.3 임계값 조정 연구를 하지 않는 이유

`−10%` 를 `−15%` 로 바꾸면 **같은 종류의 신호를 더 적게 보낼 뿐**이다. 기준을
바꿔도 "1개월 수익률" 이라는 성격과 "보유 무관" 이라는 한계는 그대로다.
설계자 확정대로 **임계값 연구로 들어가지 않는다.**

### 2.4 조치

`PUSH_AUTOSEND_SPIKE_OR_FALLING_ALERT_ENABLED=false` — 자동발송 비활성 유지.
**cron·코드는 제거하지 않는다.** 차단 실측은 §4.

## 3. 질문 2 — 현재 OCI 데이터로 위험을 검증할 수 있는가

### 3.1 OCI 위험 artifact 실측 (읽기 전용)

| 테이블 | OCI | 비고 |
|---|---|---|
| `market_risk_feature_daily` | **0행** | 사전 계산 위험 artifact **없음** |
| `etf_nav_daily` | 5,705행 · **2026-07-04 정체** | 65일 |
| `market_benchmark_daily_price` (KOSPI·VIX) | 6,079행 · **2026-07-03 정체** | 65일 |

> 로컬에는 `market_risk_feature_daily` 3,018행이 있으나 **운영은 OCI** 다.

### 3.2 판정 — `DATA_GAP` (범위 한정)

**OCI 의 사전 계산 위험 artifact 는 현재 사용할 수 없다.** 다만 일별 가격 ·
보유 수량 · runtime 현재가를 이용한 낙폭 · 집중도 · 변동성 등의 **최소 산출
가능성은 이번 조사에서 판정하지 않았으며, 다음 개발 PLAN(`OPS-02A`)의 선행 실측
대상으로 넘긴다.**

> ⚠️ 개발자 초기 보고의 **"변동성·낙폭·breadth·NAV 괴리 중 하나도 계산 불가"** 는
> **과장이었다.** 사전 계산 artifact 가 없다는 것과, 원천 데이터로 최소 산출이
> 불가능하다는 것은 다른 주장이다. 후자는 **평가하지 않았다.** (설계자 정정)

### 3.3 이번 `DATA_GAP` 근거에서 제외한 것

| 항목 | 제외 사유 |
|---|---|
| `etf_ml_feature_daily = 0행` | **위험 감지의 직접 근거가 아니다** (설계자 확정). ML feature 는 별개 관심사 |
| "최소 2년 표본" · "결측률 5% 이하" | **승인된 기준이 아니다.** 확정 계약으로 기록하지 않는다 |

이번 `DATA_GAP` 은 **"OCI 사전 계산 위험 artifact 부재 + 장중 시계열 부재"** 로만
성립한다. 그 밖의 수치 기준은 세우지 않았다.

### 3.4 재개 조건 (계약 아님 · 관심 항목)

다음이 확보되면 위험 감지를 다시 본다. **수치 기준은 승인 전이므로 적지 않는다.**

- **장중 가격 시계열** 또는 최소한 당일 시가·현재가 — "장중 급변" 을 정의하려면 필수
- **보유 종목 기준** 위험 지표(낙폭·집중도·변동성 등)의 산출 경로
- **시장 위험 축**(KOSPI/VIX)의 최신화 — 현재 65일 정체
- 위험 판정 시점의 **PIT timestamp**
