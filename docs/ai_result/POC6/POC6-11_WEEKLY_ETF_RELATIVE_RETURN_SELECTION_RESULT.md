## 0. 요약

- **무엇**: 같은 주간 운용 규칙(최대 5종목 · 상위 10위 유지 · 주 1개 편입 · 보호 이탈 −15%)에서 순위만 바꿔 비교했다.
  - L = LightGBM 순위(검증 구간에서 ML_A · ML_B 중 선택)
  - B = 단순 모멘텀(MOM20 · MOM120 중 선택)
  - K = KODEX200(069500) 보유
- **선택(검증 2018~2020 · 20bp)**: L = **ML_B**(CAGR −2.38%) · B = **MOM120**(CAGR +6.75%).
- **결과(시험 2021-01-04 ~ 2026-09-21 · 20bp)**:

| 곡선 | 기간 수익 | CAGR | MDD | 연환산 회전율 |
|---|---:|---:|---:|---:|
| L(ML_B) | +33.25% | 5.15% | −21.39% | 8.73 |
| B(MOM120) | +38.15% | 5.82% | −55.78% | 6.43 |
| K(069500) | +210.15% | 21.92% | −40.81% | 0.07 |

- **판정**: `PRICE_GAIN_NOT_SHOWN` · `NOT_CANDIDATE`. 네 기준 모두 미충족이다(위험 기준의 MDD 하위 조건은 충족했지만 회전율이 상한을 넘었다). 검증자 실측 정정(2026-10-27): §8-5의 네 축과 일치시켰으며 연구 결론은 변하지 않는다.
  - H1: CAGR(L) − CAGR(B) = **−0.67%p**(기준 ≥ +1.0%p) · 보조 구간 우위 **1/3**(기준 ≥ 2)
  - 목적: CAGR(L) − CAGR(K) = **−16.76%p**(기준 > 0)
  - 위험: MDD 는 L 이 B · K 보다 낮지만 회전율 **8.73**(기준 ≤ 6)
  - 비용: 40bp 에서 CAGR(L) − CAGR(B) = **−1.45%p**(기준 > 0)
  - 불확실성: 주간 L−B 평균 차이 95% 구간 [−0.49%, +0.30%] 에 0 포함 → `UNCERTAIN`
- **뜻**: 설계 §10 대로 **이 30열 · 60일 순위 목표 · LightGBM · 공통 운용 묶음의 H1 비교를 종료**한다. 다른 설정 · 보유 수 · 임계 · 목표 기간을 바꾼 후속은 자동으로 열지 않는다.
- **눈에 띈 점(설명용 · 판정 무관)**:
  - L 의 낙폭은 B 보다 작았다(−21% 대 −56%).
  - 그러나 L 의 중앙 보유가 12.5거래일(청산 246건의 하위 25%가 5거래일 이하)이라 회전이 많았다.
  - L 의 시험 순위 상관(rank IC) 평균은 −0.003(286일)이고, B 는 +0.065 였다.

- **같은 칸 조임(계약 밖 파일)**: 모델 폴더에 있어도 되는 파일을 '계약 단계 전체'에서 '기록된 학습 단계 + 그 바로 다음 학습'으로 좁혔다(`evidence._unexpected_files`).
  - 기록된 학습 단계의 원문 · 기록과, 기록된 단계 바로 다음 학습의 원문 · 기록을 허용한다. 바로 다음 학습은 정지 종류와 관계없이 허용한다.
    - 실패 · 복원 차이 정지에서는 흐름이 그 학습 도중(복원 대조 전) 원문을 실제로 쓴다.

  - 그래서 정상 실행에 심은 진단 파일 · 다른 학습 이름의 진단 파일 · 바로 다음 학습보다 뒤 학습의 원문은 '계약 밖 파일'이다.

## 5. 알려진 한계 / 미완성

- **가격 의미**: 합성 가격지수 결과다. 분배금 · 총수익은 확인하지 않았다(`TOTAL_RETURN_VALIDATED=NO`).
- **이미 본 시기**: 시험 기간은 과거 연구에서 이미 본 시기와 겹친다. 전향 입증이 아니다.
- **비용**: 20bp · 40bp 는 연구 가정이다. 실측 계좌 요금 · 세금이 아니다.
- **설명용 지표 일부 미산출**: 피어슨 IC · 학습 손실은 내지 않았다(판정 무관).
- **069500 의 2026-06 ~ 07 급락**: K 의 MDD −40.81%(2026-06-22 → 2026-07-30 · 끝까지 미회복)는 봉인 자료의 원시 종가 · 공표 등락률 · NAV 에 같은 하락으로 있다. 예: 06-19 종가 146,910 → 07-30 87,635 · 07-13 등락률 −9.77%. 개발자는 외부 시세와 대조하지 않았다. 사용자는 실제 코스피의 단기간 급락을 확인했다고 알렸다(§11-7 · 사용자 확인). POC6-10 의 KODEX200 보유 곡선 MDD 도 같은 −40.81% 였다.
- **verify 가 구별하지 못하는 위조(실행 기록 안에 시각을 보증할 외부 기준이 없음 · 설계자 판정 2026-10-27 §2-3 으로 수용)**: 시각 · 단계 경과 · 끝 시각 · 정지 문구 · 보고 판정까지 일관되게 고쳐 정상 실행을 '마지막 단계에서 예산 정지'로 낮추면 verify 가 통과시킨다(시험 `test_consistent_downgrade_never_certifies_a_conclusion` 로 실측 · verify OK).
  - 기록을 일관되게 바꿔 '복원 차이 정지'로 낮추는 경우도 같은 부류로 본다(판정 §2-3 · 시험 실측은 예산 정지 하향만 했다).
  - 이때 판정은 NOT_JUDGED 이고 남는 것은 판정 §3-3 이 허용한 진단 수치뿐이라, **결론을 인증하지는 않는다**. NOT_JUDGED 는 '검증된 연구 성과'가 아니며, 그 상태의 verify OK 는 그 상태에 요구되는 대조 통과일 뿐 run OK · 연구 채택과 다르다.
  - 부분 수정 · 숫자 하나 수정 · 이유가 다시 계산되지 않는 정지는 모두 불일치다.
- **중단 묶음의 쓰이지 않는 원문(검증 r5 F5 · 설계자 판정 2026-10-27 §2 · 비차단 공개 한계 · 코드 수정 없음)**:
  - 예산 정지 기록에 아직 시작하지 않은 바로 다음 학습의 원문(`models/<id>.txt`)을 더하고 해시 목록을 맞추면 verify 가 OK 다(검증자 재현 · 상태 BUDGET_STOP · H1 · 후속 후보 NOT_JUDGED 그대로).
  - 원인: 모델 폴더 검사가 기록된 학습 + 바로 다음 학습의 원문을 정지 종류와 관계없이 허용한다(§4-8).
  - 예산 정지 기록에서는 이 원문을 읽는 검사가 없다. 모델 대조는 모델 기록(json)이 있는 학습만 읽고, 원문을 다시 읽는 정지 이유 재계산은 복원 차이 정지뿐이다(`verify.py` · `evidence.py` 읽기로 확인). 그래서 이 원문은 예측 · 장부 · 결론의 근거가 되지 않는다.
  - 중단 기록의 일관성 검사를 통과해도 그 학습의 실행 · 완료 · 모델 유효성을 인증하지 않는다.
  - 최신 공식 실행(정상 완료)의 모델 폴더는 모델 기록 47 · 원문 47 · 진단 파일 0 이다(실측).
  - 판정 §2-3 이 계속 막으라고 한 경우에 해당하는 지금 검사는 그대로다(이번 판정으로 걷어 낸 검사 0).
    - 결론 근거가 되는 기록(모델 기록 · 예측 · 일정 · 장부 · 선택 · 보고)은 다시 계산해 대조한다.
    - 남은 파일 · 보고 칸이 더 강한 주장을 하면 필요한 단계 범위가 늘어 불일치가 된다(§4-7 '가장 강한 주장').
    - 멈춘 실행의 판정은 NOT_JUDGED 여야 한다.
    - 시험 근거: 적대 시험의 위조 49개 · 심은 파일 3종이 모두 불일치(§9-2).
- **OpenMP 동반 적재(설계자 판정 2026-10-27 §3 · 이 고정 Mac 환경 · 별도 연구 프로세스에 한해 수용)**: 연구 프로세스에는 libomp 3개가 함께 올라온다.
  - 로드 순서 고정 · 가드는 이 환경 · 경로에서 확인한 실행 조건이다. 복수 런타임 충돌의 근본 해결이나 다른 환경의 안전성 보장이 아니다.
  - 가드는 torch 의 libomp 가 먼저 올라온 경우 · Homebrew libomp 가 없는 경우를 CHECK_REQUIRED 로 멈추게 할 뿐, 모든 네이티브 충돌을 미리 잡지는 않는다(§4-2).
- **실제 LightGBM 시험의 실행 방식**: 전체 회귀에서 다른 시험 모듈이 torch 를 먼저 불러올 수 있어 새 프로세스에서만 돈다(실행기 시험 1개가 띄움).
