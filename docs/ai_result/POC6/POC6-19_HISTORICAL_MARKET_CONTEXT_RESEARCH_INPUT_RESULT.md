- **구현한 것**: 맥북 1회성 연구 명령 `python scripts/run_market_history.py fetch` 와 검산 명령 `verify`.

  - 원시를 보관하고, 정규화 · report.json/md 를 만든 뒤, 원시에서 다시 계산해 대조한다.
- **기존 코드는 바꾸지 않았다**(`git diff` 0줄). 기존 어댑터 두 개에 이미 있는 주입 인자(`http_post` · `http_get`)로 전송을 끼워 원시를 보관한다. 새 의존성도 없다.
- **판정 보완 2건을 코드와 시험에 반영했다.**
  - 13분류 값이 다른 날짜와 같아도 '반복 응답 의심' 표시만 한다(유효 · 연속 실패 판정에 쓰지 않음).
  - Yahoo 의 날짜 집합이 기존 저장본과 달라도 B 를 진행하고, 차이는 사유와 함께 기록한다.
- **시험**:
  - 새 시험 53개 · 재사용한 어댑터 시험 43개(합계 96개)가 모두 통과했다(설계자 RESULT 판정 정정 뒤).
  - 코드 변이: 검증자 r2 정정까지 59종 · RESULT 판정 정정의 변경 경로 7종을 모두 잡았다(복원 뒤 원본 지문 같음).

- **선행 실측(사용자 결정 · §9)**: 등록 IP 망이 아닌 지금 한 번 실행했다. 원/달러 · WTI 는 2014-01-02 ~ 2026-09-21 을 받아 ARCHIVE_READY · verify OK 다. 키움은 토큰 1회에서 '코드 3 · 사유 8050(IP 미등록)'으로 거절돼 ACCESS_BLOCKED 다. 실제 거절 꼴이 코드의 가정(문구 안 `[8050:` · §4-5)과 맞았다.

4. **실행 중 운영 작업 시간대 보호(판정 §4 · 독립 검토 지적).**
   - 시작 금지: 08:20 ~ 10:30 KST.

5. **키움 사유 코드는 응답 문구 안의 네 자리 코드(`[8050:…]` 꼴)도 읽는다.** 저장소의 실제 거절 기록이 '코드 3 · 8050 IP 미등록'(POC6-17)이라, 네 자리 코드는 `return_code` 가 아니라 문구 안에 있다.

## 5. 알려진 한계 / 미완성

- **선행 실측 폴더의 보고는 정정 전 형식이다.** 고친 코드로 verify 하면 새 형식 3곳(제외 목록 파일 · report.json · report.md)이 다르게 나온다. 원시 · 기존 정규화 3파일은 같다. 이 차이는 알려진 형식 차이이며 원본 손상이 아니다. 폴더는 정정 전 형식 그대로 보존한다. 이 폴더를 '현행 코드로 verify 완전 일치'라고 하지 않는다. 원/달러 · WTI 판정 근거는 이 폴더 + 검증자 r1 ~ r3 대조 + §14 새 형식 대조로 고정됐다(범위 확정 판정 §4).
