## 5. 지시문 외 변경

- **공식 실행 뒤 바뀐 잠금 대상 코드(2026-11-24 실측):** 잠금 코드 해시 14개 중 `app/candidate_compare/verify.py` · `scripts/run_candidate_compare.py` 2개가 잠금과 다르고 12개(연구 모듈 7 · 재사용 5)는 같다. CLI 는 `week` 판정 표시(공식 실행 직후)와 r1 정정(표시 조건 · 종료 코드), `verify.py` 는 r1 정정이다. 실행 경로(`prepare` · `run`)와 계산 모듈(`protocol` · `rules` · `population` · `study` · `flow` · `report`)은 바뀌지 않았다. r1 정정 때 나눈 `recompute.py` · `recompute_weeks.py` 는 잠금 목록(잠긴 `protocol.py`) 밖이라 검산 코드 해시(§16-1 F2)가 덮는다.
- **PLAN §5-3 주별 끝일 구현 규칙 교체(r1 F3 · §16-3):** 처음의 '끝일 금요일 · 평일 기준' 규칙을 판정 Q6 · 프로젝트 거래일 계약(`calendar.check_trading_day`)에 맞춰 바꿨다.
- **시험 가짜 값 정정(r1 정정 · 공개 저장소):** 복사문에 개인 보유 수치가 새지 않는지 보는 시험(`test_copy_text_has_no_personal_holdings_and_starts_with_latest_check`)의 가짜 값이 실제 보유 수치와 같았다. 누가 봐도 가짜인 값으로 바꿨다(시험 뜻 그대로).
- **검산 모듈 · 시험을 나눔(r1 · r2 정정 · KS-10):** r1 정정으로 `verify.py` 가 955줄(백엔드 650 초과)이 되어 재계산 ① 주 · ② 요약을 새 파일로 옮겼다(옮긴 함수 24개는 글자 그대로). r2 정정 때 마지막 잠금 · 검산 기록 이어짐 · 검산 지문 · 화면 표시 확인을 `verify_records.py` 로, 검산 시험을 `tests/test_poc7_03_verify.py` 로 나눴다(시험 1,665줄 → 사전 경고 1,450 넘음 · 내용 그대로 · §18-4).
