## 0. 한 줄

PC 시세 DB 의 ETF 가격 이력에는 다른 시점에 받은 '수정주가 묶음'이 섞여 있다. 제안은 같은 원천 · 같은 수집 묶음으로 전체 이력을 한 번 받아 **별도 연구 사본**을 만들고, 06 경계 판정으로 사본의 경계 수를 관측하고, 기존 KRX 자료의 기준가 조정 후보와 일간 배율을 대조해 사본의 일관성을 **검증하는** 것이다(판정 §4-1 정정). 라이브 DB 는 덮어쓰지 않고, 성과 실험은 시작하지 않는다.

## 2. 목적 · 하지 않는 것 (판정 §3 · §4)

- **목적**: 다른 시점의 가격 묶음이 섞인 문제를 일관된 연구용 자료로 다루는 방법을 정하고 검증한다. 종목 수를 늘리려고 가격 의미를 무시하지 않는다.
- **하지 않는 것**:
  - 라이브 `market_data.sqlite` 덮어쓰기 · 갱신 방식(120일 창) 변경.
  - 06 경계 판정 완화.
  - 경계마다 비율로 이어 붙이기(가격 의미 무시).
  - POC6-02 실험에 새 자료 끼워 넣기 · 공식 실험 교체.
  - 새 자료로 성과 실험 자동 시작.
  - 새 factor · 메뉴 · API · 알림.
  - 저장소 전체 재감사.

**(a) 의 확인 순서(결과 = 자료 판정만 · 성과 0)**

1. 대상 ETF(Q1)의 전체 이력을 같은 날 한 번에 받는다. 원응답 행 수 · 받은 시각 · 원천을 기록한다.
2. 연구 사본(`state/ml/research/poc6_03/<시각>_<id>/prices.sqlite` · gitignored · 새 폴더)에 저장한다. 라이브 DB 는 `mode=ro` 로만 읽는다.
3. 06 경계 판정(`prices.AxisSeries` · `link_break`)을 수정 없이 적용해 사본 안의 경계 수 · 날짜 · 종류를 **관측**한다(0 을 만들려고 판정 · 값을 바꾸지 않음 · 경계 0 은 그 검사에서 못 찾았다는 뜻일 뿐 공식 수정주가 · 총수익 · PIT 보증 아님).
4. KRX 대조(2014-01-02 ~ 2026-09-21):
   - 사본 종가 ÷ KRX 무조정 종가의 비율을 날짜마다 구한다.
   - 그 비율이 바뀌는 날이 KRX 기준가 조정일과 같은지, 바뀐 크기가 조정 크기와 같은지 본다(허용 오차는 원 단위 반올림 범위 · PLAN 판정 뒤 고정).

5. 라이브 DB 와의 차이표를 만든다(ETF × 날짜 · 차이 비율 · 라이브 행 수집 시각). 지금 경계가 '수집 묶음 기준 차'라는 추정을 사실로 바꾸거나 반박한다.
6. 보고서(report.md · report.json): 대상 · 받은 시각 · 경계 수(라이브 vs 사본) · KRX 대조 결과 · 06 적격 기준으로 다시 셌을 때 적격이 될 ETF 수(숫자만 · 성과 계산 0) · 한계.

### 7-3. 대조 규칙(판정 §4 · 결과 전에 고정)

- 경계: 06 `link_break` 를 기존 이력(POC6-02 공식 snapshot 행)과 사본에 그대로 적용. 원천 이름 바꾸기 · change 재작성 없음. 사본도 받은 날 기준의 사후 자료.
- 짝: 같은 종목의 **기존 연구 거래일 축에서 연속인 두 거래일**만. 그 두 날이 KRX 거래일에서도 연속이어야 한다. 중간 행 · 값이 없으면 건너뛰어 계산하지 않고 '대조 불가(사유)'. 유효한 0(전일 대비 0)과 결측을 구분.
- KRX 값: `krx_sealed_reader.load_panel` 의 무조정 종가 C_t 와 관계 검증된 일간 수익률 r_t = Δ_t / (C_t − Δ_t)(FLUC_RT 와 허용 오차 대조 · 부호 있는 전일 대비 금액이라는 의미를 이 관계로 확인) → 기준가 B_t = C_t − Δ_t = C_t / (1 + r_t), KRX 기준가 대비 배율 C_t / B_t = 1 + r_t. 관계 불일치 · 종가 무효 · 값 없음 = 대조 불가.
- 기준가 조정 후보 = |B_t − C_prev| ≥ 0.5원(원 단위 정수 가격의 반 원 · 부동소수 역산 여유). 후보 배율 = B_t / C_prev. 사건 근거 없으면 '조정 사유 미확인'.
- 일치 판정(±1원 진단 폭 · 고정): A = 사본 종가. A_prev − 1 > 0 일 때 하한 = (A_t − 1)/(A_prev + 1) · 상한 = (A_t + 1)/(A_prev − 1). C_t/B_t 가 [하한, 상한] 안 = '표기 오차 허용 범위 내 일치', 밖 = '불일치'. 계산에 표시용 반올림 없음. 결과를 본 뒤 폭을 넓히지 않는다.
- 단위: 종목별 겹치는 날의 A_t / C_t 중앙값이 [0.5, 2.0] 이면 같은 원 단위로 본다. 아니면 그 종목 전체 '대조 불가(단위 미확인)'.
- 누적: A_t / C_t 를 보고하고, 여러 조정의 누적은 배율의 곱으로 비교한다(합 · 반올림된 FLUC_RT 누적 복원 없음).
- 범위: KRX 봉인 판 = 2014-01-02 ~ 2026-09-21. 그 뒤 날짜는 'KRX 범위 밖'으로 센다(KRX 로 검증했다고 쓰지 않음). 14종은 봉인 DB 의 자료 유무만 읽어 확인 · 없으면 대조 불가 · 새 KRX 조회 없음.
