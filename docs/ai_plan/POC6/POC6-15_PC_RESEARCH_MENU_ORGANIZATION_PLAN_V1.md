## 2. 최소 변경안(설계 §9-2 · 판정 §2 · §5 반영 · 현행)

- **메뉴 키 호환**: 기존 `ml` 키를 지우지 않고 「예측과 결과 비교」에 쓴다(설계 §4-4 '구 키 → 전향 ML 비교'). 진입 호출자 · 저장 값이 없어 별도 매핑 표가 필요 없다. 새 키는 `ml_legacy` 하나.
- **사이드바 폴더**(`LeftSidebar.tsx`): 그룹 항목에 폴더 하나를 허용한다(한 단계만 · 범용 트리 아님).
  - 폴더 버튼 = 펼침 · 접힘만(`onSelect` 호출 없음 · `aria-expanded` · `aria-controls`). 하위 메뉴 = 지금 메뉴 버튼과 같은 모양 · `aria-current` · 들여쓰기.
  - 접힘 상태 = 지금 그룹 접힘과 같은 방식(화면 안 `useState` · 저장 없음). 활성 화면이 폴더 안이면 처음 · 활성 변경 때 폴더를 자동으로 편다(지금 그룹 자동 펼침과 같은 규칙). 접어 두면 폴더 줄에 현재 위치를 표시한다.
  - 무결성 검사(모든 키 정확히 1번)와 평탄화 목록(`MENU_ITEMS`)은 폴더 하위까지 센다.
- **화면 선택**(`MainPanel.tsx`): `case` 1개 추가 · `<MLView key="…" page="forward|legacy" />`. 선택한 화면만 렌더링하고, 화면마다 새로 마운트한다(지금 메뉴를 옮길 때와 같은 수명).
- **ML 화면**(`MLView.tsx`): 화면별 제목 · 소개 문장 · 카드 목록만 다르다. 소개 = '미리 기록한 예측과 이후 실제 결과를 비교합니다.' · '현재 예측 비교와 별개인 이전 자료와 실험 결과를 확인합니다.'(판정 §2). 「이전 자료·실험」 맨 위에 '이 자료를 다시 만들어도 현재 예측 비교의 입력이나 모델이 갱신되는 것은 아닙니다' 한 줄. 상대 상승 결과 상태는 「이전 자료·실험」 화면에서만 보관한다(지금은 MLView 가 보관 · 메뉴를 떠나면 사라지는 수명 그대로). 카드 컴포넌트 · API 함수는 복제하지 않는다.
- **안내 문장 1곳**(`DiagnosticsView.tsx`): '데이터 상태·ML 실험은' → '데이터 상태·ML 연구는'.
- **CSS**(`globals.css`): 폴더 버튼 · 하위 메뉴 들여쓰기 · 카드 결론 줄 규칙 소량.
- **하위 메뉴 힌트(새 문구 · 목업 3 확인 대상)**: 예측과 결과 비교 '미리 기록한 예측 · 이후 실제 결과' · 이전 자료·실험 '예측 비교와 별개인 이전 자료 · 실험'. 폴더 자체에는 힌트를 두지 않는다.
- **카드 안**(판정 §3 · §4 · 자세히 §8): 순서 = 제목 → 현재 결론 한 줄 → 주요 버튼 · 선택 → 설명 · 상세. 여섯 카드의 사용자용 문구 전체를 쉬운 한국어로. 개발 식별자 · 원시 진단은 접힌 '자세한 정보 › 개발 정보'로.
- **바꾸지 않는 것**: 백엔드 · API 계약 · 저장 구조 · 명령 버튼의 핸들러 · 재생성 대상 · 사용 제한 · 통계 · 모델 설정 · 06 / 13 / 05 · 다른 메뉴 화면 · AI 세션 초안 · 원장 · 새 라우터 · 새 저장 장치 · 새 상태 관리 라이브러리 · 새 상태 조회 · 연구 계산.
- 예상 파일: `LeftSidebar.tsx`(253 → 약 320) · `MainPanel.tsx`(+약 4) · `MLView.tsx`(58 → 약 85) · `DiagnosticsView.tsx`(1문장) · `globals.css`(+약 25) · 카드 6파일(`ML*Card.tsx` 4 · `RelativeUpsideRunCard.tsx` · `ml_forward/ForwardComparisonCard.tsx`)과 `ml_forward/ForwardCompareReport.tsx` · `forwardText.ts`(문구 · 순서) · 결론 줄 · 접힌 개발 정보용 작은 표시 컴포넌트 1개(필요 시 · 판정 §3 허용) · 시험(아래) · `PROGRAM_TRUTH` §5.1 · §5.2 · STATE. 지금 가장 긴 카드 = `ForwardComparisonCard.tsx` 426줄 · 프런트 임계 900 · 근접 850 에서 멀다(KS-10 기준 안).
