## 4. 보고 표 (결과 전에 고정)

**T1. 공통 4종 · 같은 행(A · B · C 의 4종 행)**
- 방법별 날짜 균형 MAE(전체 · 3구간)와 같은 행 ID 수를 싣는다. 정답은 각자의 자료다(A = 기존 저장 종가 · B · C = 사본 종가).
- **정답 차이** |정답_A − 정답_B| 를 같은 행에서 직접 센다(평균 · 최대 · 0.1%p 넘는 행 수). 일간 잔차나 누적 차이로 20거래일 목표의 정확성을 대신하지 않는다(판정 §6-3).
- **자료가 바뀐 영향** = A 대 B. 같은 4종 · 같은 모델 · 같은 행에서, 자료(feature · 정답)만 다르다.
- **표본이 넓어진 영향** = B 대 C 의 POOLED_HGB(같은 사본 자료 · 같은 4종 행 · 학습 표본만 4 → 12종).
  - MEDIAN · RIDGE 는 ETF 별 학습이라 B 와 C 에서 4종 예측이 같아야 한다. 이것을 대조군으로 확인하고, 다르면 멈춘다.
- 정답이 다른 A 의 MAE 와 B · C 의 MAE 를 빼서 '모델 향상'으로 쓰지 않는다. 표에는 나란히만 둔다.

**T2. C 내부 12종**
- MEDIAN · RIDGE · POOLED_HGB 의 날짜 균형 MAE(전체 · 3구간)를 싣는다.
- POC6-02 의 세 조건 판정(두 기준 각각 · 5% · 2구간 · 5% 악화 금지 · 기준 0 · 경계 근처 표시)을 그대로 적용하고 '탐색적'으로 표시한다(Q3).
- ETF 별 MAE · 개선/악화 수 · D20 ≤ −8% 행 보조 진단을 싣는다.

**T3. 자료 불확실성 표시(성과와 함께 · 제외 0)**
- ETF 별 POC6-03 KRX 대조 불일치 비율(±1원 규칙)을 ETF 별 MAE 옆에 둔다.
- 월 분배 2종(161510 · 441800)에 '조정 사유 미확인' 표시를 단다.
- 3구간에서 정답 끝이 KRX 봉인 판 범위 밖(2026-09-21 뒤)인 행 수를 싣는다(B 64 · C 192 · 실측).
- 응답 시작이 늦은 3종(069500 · 139260 · 161510 · 2014-07-28 부터)의 학습 행 수를 싣는다.

## 5. 자료 불확실성 취급 (결과 전에 고정 · 판정 §6-2)

- A/B 정답 차이: 같은 행 · 수익률 단위 · 평균 · 최대 · |차| > 0.001 행 수.
- 정답이 다른 MAE 끼리 빼서 개선율로 쓰지 않는다.
- C 주 판정 = POC6-02 세 조건(MEDIAN · RIDGE 각각 · 전체 5% 이상 감소 · 2구간 이상 엄격 개선 · 어느 구간도 5% 넘는 악화 없음) · 기준 0 = 미충족(사유) · 반올림 전 값 · 입력 손상 · 표본 부족 · 실행 실패는 기준 미충족으로 대체하지 않음.
- ETF 별 KRX 불일치율 = 불일치/(일치 + 불일치) · 대조 불가 수 따로 · 대조 관측 기간과 MAE 시험 기간 구분 · 성능 원인으로 단정 안 함.
- D20 ≤ −8% = 미래 정답으로 고른 행의 사후 진단(급락 사전 탐지 성공률 아님).
- 같은 시험 기간 재사용 · 현재 보유 사후 선택 → 기준 충족이어도 **탐색적 재현 결과**(독립 시험 · 투자 수익 검증 아님).

### 10-5. 입력 고정 · 출력(판정 §6)

- 실행용 manifest = 각 입력 파일의 전체 64자리 sha256 · 학습 전에 확인 · 다르면 CHECK_REQUIRED(자동 대체 없음).
- A 의 CPU report.json 은 같은 해시의 읽기용 사본을 출력 폴더에 보존하고 그 사본으로 A 를 참조한다(POC6-02 GPU 취합이 생겨도 A 고정).
- B · C 는 새 snapshot 으로 식별해 각자 digest 를 계산하고 부모 입력 경로 · 해시를 따로 기록한다(원본 digest 를 붙이지 않음).
- 결과는 새 `state/ml/research/poc6_04/<시각>_<id>/` 에만.
