## 4. 환경 · 충돌 (설계 §11-4)

**LightGBM 4.7.0**(PyPI 2026-07-18 · 최신 · MIT · `requires_python >=3.10`):
- 현재 `.venv` 에는 없다(Python 3.12.13 · macOS 27.0.1 · arm64).
- 의존(`narwhals>=1.15` · `numpy>=1.21.3` · `scipy`)은 모두 이미 설치돼 있다. narwhals 2.24.0(scikit-learn · plotly 의존) · numpy 2.4.6 · scipy 1.18.0 이다. 새로 깔리는 파이썬 패키지는 lightgbm 하나다.
- 대상 휠은 `lightgbm-4.7.0-py3-none-macosx_12_0_arm64.whl` · sha256 `129535462686f274df179133643118c5c5c5667167fe6c3a28d955f0b3c8e868` 다. 내려받은 파일 해시가 PyPI 공개값과 같다.
- **OpenMP 차단**: `lib_lightgbm.dylib` 이 `@rpath/libomp.dylib` 을 요구한다. 휠에는 libomp 가 없다.
  - rpath 는 `/opt/homebrew/opt/libomp/lib` · `/opt/local/lib/libomp` 두 곳뿐이다.

- 원 실행과 네 정정 실행을 보존하고, 최신 잠금 · 실행이 판정 대상이다.
- 추가 설정 탐색 · 새 잠금 · 여섯 번째 공식 실행의 승인은 아니다. 문서만 바뀌면 잠금을 갱신하지 않는다.

**시험 40bp 만 미확정(판정 §5)**: 전체 H1 · 후속 후보 NOT_JUDGED 를 유지한다(§6 Q2 중단 순서 그대로).
- 확인된 20bp 수치는 진단으로 남긴다. 이를 완결된 H1 판정으로 올리거나, 40bp 를 빼고 비용 기준을 바꾸지 않는다.
- 미확정을 성과 미달 · 비용 민감의 입증으로 쓰지 않는다.
