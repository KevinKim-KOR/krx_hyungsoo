## 3. 분석 정의(설계 §3 그대로 · 한 번만)

- **3-1 점수 자체**: 공통 행에서 R(= log1p(RET_60)) · M(저장 예측)을 같은 정의로 본다. 구간 = q ≤ −2h / −2h < q ≤ −h / −h < q < h / h ≤ q < 2h / q ≥ 2h(h · 2h = 잠금 recipe 값). 구간마다 행 수 · 날짜 수 · 평균 점수 · 평균 y_abs · y_abs > 0 비율, 전체 MAE |q − y_abs| · 부호 일치(q > 0 ↔ y_abs > 0 · 0 은 비양수). 평균 · 비율은 **날짜 안에서 먼저 낸 뒤 그 구간에 행이 있는 날짜끼리 같은 비중**으로 요약하고(R · M 의 구간별 날짜 집합은 다를 수 있음 · 날짜 수 · 행 수를 함께 적음), 전체 MAE · 부호 일치도 같은 공통 행의 날짜 균형 요약이다. 빈 구간 = 자료 없음(미성숙 · 정답 부재와 구분). 전체 · 보조 3구간 · 상위 5 후보 부분집합. R 의 MAE 는 과거 추세 점수와 미래 절대 정답의 같은 단위 거리이며 R 이 미래 예측으로 검증됐다는 뜻이 아니다. 새 합격선 · 확률 교정 · 신뢰구간은 만들지 않는다.
- **3-2 운용 경로**(R0 · M0 먼저 · R1 · M1 은 강화 효과와 연결): 계획마다 후보 5종을 '검토 → 문턱 통과 · 실패'(저장된 `entry_reviews` = **직접 기록**)와 '미검토'로 나누고, 미검토 사유는 **판단일 당시** 계획 · 보유(그날 장부) · 살아 있는 의도 · 한도만으로 복원한다(**사후 복원 · 직접 기록과 구분** · 판단일 뒤 체결 · 손익 미사용). 조건이 겹치면 복수 조건으로 표시하고(보유 중 · 매수 대기 · 매도 대기 · 한도 도달), 하나도 맞지 않으면 확인 불가로 남긴다. 미검토를 문턱 실패로 세지 않는다. → 편입 의도 → 체결(취소 사유별)까지 건수 · 날짜 수를 센다. 매수 의도 취소 0건은 '만든 의도가 모두 체결됨'이며 검토 전 기회 제한이 없었다는 증거가 아니다. 입력 공백 9주 · 비적격 보류는 따로 센다. 완료 거래는 공식 `trades[]` 를 그대로 써서 보유기간 분위 · 이탈 구분(통상 · 단기 재이탈 · 보호)별 손익 · 비용 · 열린 보유 평가를 낸다. **연결 확인**: 완료 손익 합 + 열린 보유 평가손익 합 = 끝 평가 − 100(장부 단위 · 비용 다시 빼지 않음). 현금 비중 · K 움직임은 **모든 달력 월**을 같은 정의로 나란히 둔다(고르지 않음 · 첫/끝 불완전 월은 범위 표시 · 곡선/K 같은 월 경계): 평균 현금 비중 = 그달 저장 거래일 평균 · 월 수익 = 직전 월말 저장 평가 대비 그달 마지막 저장 평가(첫 월 기초 = 시작 100) · 진입 · 이탈 체결 수. 보조 3구간 요약도 같은 정의. 'K 에 넣었다면' 수익 · 반사실 장부는 만들지 않으며, 이탈 사유별 손익 · 현금/K 동시 움직임은 실제 경로의 기술이지 CAGR 차이의 인과 분해가 아니다. 연결 차이를 보정값으로 없애지 않는다.
- **3-3 Q4 보류**: 원래 126/117주 · 171/150 종목·주를 계획 기록과 대조한다. 보류 구간 = 같은 보유 회차(매수 체결 ~ 매도 체결)에서 보류 표시가 이어진 정기 계획들(회차가 바뀌면 별도 구간)이며, 구간마다 종목 · 첫/마지막 보류 계획일(그 날짜의 관측 · 매일 자격 재검사 아님) · 주 수 · 보유 거래일 · 첫 보류일의 보유 금액 비중(수량 × 종가 / 장부 평가) · 그 구간의 실제 평가 변화 · 이후 경로(다시 자격 → 통상 검토 · 보호 이탈 · 끝까지 보유)를 장부 그대로 정리한다. **일별 노출** = 직전 유효 정기 계획의 보류 표시를 다음 유효 정기 계획 또는 실제 이탈까지 이은 집계(무계획 9주에 걸친 날은 따로 표시 · '그날 자격 탈락 확인'이 아님)이며, 수량 · 종가 · 평가는 각 장부 날짜 값 · 평균 분모 = 확인 가능한 모든 장부 날짜(현금 · 비보류일 0 포함) · 상태를 이을 수 없는 날은 미확인으로 분리(0 으로 대체 안 함). 주 비율 · 종목·주 · 종목·일 · 금액 비중을 섞지 않는다. 보류 때문에 생긴 손익 크기 · 강제 매도 차이는 계산하지 않고 확인 불가로 적으며, 비적격 보유의 새 점수는 만들지 않는다.
- **결론 형식**: 관측 사실 / 일치하는 설명 · 가설 / 저장 자료로 분리 못 하는 원인 · 빠진 필드 / 후속 가설 근거 유무(설계 §4). 다음 모델 · 임계 · 보유기간 · Q4 대체 규칙은 정하지 않는다.
