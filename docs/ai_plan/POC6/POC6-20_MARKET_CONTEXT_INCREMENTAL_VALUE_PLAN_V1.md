## 2. 분모 — 성과 없이 센 값(2026-11-04 실측)

입력 지문(sha256): 봉인 판 `fe3022e9…dacf2`(H1 과 같음) · 수급 `investor_flow.csv` `43f9578d…a9e68` · `investor_flow_dates.csv` `e7d8baa5…77e71` · 매크로 `macro.csv` `60be6c20…c7e9ef0`.

**4열 정의 규칙(설계 §3 · §4 · 이번 셈에 쓴 해석)**

- 예상 한국 거래일 = 봉인 판의 069500 날짜 축(H1 과 같은 축). 수급 사본의 날짜는 2014-04-10 ~ 2026-09-21 구간에서 이 축과 한 날도 다르지 않다(실측).
- 수급: 관측일 d 는 'd 다음 축 거래일 12:00 KST' 에 쓸 수 있다 → 신호일 D(23:59:59 KST 마감)에서 쓸 수 있는 마지막 날 = D 바로 앞 축 거래일. 창 = 그날까지 20 축 거래일. 20일 모두 VALID 여야 하고, 실패일이 하나라도 있으면 미정의. 절댓값 합 0 인 창은 0개(실측).
- 매크로: 관측일 d(원천 시간대 날짜)는 'd + 2달력일 00:00(원천 시간대)' 을 KST 로 바꾼 시각에 쓸 수 있다. D 마감까지 쓸 수 있는 마지막 유효 관측과 그보다 20개 앞 관측(모두 21개). 20개 간격의 실제 달력 길이 = 원/달러 28 ~ 30일 · WTI 28 ~ 35일.

- **Q1 기반 문서 예외(충돌)**: 세 기반 문서(PROJECT_ORIGIN_INTENT §9.5 '축 간 관계' 아래 예외 기록 · ASSUMPTIONS Q6 · KILL_SWITCHES KS-11 기록)의 ML 연구 예외는 'POC6-11 H1에 한해 … 가격 · 거래량 30열'이다. H1 설계 §4 는 수급 · 환율 · WTI 를 입력에 넣지 않는다고 적었다. POC6-20 의 4열 추가는 이 예외 밖이다. → POC6-20 한정 예외 문장을 판정에 주시면 세 문서에 원문 그대로 넣는다.
- **Q2 순위 없는 주의 재진입 대기**: H1 코드는 보호 이탈 뒤 '정기 검토 4번'을 **모든 주간 신호일**로 센다(H1 에서는 모든 신호일이 계획 주였음). 이번에는 4열이 없어 순위를 만들지 않는 주가 검증 4 · 평가 9 생긴다.
  - (a) 권장: H1 코드 그대로 모든 주간 신호일을 센다(대기 = 달력상 4주 · 운용 계약 불변).
  - (b) 순위를 만든 주만 센다(대기가 그만큼 길어짐).
- **Q3 2018 ~ 2020 재생의 역할**: 선택이 없으므로 무엇을 만들고 무엇이 멈춤 조건인지.
  - (a) 권장: P/M/B/K 장부를 20bp 로 만든다(H1 검증과 같은 비용). 재생에서 CHECK_REQUIRED · 복원 불일치가 나오면 평가를 시작하지 않는다(H1 판정 '검증 CHECK_REQUIRED 는 시험을 멈춘다'와 같은 뜻).
  - (b) 재생 결과와 무관하게 평가를 진행하고 재생은 기록만 한다.
- **Q4 M−P 주간 차이(bootstrap)의 주 범위**:
  - (a) 권장: 평가 구간의 완전한 주 전체(H1 과 같은 셈 · 순위 없는 주도 보유는 움직이므로 포함).
  - (b) 공통 계획 주(289)만.
- **Q5 이름(결과를 보기 전 고정)**:
  - 열 이름 · 순서 제안: 30열 뒤에 `FLOW_FRGN_DIR_20` · `FLOW_ORGN_DIR_20` · `USDKRW_CHG_20` · `WTI_DIFF_20`.
  - 상태 이름 제안: 추가 효용 `MARKET_GAIN_OBSERVED` / `MARKET_GAIN_NOT_SHOWN` · 후속 후보 `FURTHER_REVIEW_CANDIDATE` / `NOT_CANDIDATE` · `NOT_JUDGED` · `DATA_SHORT` · `BUDGET_STOP` · `CHECK_REQUIRED`(H1 이름 체계와 같은 꼴).
  - 설계 §5 '시장 공통 관측을 ETF 행 수만큼 독립 표본으로 늘려 세지 않는다'는 보고 규칙으로 읽고, 학습 가중치는 H1 그대로(날짜마다 같은 합)로 둔다. 다르게 읽어야 하면 알려 주시기 바란다.

### 5-2. 구현 · 확인 범위 추가(판정 §6)
