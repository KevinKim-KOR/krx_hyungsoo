## 1. 현재 코드 확인 (설계 §7)

### 1-1. 시장 국면 코드 · 전달 위치
- 판정 함수 `app/market_regime.py :: _label_from_score`(`:373`)의 코드는 `bull`(상승장) · `bear`(하락장) · `neutral`(보합장) 세 가지다.
- KODEX200 자료가 부족하면 `status = unavailable` · `regime_code = "unavailable"` · `regime_label = "판정불가"`다(`:420`).
- 두 화면은 근거 응답의 `judgment_summary.market_position`(`app/market_summary_composer.py :: summarize_market_position` · `:231`)을 이미 받는다. 13 의 시장 국면 문구도 이 값이다.
  - `available` = `market_context` 가 있고 `status` 가 `unavailable` 이 아님(`:245`)
  - `regime_code` · `regime_label` · `regime_streak_days` · `regime_streak_at_least`
- 「확인 근거」는 시장 GET 을 부르지 않는다. 그래서 두 화면 모두 근거 응답의 `market_position` 하나를 쓴다(새 조회 0).
- **M 판정**: `available` 이고 `bear` → 하락 · `available` 이고 `bull` · `neutral` → 하락 아님 · 그 밖(`available=false` · `unavailable` · 없음 · 모르는 코드) → 미확인.
- 화면은 Python 함수를 가져올 수 없다. 그래서 세 코드를 화면 상수로 두고(주석에 출처) 시험으로 고정한다.
  - 판정 함수에 코드가 새로 생기거나 바뀌면 화면은 '미확인'으로 보인다. '하락 아님'으로 잘못 보이지 않는다.
- 자료 최신성(KODEX200 기준일 · 시장 지연 안내)은 기존 표시를 그대로 둔다. 분류 입력에 넣지 않는다.
